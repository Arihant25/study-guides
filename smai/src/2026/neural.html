3.1Neurons and neuron models

Lecture L14 · Short video: Neural networks basics

An artificial neuron multiplies each input by a weight, adds the results, and passes the sum through a fixed function called the activation.

The name comes from biology. A nerve cell in the brain (a neuron) receives signals from other cells through branches called dendrites. The strength of each connection (a synapse) differs. When the combined incoming signal is strong enough, the cell sends its own signal out along its axon. The slides quote the human brain as having about 10 billion neurons and 60 trillion connections.

The artificial neuron copies only the arithmetic. It has inputs \(x_1, x_2, \dots, x_m\) and one weight per input, \(w_1, w_2, \dots, w_m\). A weight \(w_{kj}\) on the slides means the weight on the connection from neuron \(j\) into neuron \(k\).

  1. The adder computes the weighted sum \(v \)\({}= w_1x_1 + w_2x_2 + \dots + w_mx_m + b\). The extra number \(b\) is the bias. It shifts the sum up or down whatever the inputs are.
  2. The activation function \(\varphi\) (phi) turns the sum into the output, \(o = \varphi(v)\). It is usually nonlinear, and it keeps the output within a fixed range.

To save writing, the bias is folded into the weights. Put a constant 1 in front of the input and \(b\) in front of the weights.

\[\mathbf x = [1, x_1, \dots, x_m]\T,\]\[\mathbf w = [b, w_1, \dots, w_m]\T,\]\[v = \mathbf w\T\mathbf x.\]
Reading the formula

\(\mathbf w\T\mathbf x\) is the dot product. It multiplies matching entries and adds them, so \(\mathbf w\T\mathbf x \)\({}= b\cdot 1 + w_1x_1 + \dots + w_mx_m\). The \(\T\) (transpose) turns the column \(\mathbf w\) into a row so the product is a single number.

The leading 1 in \(\mathbf x\) is what makes the bias appear. This is called the augmented input. Page 1 used the same trick for the linear classifier.

Example. Take \(\mathbf w = [1, 2, -1]\T\) and the input \((x_1, x_2) = (3, 4)\). The augmented input is \(\mathbf x = [1, 3, 4]\T\). Then \(v \)\({}= 1\cdot1 + 2\cdot3 + (-1)\cdot4 \)\({}= 1 + 6 - 4 \)\({}= 3\). If the activation is the sign function, the output is \(+1\) because \(3 > 0\).

L14 lists when a neural network is a sensible choice. The input has many attributes. The output may be a class, a real number or a vector. The training data may be noisy. You can afford a long training time but need fast predictions. You do not need a person to be able to read the learned function. The slides also contrast a network with a normal computer. A network does many simple operations in parallel, while a CPU does complicated instructions one after another. And instead of writing a model by hand and checking it against data, a network finds the model from the data.

Remember
  • Neuron output \(o \)\({}= \varphi(\mathbf w\T\mathbf x)\) with the bias folded into \(\mathbf w\) by putting a 1 at the front of \(\mathbf x\).
  • The weights are what is learned. The activation \(\varphi\) is fixed in advance.

3.2The perceptron

Lecture L14 · Reading for the convergence proofs: Duda, Hart and Stork, Pattern Classification, page 229 (cited on L14 slide 19)

A perceptron is one neuron with the sign function as its activation. It labels an input \(+1\) or \(-1\) by which side of a line (or plane) the input is on, and it learns the line by nudging the weights after each mistake.

The word comes from "perception". Frank Rosenblatt built the first one in 1958 as a model of how a machine might perceive patterns. It is also called a single layer perceptron (SLP), because there is one layer of weights between the input and the output.

The sign function is \(\operatorname{sgn}(v) = +1\) when \(v > 0\) and \(-1\) when \(v \lt 0\). Each training sample comes with a target \(t\), which is \(+1\) for one class and \(-1\) for the other. The output is \(o \)\({}= \operatorname{sgn}(\mathbf w\T\mathbf x)\).

The learning rule

\[w_i \leftarrow w_i + \Delta w_i,\]\[\Delta w_i = \eta\,(t - o)\,x_i.\]
Reading the formula

The arrow \(\leftarrow\) means "replace the old value by the new one". \(\eta\) (eta) is the learning rate, a small positive number such as 0.1 that sets the size of each change.

The factor \(t - o\) is the error. Since \(t\) and \(o\) are each \(+1\) or \(-1\), it can only take three values.

  • Correct output, \(t = o\). Then \(t - o = 0\) and nothing changes.
  • Target \(+1\), output \(-1\). Then \(t - o = 2\) and the rule adds \(2\eta\,\mathbf x\) to \(\mathbf w\).
  • Target \(-1\), output \(+1\). Then \(t - o = -2\) and the rule subtracts \(2\eta\,\mathbf x\).

In both error cases the change is \(2\eta\,t\,\mathbf x\). L14 slide 7 writes it as \(\eta\,t\,\mathbf x\), which is the same rule with the 2 absorbed into \(\eta\). Use the \((t - o)\) form unless a question says otherwise, and say which form you are using.

Why it helps. After the update, the new sum for the same sample is \((\mathbf w + 2\eta t\mathbf x)\T\mathbf x \)\({}= \mathbf w\T\mathbf x + 2\eta\,t\,\|\mathbf x\|^2\). The added part \(2\eta t\|\mathbf x\|^2\) has the sign of \(t\), because \(\|\mathbf x\|^2\) (the squared length of \(\mathbf x\)) is positive. So the sum moves towards the correct side.

Example. With \(\mathbf w = [0, 1]\T\), \(\mathbf x = [1, -2]\T\), \(t = +1\) and \(\eta = 0.5\), the sum is \(0 - 2 = -2\), so \(o = -1\), which is wrong. The change is \(0.5\cdot 2\cdot[1,-2]\T \)\({}= [1, -2]\T\). The new weights are \([1, -1]\T\) and the new sum is \(1 + 2 = 3 > 0\), now correct.

One full sweep through the training set is called an epoch. The algorithm stops after the first epoch with no mistakes.

Common mistake

Forgetting the leading 1. The first weight is the bias, so it changes on every update by \(\pm0.2\times 1\). Also, the final weights depend on the order of the samples and on whether you use \(\eta(t - o)\) or \(\eta t\). Any weights that classify all three samples correctly are a valid answer to "iterate until convergence" if you show the steps.

AND, OR and XOR

Boolean functions are a standard test. With \(\pm1\) logic, \(+1\) means true and \(-1\) means false. AND is true only when both inputs are \(+1\). A perceptron with \(b = -1\), \(w_1 = 1\), \(w_2 = 1\) does it.

\(x_1\)\(x_2\)\(v = -1 + x_1 + x_2\)\(\operatorname{sgn}(v)\)AND
\(-1\)\(-1\)\(-3\)\(-1\)false
\(-1\)\(+1\)\(-1\)\(-1\)false
\(+1\)\(-1\)\(-1\)\(-1\)false
\(+1\)\(+1\)\(1\)\(+1\)true

With 0/1 logic and a threshold unit \(\varphi(v) = 1\) if \(v \ge 0\), otherwise 0 (the L15 question uses this), AND is \(\varphi(x_1 + x_2 - 1.5)\) and OR is \(\varphi(x_1 + x_2 - 0.5)\). The sum \(x_1 + x_2\) counts how many inputs are on. AND needs the count to reach 2, so the threshold sits between 1 and 2. OR needs a count of at least 1, so the threshold sits between 0 and 1.

XOR (exclusive or, written EXOR on the slides) is true when exactly one input is on. Its four points cannot be split by a single line. The two true points \((0,1)\) and \((1,0)\) sit on one diagonal of the unit square and the two false points \((0,0)\) and \((1,1)\) on the other. Any line that puts both true points on one side puts at least one false point there too. Data that a line (or plane) can split is called linearly separable, so XOR is not linearly separable and no single perceptron can compute it.

There are two ways round this, and L14 slide 22 asks for both.

  1. Two layers. Compute OR and AND in a hidden layer, then output "OR and not AND". With \(h_1 = \varphi(x_1 + x_2 - 0.5)\) (OR) and \(h_2 = \varphi(x_1 + x_2 - 1.5)\) (AND), the output is \(y = \varphi(h_1 - h_2 - 0.5)\). At \((1,1)\) both hidden units are 1 and \(y = \varphi(-0.5) = 0\). At \((1,0)\), \(h_1 = 1\), \(h_2 = 0\) and \(y = \varphi(0.5) = 1\). At \((0,0)\) both are 0 and \(y = \varphi(-0.5) = 0\).
  2. Expand the input (the kernel idea from page 2). Add the product \(x_1x_2\) as a third feature. With \(\pm1\) inputs, \(x_1x_2 = -1\) exactly when the inputs differ, so XOR is \(\operatorname{sgn}(-x_1x_2)\), a perceptron with weight \(-1\) on the new feature. With 0/1 inputs, XOR \(= \varphi(x_1 + x_2 - 2x_1x_2 - 0.5)\). In the expanded space \((x_1, x_2, x_1x_2)\) the four points are linearly separable.

The first idea is the start of the multi-layer perceptron in 3.4. The hidden layer builds new features (OR and AND) out of which the answer is a linear function.

Does it always stop?

  • Claim 1. If some weight vector classifies every training sample correctly (the data is linearly separable), the perceptron algorithm reaches such a vector in a finite number of updates. This is the perceptron convergence theorem.
  • Claim 2. If the data is not linearly separable, there is always a mistake somewhere, so updates never stop. The weights keep cycling, so the algorithm loops for ever. XOR is the standard example.
  • Claim 3. For separable data the number of updates is bounded. The usual statement (Novikoff's bound) is at most \((R/\gamma)^2\) updates. Here \(R\) is the length of the longest input vector, and \(\gamma\) is the margin, the smallest distance from a sample to the best separating plane through the origin (with \(\|\mathbf w\| = 1\)). A wide gap between the classes means few updates.
  • Claim 4. Every Boolean function can be computed by a network of perceptrons two layers deep. Write the function as an OR of AND terms (one AND unit per row of the truth table that is true, then one OR unit). The XOR network above is a small case of this.

Is the perceptron doing gradient descent?

Gradient descent (page 1) needs a loss that changes smoothly as \(\mathbf w\) changes. The number of mistakes does not. It jumps between whole numbers, and a small change in \(\mathbf w\) usually leaves it the same, so its gradient is 0 almost everywhere. L14 slides 16 to 18 fix this by weighting each mistake by how far it is on the wrong side.

Write this in the exam

Show that the perceptron rule is gradient descent on a loss.

  1. Let \(E\) be the set of misclassified samples. Define \(J(\mathbf w) \)\({}= \sum_{\mathbf x_i\in E} -t_i\,\mathbf w\T\mathbf x_i\).
    Why (4 steps)
    1. A sample is misclassified when \(\mathbf w\T\mathbf x_i\) has the opposite sign to \(t_i\).
    2. So for a misclassified sample \(t_i\,\mathbf w\T\mathbf x_i \lt 0\), and \(-t_i\,\mathbf w\T\mathbf x_i > 0\).
    3. That term is larger the further the sample is on the wrong side. So \(J \ge 0\), and \(J = 0\) only when nothing is misclassified.
    4. The slides write the same idea as \(\sum_i (t_i - o_i)^2(-\mathbf w\T\mathbf x_i)\). Correct samples give \(t_i - o_i = 0\) and drop out. On a mistake \(t_i - o_i = 2t_i\), and the slides then use \((t_i - o_i)\) as the weight, which gives \(-2t_i\,\mathbf w\T\mathbf x_i\), our term times 2.
  2. \(\nabla J \)\({}= \sum_{\mathbf x_i\in E} -t_i\,\mathbf x_i\).
    Why (3 steps)
    1. \(\nabla J\) is the vector of partial derivatives of \(J\) with respect to each weight.
    2. For one term, \(\mathbf w\T\mathbf x_i \)\({}= w_0x_{i,0} + w_1x_{i,1} + \dots\), so its derivative with respect to \(w_k\) is \(x_{i,k}\). Collected over \(k\), \(\nabla(\mathbf w\T\mathbf x_i) \)\({}= \mathbf x_i\).
    3. Multiply by the constant \(-t_i\) and add over the mistakes.
  3. Gradient descent \(\mathbf w \leftarrow \mathbf w - \eta\nabla J\) gives \(\mathbf w \leftarrow \mathbf w + \eta\sum_{\mathbf x_i\in E} t_i\,\mathbf x_i\).
  4. Using one misclassified sample at a time gives \(\mathbf w \leftarrow \mathbf w + \eta\,t_i\,\mathbf x_i\), the perceptron rule (with \(\eta\) absorbing the factor 2 of the \((t - o)\) form).

This \(J\) is called the perceptron criterion. It is piecewise linear, so it has a gradient everywhere except where a sample lies exactly on the boundary.

Remember
  • Perceptron update \(\Delta\mathbf w \)\({}= \eta(t - o)\mathbf x\). It changes only on mistakes, by \(\pm2\eta\mathbf x\).
  • Converges in finitely many steps when the data is linearly separable. Loops for ever when it is not.
  • XOR is not linearly separable. Fix it with a hidden layer or with an extra feature \(x_1x_2\).
  • The rule is gradient descent on the perceptron criterion \(\sum_{E} -t_i\mathbf w\T\mathbf x_i\).

3.3The delta rule and gradient descent

Lecture L14 · Short video: MSE using GD

Drop the sign function, keep the plain sum \(o = \mathbf w\T\mathbf x\), and minimise the squared error by gradient descent. The update you get is the delta rule.

A neuron with no activation (or the identity activation) is called a linear unit. Its output \(o = \mathbf w\T\mathbf x\) can be any real number, and the slides call it "unthresholded". Over the training samples \(d = 1, 2, \dots\), each with target \(t_d\) and output \(o_d\), the error is

\[E(\mathbf w) = \frac12\sum_d (t_d - o_d)^2\]\[{}= \frac12\sum_d \Big(t_d - \sum_i w_ix_{i,d}\Big)^2.\]
Reading the formula

\(\sum_d\) adds over the training samples. \(x_{i,d}\) is feature \(i\) of sample \(d\), and \(\sum_i w_ix_{i,d}\) is the output \(o_d\) written out.

The \(\frac12\) is there only so that it cancels the 2 that comes down when you differentiate the square. It does not move the minimum.

Example. One feature, no bias, two samples \((x, t) = (1, 2)\) and \((2, 3)\), and \(w = 1\). The outputs are 1 and 2, the errors are 1 and 1, and \(E = \frac12(1 + 1) = 1\).

As a function of \(\mathbf w\), \(E\) is a sum of squares of linear functions, so it is a bowl (a quadratic with a single lowest point region and no other dips). L14 slide 11 asks you to plot it for one sample. With \(x = 2\), \(t = 4\) it is \(E(w) \)\({}= \frac12(4 - 2w)^2 \)\({}= 2(w - 2)^2\), a parabola with its minimum at \(w = 2\). This shape is called convex, so gradient descent cannot get stuck in a wrong dip.

Write this in the exam

Derive the delta rule \(\Delta w_i \)\({}= \eta\sum_d (t_d - o_d)\,x_{i,d}\).

  1. Gradient descent moves against the gradient. \(\Delta w_i \)\({}= -\eta\,\frac{\partial E}{\partial w_i}\).
  2. \(\frac{\partial E}{\partial w_i} \)\({}= \frac12\sum_d 2(t_d - o_d)\,\frac{\partial}{\partial w_i}(t_d - o_d)\).
    Why (3 steps)
    1. The derivative of a sum is the sum of the derivatives, so take \(\frac{\partial}{\partial w_i}\) inside \(\sum_d\).
    2. Each term is a square of something, \(u^2\) with \(u = t_d - o_d\).
    3. By the chain rule, \(\frac{\partial}{\partial w_i}u^2 \)\({}= 2u\,\frac{\partial u}{\partial w_i}\).
  3. \(\frac{\partial}{\partial w_i}(t_d - \mathbf w\T\mathbf x_d) \)\({}= -x_{i,d}\).
    Why (3 steps)
    1. The target \(t_d\) does not depend on \(\mathbf w\), so its derivative is 0.
    2. \(\mathbf w\T\mathbf x_d \)\({}= w_1x_{1,d} + w_2x_{2,d} + \dots\). Only the term \(w_ix_{i,d}\) contains \(w_i\).
    3. Its derivative is \(x_{i,d}\). With the minus sign in front, the result is \(-x_{i,d}\).
  4. So \(\frac{\partial E}{\partial w_i} \)\({}= \sum_d (t_d - o_d)(-x_{i,d})\). The \(\frac12\) cancelled the 2.
  5. Substitute into line 1. \(\Delta w_i \)\({}= \eta\sum_d (t_d - o_d)\,x_{i,d}\).

The rule is named after the error \(t - o\), often written \(\delta\) (delta). It is also called the LMS rule (least mean squares) or the Widrow–Hoff rule. It looks exactly like the perceptron rule. The difference is that \(o\) here is the real-valued sum, not its sign, so even a correctly classified sample moves the weights a little if \(o\) is not exactly \(t\).

Batch and incremental (stochastic) gradient descent

  • Batch gradient descent. Compute the gradient of the total error \(E_D \)\({}= \frac12\sum_{d\in D}(t_d - o_d)^2\) over the whole data set \(D\), then make one update. This is the delta rule as derived.
  • Incremental (stochastic) gradient descent. For each sample \(d\) in turn, compute the gradient of that sample's error \(E_d = \frac12(t_d - o_d)^2\) and update straight away, \(\Delta w_i \)\({}= \eta(t_d - o_d)x_{i,d}\). "Stochastic" means random. The samples are usually visited in a random order, so each step follows a noisy estimate of the true gradient.

With a small enough \(\eta\), the incremental version follows the batch version as closely as you like. Each incremental step is cheap, so in practice it often gets close to the minimum faster. Section 3.7 adds the middle ground, the mini-batch.

Example

Data \((x, t) = (1, 2)\) and \((2, 3)\), one weight, no bias, \(w = 1\), \(\eta = 0.1\).

Batch. The errors are \(2 - 1 = 1\) and \(3 - 2 = 1\). \(\Delta w \)\({}= 0.1\,(1\cdot1 + 1\cdot2) \)\({}= 0.3\). New \(w = 1.3\).

Incremental. Sample 1 gives \(\Delta w \)\({}= 0.1\cdot1\cdot1 \)\({}= 0.1\), so \(w = 1.1\). Sample 2 now has output \(2.2\) and error \(0.8\), so \(\Delta w \)\({}= 0.1\cdot0.8\cdot2 \)\({}= 0.16\), and \(w = 1.26\). Close to the batch value, but not equal, because the second step used the updated weight.

L14 slideIs \(E(\mathbf w) \)\({}= \frac12\sum_d (t_d - \mathbf w\T\mathbf x_d)^2\) convex with a single minimum?›

It is convex. Each term is the square of a linear function of \(\mathbf w\), and a sum of such squares is a quadratic bowl. Its matrix of second derivatives (the Hessian, 3.8) is \(\sum_d\mathbf x_d\mathbf x_d\T\), which is positive semi-definite because \(\mathbf z\T(\sum_d\mathbf x_d\mathbf x_d\T)\mathbf z \)\({}= \sum_d(\mathbf x_d\T\mathbf z)^2 \ge 0\).

The minimum value is unique. The minimising \(\mathbf w\) is unique when that matrix is invertible, which is the same condition as \(X\T X\) being invertible in the closed-form regression of page 1. If it is not (for example, fewer samples than weights), a whole line or plane of \(\mathbf w\) gives the same lowest error. For one sample with \(x = 2\), \(t = 4\), \(E(w) = 2(w - 2)^2\), a parabola with its lowest point at \(w = 2\).

3.4Multi-layer perceptrons

Lecture L15 · Short video: Neural networks basics

Stack layers of neurons, each feeding the next, with a nonlinear activation after each layer. The hidden layers build new features, and the last layer makes the prediction from them.

A multi-layer perceptron (MLP) has an input layer (the features, no computation), one or more hidden layers, and an output layer. "Hidden" means that these values are neither given in the data nor asked for as outputs. Successive layers are usually fully connected (dense). Each neuron sees every output of the layer before. L15 slide 12 lists the features of a typical MLP. It has nodes and edges, a layered structure, dense connections between successive layers, and few layers. It works as a classifier or a regressor on small hand-made features, and it often expands the features (a wide hidden layer) before classifying.

In matrix form, one layer computes \(\mathbf h \)\({}= \varphi(W\mathbf x + \mathbf b)\). Here \(W\) has one row per neuron of the layer, holding that neuron's weights, and \(\varphi\) is applied to each entry separately.

Why hidden layers, and why nonlinear activations

L15 slide 11 asks three questions.

  • Why hidden layers? One layer gives one linear boundary (3.2). A hidden layer can compute several boundaries and combine them, as the XOR network combined OR and AND. Each extra layer can combine the regions of the layer before.
  • Why nonlinear activations? Without them, two layers collapse into one. \(W_2(W_1\mathbf x) \)\({}= (W_2W_1)\mathbf x\), and \(W_2W_1\) is just another matrix. However many linear layers you stack, the whole network is still one linear map.
  • What do hidden layers do? They compute new features (a new representation) of the input, chosen by training so that the final layer's job becomes easy. This is the same idea as the feature transformation \(\mathbf x' = f(W, \mathbf x)\) on page 1, now learned instead of designed.

The universal approximation theorem

The theorem (L15 slide 14) says the following. Take a network with one hidden layer, any finite number of neurons in it, and a nonlinear activation that is not a polynomial (sigmoid and ReLU both qualify). Such a network can approximate any continuous function on a closed and bounded set of inputs as closely as you want, if you give it enough hidden neurons.

"Closed and bounded" (called compact) means the inputs stay in a finite region that includes its edge, such as \([0,1]^d\). The theorem says such a network exists. It does not say how many neurons you need (it can be huge), and it does not say gradient descent will find the weights.

Counting parameters, and writing the function out

Write this in the exam

    Why (5 steps)

The general count for a dense layer with \(n_{\text{in}}\) inputs and \(n_{\text{out}}\) neurons is \(n_{\text{out}}(n_{\text{in}} + 1)\). Add this over the layers.

Regression and classification outputs

Regression (L15 slide 15). The target is any real number, not something in \([0, 1]\) or \([-1, 1]\). So the output neuron uses the linear activation \(\varphi(z) = z\), and the loss is usually the squared error.

Classification (L15 slide 16). With \(K\) classes, use \(K\) output neurons, one per class. Taking the arg max (the index of the largest output) at the end gives a class but not a usable gradient, because a small change in the weights rarely changes which output is largest. So the slides add a softmax layer and use cross-entropy loss.

\[o_i = \operatorname{softmax}(\mathbf z)_i = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}},\]\[L(\mathbf o, \mathbf t) = -\sum_{i=1}^K t_i\log o_i.\]
Reading the formula

\(z_1, \dots, z_K\) are the raw outputs of the last layer, one per class, often called logits. \(e^{z_i}\) makes each one positive. Dividing by the total \(\sum_j e^{z_j}\) makes the \(K\) values add up to 1. So \(\mathbf o\) can be read as a probability for each class. The largest \(z_i\) still gets the largest \(o_i\), which is where the name "soft" max comes from.

\(\mathbf t\) is the target written as a probability vector. For a sample of class \(c\) it is 1 at position \(c\) and 0 elsewhere (one-hot). Then the sum has one surviving term and \(L = -\log o_c\). The loss is small when the network gives the true class a probability near 1, and large when it gives it a probability near 0. The minus sign makes the loss positive, since \(\log o_c \le 0\). L15 slide 16 drops the minus sign, which is a typo.

Example. \(\mathbf z = [2, 1, 0]\). \(e^2 = 7.389\), \(e^1 = 2.718\), \(e^0 = 1\), total \(11.107\). So \(\mathbf o \)\({}= [0.665, 0.245, 0.090]\), which adds to 1. If the true class is the first, \(L = -\ln 0.665 = 0.408\). If it were the third, \(L = -\ln 0.090 = 2.408\), much larger.

Link to KL divergence. The Kullback–Leibler (KL) divergence measures how different a distribution \(\mathbf o\) is from a distribution \(\mathbf t\). It is \(\mathrm{KL}(\mathbf t\,\|\,\mathbf o) \)\({}= \sum_i t_i\log\frac{t_i}{o_i}\). Split the log of the fraction into a difference.

\[\mathrm{KL}(\mathbf t\,\|\,\mathbf o) = \sum_i t_i\log t_i - \sum_i t_i\log o_i\]\[{}= -H(\mathbf t) + L(\mathbf o, \mathbf t).\]

\(H(\mathbf t) \)\({}= -\sum_i t_i\log t_i\) is the entropy of the targets. It does not depend on the network's weights, so minimising the cross-entropy and minimising the KL divergence give the same weights. For one-hot targets \(H(\mathbf t) = 0\) (using \(0\log0 = 0\)) and the two are equal.

With two classes and a single sigmoid output, softmax and cross-entropy reduce to logistic regression and the binary cross-entropy of page 2.

Going further, why the gradient of softmax with cross-entropy is \(\mathbf o - \mathbf t\)

For a one-hot target of class \(c\), \(L \)\({}= -\log o_c \)\({}= -z_c + \log\sum_j e^{z_j}\). Differentiate with respect to \(z_i\). The first term gives \(-1\) if \(i = c\) and 0 otherwise, which is \(-t_i\). The second gives \(\frac{e^{z_i}}{\sum_j e^{z_j}} \)\({}= o_i\). So \(\frac{\partial L}{\partial z_i} \)\({}= o_i - t_i\). In the example above with class 1 true, the gradient is \([0.665 - 1, 0.245, 0.090] \)\({}= [-0.335, 0.245, 0.090]\). This simple form is one reason the pair is used together.

Remember
  • Parameters of a dense layer \(= n_{\text{out}}(n_{\text{in}} + 1)\) with biases.
  • Without nonlinear activations, any stack of layers equals one linear layer.
  • Universal approximation needs only one hidden layer, but possibly very many neurons.
  • Regression uses a linear output and squared error. Classification uses softmax and cross-entropy \(-\sum_i t_i\log o_i\), which equals the KL divergence up to a constant.

Write this in the exam

Show that \(\sigma'(z) \)\({}= \sigma(z)(1 - \sigma(z))\).

  1. \(\sigma(z) = (1 + e^{-z})^{-1}\), so \(\sigma'(z) \)\({}= \frac{e^{-z}}{(1 + e^{-z})^2}\).
    Why (3 steps)
    1. Write the fraction as a power, \(\sigma = u^{-1}\) with \(u = 1 + e^{-z}\).
    2. Chain rule. \(\frac{d}{dz}u^{-1} \)\({}= -u^{-2}\,\frac{du}{dz}\).
    3. \(\frac{du}{dz} = -e^{-z}\). The two minus signs cancel, leaving \(\frac{e^{-z}}{(1 + e^{-z})^2}\).
  2. Split it. \(\sigma'(z) \)\({}= \frac1{1 + e^{-z}}\cdot\frac{e^{-z}}{1 + e^{-z}}\).
  3. The second factor is \(1 - \sigma(z)\), because \(1 - \frac1{1 + e^{-z}} \)\({}= \frac{e^{-z}}{1 + e^{-z}}\).
  4. So \(\sigma'(z) \)\({}= \sigma(z)(1 - \sigma(z))\).

This form is handy in backpropagation. Once the forward pass has computed \(o = \sigma(s)\), the derivative is just \(o(1 - o)\), with no new exponentials. At \(z = 0\), \(\sigma = 0.5\) and \(\sigma' = 0.25\), the largest it gets. At \(z = 4\), \(\sigma \approx 0.982\) and \(\sigma' \approx 0.018\). This flat region at both ends is called saturation.

The same method gives \(\tanh'(z) = 1 - \tanh^2 z\). Write \(\tanh = \frac{N}{D}\) with \(N = e^z - e^{-z}\), \(D = e^z + e^{-z}\). Then \(N' = D\) and \(D' = N\), so the quotient rule gives \(\frac{D\cdot D - N\cdot N}{D^2} \)\({}= 1 - \frac{N^2}{D^2}\). The two S-curves are related by \(\tanh(z) = 2\sigma(2z) - 1\) (the L11 problem). Check: \(2\cdot\frac1{1 + e^{-2z}} - 1 \)\({}= \frac{1 - e^{-2z}}{1 + e^{-2z}}\), and multiplying top and bottom by \(e^z\) gives \(\frac{e^z - e^{-z}}{e^z + e^{-z}}\).

Why ReLU helps with vanishing gradients (L17 slide 5)

Backpropagation (3.6) multiplies one activation derivative per layer. The sigmoid's derivative is at most 0.25. Through 10 sigmoid layers the product is at most \(0.25^{10} \)\({}\approx 9.5\times10^{-7}\), so the early layers get almost no gradient and barely learn. This is the vanishing gradient problem.

ReLU's derivative is exactly 1 for every positive input, so a chain of active ReLUs passes the gradient back unshrunk. Its weakness is that a neuron whose input is always negative has gradient 0 and stops learning (a "dead" ReLU). Leaky ReLU and ELU keep a small gradient there.

Remember
  • \(\sigma' \)\({}= \sigma(1 - \sigma) \le 0.25\). \(\tanh' = 1 - \tanh^2 \le 1\). ReLU' is 0 or 1.
  • \(\tanh(z) = 2\sigma(2z) - 1\).
  • S-shaped activations saturate and cause vanishing gradients in deep networks. ReLU does not saturate for positive inputs.

3.6Backpropagation

Lectures L16 and L17

Backpropagation computes the gradient of the loss with respect to every weight by applying the chain rule from the loss backwards, layer by layer, reusing the products it has already computed.

Training an MLP is still gradient descent, \(\theta \leftarrow \theta - \eta\frac{\partial L}{\partial\theta}\) for every weight \(\theta\). The only hard part is computing \(\frac{\partial L}{\partial\theta}\) for weights deep inside the network. The method is called backpropagation (backprop) because the error signal travels from the output back towards the input.

The network has two inputs \(x_1, x_2\), two hidden sigmoid neurons and one sigmoid output, then a squared-error loss against the target \(y\). There are no biases, to keep it small. In five steps, each the input of the next,

\[\mathbf p = W\mathbf x,\quad \mathbf q = \sigma(\mathbf p),\quad s = \mathbf u\T\mathbf q,\]\[o = \sigma(s),\quad L = (o - y)^2.\]
Reading the formula

\(W = \begin{bmatrix}w_{11} & w_{12}\\ w_{21} & w_{22}\end{bmatrix}\), so \(p_1 = w_{11}x_1 + w_{12}x_2\) and \(p_2 = w_{21}x_1 + w_{22}x_2\). The weight \(w_{jk}\) goes from input \(k\) to hidden neuron \(j\).

\(\mathbf q \)\({}= [\sigma(p_1), \sigma(p_2)]\T\) are the hidden outputs. \(\mathbf u = [u_1, u_2]\T\) are the output weights, so \(s = u_1q_1 + u_2q_2\). The learnable parameters are \(W\) and \(\mathbf u\), six numbers. The steps \(\sigma\) and the loss have no parameters.

Seeing the network as a chain of blocks, each taking the previous block's output, is the computational graph view (L16 slide 5). Softmax, activations and the loss are all just blocks.

The chain rule, one weight at a time

The chain rule (basics page) says that if \(L\) depends on \(o\), which depends on \(s\), then \(\frac{\partial L}{\partial s} \)\({}= \frac{\partial L}{\partial o}\cdot\frac{\partial o}{\partial s}\). Follow the path from \(L\) back to the weight you want and multiply the derivative of each step.

Write this in the exam

Find \(\frac{\partial L}{\partial u_j}\) and \(\frac{\partial L}{\partial w_{jk}}\) for \(L = (o - y)^2\), \(o \)\({}= \sigma(\mathbf u\T\sigma(W\mathbf x))\).

  1. \(\frac{\partial L}{\partial o} \)\({}= 2(o - y)\).
  2. \(\delta_s \)\({}= \frac{\partial L}{\partial s}\)\({}= 2(o - y)\,o(1 - o)\).
    Why (3 steps)
    1. Chain rule. \(\frac{\partial L}{\partial s} \)\({}= \frac{\partial L}{\partial o}\cdot\frac{\partial o}{\partial s}\).
    2. \(o = \sigma(s)\), so \(\frac{\partial o}{\partial s} \)\({}= \sigma'(s) \)\({}= \sigma(s)(1 - \sigma(s)) \)\({}= o(1 - o)\) (3.5).
    3. Multiply by line 1. The name \(\delta_s\) is shorthand for this number, which is used again below.
  3. \(\frac{\partial L}{\partial u_j} \)\({}= \delta_s\,q_j\).
    Why (2 steps)
    1. \(s = u_1q_1 + u_2q_2\), so \(\frac{\partial s}{\partial u_j} \)\({}= q_j\).
    2. Chain rule. \(\frac{\partial L}{\partial u_j} \)\({}= \frac{\partial L}{\partial s}\cdot\frac{\partial s}{\partial u_j} \)\({}= \delta_s\,q_j\).
  4. \(\delta_j \)\({}= \frac{\partial L}{\partial p_j}\)\({}= \delta_s\,u_j\,q_j(1 - q_j)\).
    Why (4 steps)
    1. \(p_j\) affects \(L\) only through \(q_j\), then \(s\). So \(\frac{\partial L}{\partial p_j} \)\({}= \frac{\partial L}{\partial s}\cdot\frac{\partial s}{\partial q_j}\cdot\frac{\partial q_j}{\partial p_j}\).
    2. \(s = u_1q_1 + u_2q_2\), so \(\frac{\partial s}{\partial q_j} \)\({}= u_j\).
    3. \(q_j = \sigma(p_j)\), so \(\frac{\partial q_j}{\partial p_j} \)\({}= q_j(1 - q_j)\).
    4. Multiply the three, with \(\frac{\partial L}{\partial s} \)\({}= \delta_s\) from line 2.
  5. \(\frac{\partial L}{\partial w_{jk}} \)\({}= \delta_j\,x_k\).
    Why (2 steps)
    1. \(p_j = w_{j1}x_1 + w_{j2}x_2\), so \(\frac{\partial p_j}{\partial w_{jk}} \)\({}= x_k\).
    2. Chain rule. \(\frac{\partial L}{\partial w_{jk}} \)\({}= \frac{\partial L}{\partial p_j}\cdot\frac{\partial p_j}{\partial w_{jk}} \)\({}= \delta_j\,x_k\).
  6. Written out for \(w_{11}\), \(\frac{\partial L}{\partial w_{11}} \)\({}= 2(o - y)\,\sigma'(s)\,u_1\,\sigma'(p_1)\,x_1\), as on L16 slide 7.

Reusing the products

Look at the lines above. \(\delta_s\) is used in line 3 for both \(u_1\) and \(u_2\), and again inside both \(\delta_1\) and \(\delta_2\). \(\delta_1\) is then used for both \(w_{11}\) and \(w_{12}\). Going backwards, each new derivative is the previous one times one local factor, so nothing is computed twice. Starting from each weight separately and multiplying the whole path would repeat the same products many times. For a network with millions of weights, computing backwards makes the gradient cost about the same as one forward pass.

L16 slide 13 states the rule every block must follow. For each block with input \(\mathbf x\) and output \(\mathbf p\), you need two things.

  • How the output depends on the input, so the gradient can be passed further back. \(\frac{\partial L}{\partial\mathbf x} \)\({}= \frac{\partial L}{\partial\mathbf p}\cdot\frac{\partial\mathbf p}{\partial\mathbf x}\).
  • If the block has weights, how the output depends on them, so they can be updated. \(\frac{\partial L}{\partial\mathbf w} \)\({}= \frac{\partial L}{\partial\mathbf p}\cdot\frac{\partial\mathbf p}{\partial\mathbf w}\).

A full numeric pass

The numbers below were chosen to keep the arithmetic short. Take \(\mathbf x = [1, 2]\T\), \(y = 1\), \(W = \begin{bmatrix}1 & -0.5\\ -2 & 1\end{bmatrix}\), \(\mathbf u = [1, -1]\T\) and \(\eta = 0.5\).

Example

Forward pass.

  1. \(p_1 \)\({}= 1\cdot1 + (-0.5)\cdot2 \)\({}= 0\). \(p_2 = -2\cdot1 + 1\cdot2 = 0\).
  2. \(q_1 = \sigma(0) = 0.5\), \(q_2 = 0.5\).
  3. \(s \)\({}= 1\cdot0.5 + (-1)\cdot0.5 \)\({}= 0\).
  4. \(o = \sigma(0) = 0.5\).
  5. \(L = (0.5 - 1)^2 = 0.25\).

Backward pass.

The training loop

L16 and L17 put it together as an algorithm.

  1. Initialise the weights \(W^0\) (randomly, see 3.7).
  2. Forward pass. Take a mini-batch \(B\) of randomly chosen samples and compute their outputs \(o_i = f(W, \mathbf x_i)\).
  3. Compute the loss \(L \)\({}= \frac1{|B|}\sum_{i\in B} L(o_i, y_i)\), the average over the batch. \(|B|\) is the number of samples in the batch.
  4. Backward pass. Compute every \(\frac{\partial L}{\partial W}\) and update \(W^{k+1} \)\({}= W^k - \eta\frac{\partial L}{\partial W^k}\).
  5. Repeat steps 2 to 4 until the loss is acceptable.

Vanishing and exploding gradients, and zero initialisation

The gradient for an early weight is a product of one factor per layer (line 6 of the box). If those factors are mostly below 1, the product shrinks towards 0 with depth, which is the vanishing gradient problem. If they are mostly above 1 (large weights), it grows without bound, which is the exploding gradient problem. Section 3.5 showed the sigmoid case. L19 lists the remedies taught in the course. They are ReLU-type activations, careful initialisation, normalisation, and residual (skip) connections, which come in the CNN part of page 4.

Why not start with all weights zero or equal? (L16 and L17 problem.) If every hidden neuron starts with the same weights, they all compute the same output and, by line 4, receive the same gradient. They stay identical after every update, so the layer behaves like a single neuron however wide it is. This is called the symmetry problem, and random initialisation breaks it. With all weights exactly zero it is worse. In our network \(\mathbf u = \mathbf 0\) makes \(\delta_j \)\({}= \delta_s u_j q_j(1-q_j) \)\({}= 0\), so \(W\) never changes at all.

Remember
  • \(\delta_s = 2(o - y)\,o(1 - o)\), \(\frac{\partial L}{\partial u_j} \)\({}= \delta_s q_j\), \(\delta_j \)\({}= \delta_s u_j q_j(1 - q_j)\), \(\frac{\partial L}{\partial w_{jk}} \)\({}= \delta_j x_k\).
  • Gradient of a weight = (gradient arriving at the block's output) × (local derivative). Compute backwards so each product is reused.
  • Vanishing or exploding gradients come from long products of per-layer factors. Equal initial weights never break symmetry.

3.7Training in practice

Lectures L17 and L18 · Short video: Introduction to PyTorch

Plain backpropagation with full-batch gradient descent works on paper but is slow and fragile. L17 and L18 list the changes that make it practical.

L17 slide 6 frames it as four places where the simple algorithm can change. The initialisation can be smarter, because the loss is non-convex and the starting point matters. The gradient can be estimated from part of the data instead of all of it. The loss can include extra terms that reduce overfitting. And the update rule itself can change.

Initialisation and pretraining

  • Random. Small random values break the symmetry problem of 3.6.
  • Xavier (Glorot). Choose the spread of the random weights so that the variance of the activations, and of the gradients, stays about the same from layer to layer. Then signals neither die out nor blow up with depth. The usual choice is mean 0 and variance \(\frac1{n_{\text{in}}}\), or \(\frac2{n_{\text{in}} + n_{\text{out}}}\), where \(n_{\text{in}}\) (the fan-in) is the number of inputs to the neuron and \(n_{\text{out}}\) (the fan-out) the number of outputs. It suits sigmoid and tanh.
  • He. The same idea for ReLU, with variance \(\frac2{n_{\text{in}}}\). The extra factor 2 makes up for ReLU setting about half of its inputs to zero.

The exact formulas were left as homework on L17 slide 8 ("find out exact equations"), so the ones above are the standard ones from the original papers.

Pretraining (L18) is initialisation by learning. Train the network first on a large related data set or related task, then start the real training from those weights and adjust them (fine-tuning). The early layers usually carry over best, because they learn general features. Using the knowledge from one task on another is called transfer learning. Pretraining can also be unsupervised, for example with an autoencoder or by predicting the next word, which leads into self-supervised learning on page 4.

Batches, epochs and iterations

  • Batch gradient descent. Use all \(N\) samples for each update. Accurate but slow.
  • Stochastic gradient descent. Use one sample per update. Fast but noisy.
  • Mini-batch stochastic gradient descent. Use a random batch of, say, 32 to 512 samples. This is what is used in practice. The loss on a batch is a cheap estimate of the loss on all the data, and the estimate is good enough to point downhill.
\[\text{iterations per epoch} = \frac{\text{samples}}{\text{batch size}}.\]

With 50,000 samples and batch size 128 this is \(390.625\). So one epoch is 391 iterations if the last, smaller batch of \(50{,}000 - 390\times128 = 80\) samples is used, or 390 if it is dropped.

Learning rate and its schedule

Too large a learning rate overshoots the minimum and can diverge. Too small a rate makes progress slow. A common answer is to start larger and reduce it as training goes on. A scheduler does this automatically. Step decay divides \(\eta\) by a constant every few epochs. Exponential decay multiplies it by a factor below 1 every epoch. Cosine annealing lowers it along half a cosine curve. Reduce on plateau lowers it when the validation loss stops improving. One-cycle raises it and then lowers it again.

Momentum

\[\Delta\theta^k = \eta\,\frac{\partial L}{\partial\theta} + \gamma\,\Delta\theta^{k-1},\]\[\theta^{k+1} = \theta^k - \Delta\theta^k.\]
Reading the formula

\(\gamma\) (gamma) is the momentum coefficient, typically 0.9. Each step is the usual gradient step plus 0.9 of the previous step. The name comes from physics. A ball rolling downhill keeps some of its velocity.

When successive gradients point the same way, the steps add up and grow, so travel along a long gentle slope speeds up. When the gradients alternate in sign (zig-zagging across a narrow valley), the alternating parts cancel.

Example. \(L(w) = w^2\), so \(\frac{dL}{dw} = 2w\). Start at \(w = 1\) with \(\eta = 0.1\), \(\gamma = 0.9\) and \(\Delta = 0\).

  1. Gradient 2. \(\Delta = 0.1\cdot2 + 0 = 0.2\). \(w = 0.8\).
  2. Gradient 1.6. \(\Delta \)\({}= 0.16 + 0.9\cdot0.2 \)\({}= 0.34\). \(w = 0.46\).
  3. Gradient 0.92. \(\Delta \)\({}= 0.092 + 0.9\cdot0.34 \)\({}= 0.398\). \(w = 0.062\).

Plain gradient descent with the same \(\eta\) multiplies \(w\) by 0.8 each step, giving 0.8, 0.64 and 0.512. Momentum is much further along after three steps. (It will overshoot past 0 next, which is the price of the speed.)

Regularisation, batch normalisation, dropout and early stopping

Regularisation (L17 slide 14). Add a penalty to the loss, \(L' = L + \lambda\|\mathbf w\|\), using the L1 or L2 norm as on page 1. Other ways to fight overfitting are more data (or data augmentation, making new training samples by flipping, cropping or adding noise to old ones, so there is more data per parameter) and adding noise to the inputs, outputs or weights.

Batch normalisation. We normalise the input data before training. But the inputs to each hidden layer keep changing their distribution as the earlier layers' weights change. The slides call this the internal covariate shift. Batch normalisation normalises each hidden neuron's input over the current mini-batch.

\[\mu_B = \frac1m\sum_{i=1}^m x_i,\]\[\sigma_B^2 = \frac1m\sum_{i=1}^m (x_i - \mu_B)^2,\]\[\hat x_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}},\]\[y_i = \gamma\hat x_i + \beta.\]
Reading the formula

\(m\) is the batch size and \(x_1, \dots, x_m\) are one neuron's inputs over the batch. \(\mu_B\) and \(\sigma_B^2\) are their mean and variance. \(\hat x_i\) has mean 0 and variance 1. \(\epsilon\) is a tiny number such as \(10^{-5}\) that avoids dividing by zero. \(\gamma\) and \(\beta\) are learned, so the network can rescale and shift the result, or even undo the normalisation if that helps.

Example. Batch \(1, 2, 3, 6\). Mean \(\mu_B = 12/4 = 3\). Variance \(\frac{4 + 1 + 0 + 9}4 = 3.5\), standard deviation \(1.871\). Normalised values \(-1.069, -0.535, 0, 1.604\), which have mean 0. With \(\gamma = 1\), \(\beta = 0\) these are the outputs.

At test time (the L18 question) there may be only one sample, so there is no batch to average over. The network uses a running average of \(\mu_B\) and \(\sigma_B^2\) collected during training.

Dropout. During training, set each hidden neuron's output to zero with probability \(p\) (say 0.5), choosing afresh for every training step. A dropped neuron takes no part in that forward pass or in backpropagation. Each step therefore trains a different thinned network, and all of these networks share the same weights, so the result acts like an average of many networks. Because a neuron cannot rely on any particular other neuron being present, it has to learn features that are useful on their own. The slides describe this as reducing complex co-adaptations.

Common mistake

At test time all neurons are kept, so each neuron receives more input than it did during training. Its outputs must be scaled by the probability of keeping a neuron, \(1 - p\), if \(p\) is the drop probability. The slides say "scale outputs by \(p\)". That matches the original paper, where \(p\) is the probability of keeping. With \(p = 0.5\) the two readings agree. (Modern libraries instead divide by \(1 - p\) during training and do nothing at test time, which has the same effect.)

Early stopping. Watch the loss on a validation set during training. The training loss keeps falling, but at some point the validation loss stops falling and starts to rise, which means the network has begun to fit noise in the training data (overfitting, page 2). Stop there and keep the weights from the best validation point.

The L17 closing question asks whether training long enough always reaches zero loss. Not necessarily. Gradient descent on a non-convex loss can stop at a local minimum or a flat region. If the network is large enough to memorise the training set it may reach near-zero training loss, but that is overfitting, and the loss on new data is what matters.

Remember
  • Xavier variance \(\approx 1/n_{\text{in}}\) for sigmoid and tanh. He variance \(2/n_{\text{in}}\) for ReLU.
  • Iterations per epoch = samples / batch size.
  • Momentum \(\Delta\theta^k \)\({}= \eta\nabla L + \gamma\Delta\theta^{k-1}\).
  • Batch norm normalises over the mini-batch, then applies a learned \(\gamma, \beta\). It uses running averages at test time.
  • Dropout removes neurons at random during training and rescales at test time.

3.8Why gradient descent works, Newton's method and Adam

Lecture L18 · the second order methods part of the Quiz 2 syllabus

A Taylor expansion of the loss around the current weights shows that a small step against the gradient always lowers the loss. Adding the second derivative (the Hessian) gives the best step size and Newton's method. Adam is the practical compromise.

Gradient, Hessian and Jacobian

For a function \(f(x_1, \dots, x_n)\) that returns one number,

  • the gradient \(\nabla f\) is the column of first partial derivatives, \(\big[\frac{\partial f}{\partial x_1}, \dots, \frac{\partial f}{\partial x_n}\big]\T\). It points in the direction of steepest increase.
  • the Hessian \(H\) is the \(n\times n\) matrix of second partial derivatives, \(H_{ij} \)\({}= \frac{\partial^2f}{\partial x_i\,\partial x_j}\). It describes how the slope itself changes, that is, the curvature. It is symmetric for the smooth functions we meet.

For a function \(\mathbf f\) that returns \(m\) numbers \(f_1, \dots, f_m\), the Jacobian \(J\) is the \(m\times n\) matrix \(J_{ij} \)\({}= \frac{\partial f_i}{\partial x_j}\), one row per output. The Hessian of \(f\) is the Jacobian of its gradient.

Example

\(f(x, y) = x^2 + 3xy + y^2\). The gradient is \([2x + 3y,\ 3x + 2y]\T\). The Hessian is \(\begin{bmatrix}2 & 3\\ 3 & 2\end{bmatrix}\), the same at every point because \(f\) is quadratic.

\(\mathbf f(x, y) = (xy,\ x + y)\). The Jacobian is \(\begin{bmatrix}y & x\\ 1 & 1\end{bmatrix}\).

The Taylor expansion

In one variable, \(f(x + h) \)\({}= f(x) + hf'(x) + \frac{h^2}2f''(x) + \dots\). The same idea for a vector of weights \(\mathbf w\) and a small step \(\mathbf s\) is

\[J(\mathbf w + \mathbf s) \approx J(\mathbf w) + \mathbf s\T\nabla J + \tfrac12\,\mathbf s\T H\,\mathbf s.\]
Reading the formula

\(J\) here is the loss (the L18 slides call it \(J\)). Do not confuse it with the Jacobian matrix. \(\nabla J\) and \(H\) are evaluated at the current \(\mathbf w\).

\(\mathbf s\T\nabla J\) is the first-order change, the slope times the step, added up over the directions. \(\frac12\mathbf s\T H\mathbf s\) is the second-order correction for curvature, like \(\frac{h^2}2f''\).

Example. \(J(w) = w^2\) at \(w = 1\), step \(s = -0.2\). Here \(\nabla J = 2\) and \(H = 2\). The formula gives \(1 + (-0.2)(2) + \frac12(0.04)(2) \)\({}= 1 - 0.4 + 0.04 \)\({}= 0.64\), which is exactly \(0.8^2\), because \(J\) is quadratic and the higher terms are zero.

Write this in the exam

Show that a small gradient descent step does not increase \(J\), and find the best learning rate.

  1. The update is \(\mathbf s \)\({}= \mathbf w^{k+1} - \mathbf w^k \)\({}= -\eta\nabla J\).
  2. First order. \(J(\mathbf w^{k+1}) \)\({}\approx J(\mathbf w^k) - \eta\,\nabla J\T\nabla J\)\({}= J(\mathbf w^k) - \eta\|\nabla J\|^2\).
    Why (3 steps)
    1. Keep only the first two terms of the Taylor expansion. \(J(\mathbf w + \mathbf s) \)\({}\approx J(\mathbf w) + \mathbf s\T\nabla J\).
    2. Substitute \(\mathbf s = -\eta\nabla J\). The change is \(-\eta\,\nabla J\T\nabla J\).
    3. \(\nabla J\T\nabla J\) is the sum of the squared entries of the gradient, \(\|\nabla J\|^2\).
  3. \(\|\nabla J\|^2 \ge 0\) and \(\eta > 0\), so \(J\) does not increase. It stays the same only where \(\nabla J = \mathbf 0\), where the iterations stop.
  4. Second order. \(J(\mathbf w^{k+1}) \)\({}\approx J(\mathbf w^k) - \eta\|\nabla J\|^2 + \frac{\eta^2}2\nabla J\T H\nabla J\).
    Why (2 steps)
    1. Keep the third Taylor term \(\frac12\mathbf s\T H\mathbf s\).
    2. Substitute \(\mathbf s = -\eta\nabla J\). \(\frac12(-\eta\nabla J)\T H(-\eta\nabla J) \)\({}= \frac{\eta^2}2\nabla J\T H\nabla J\), since the two minus signs multiply to plus.
  5. Differentiate with respect to \(\eta\) and set to zero. \(-\|\nabla J\|^2 + \eta\,\nabla J\T H\nabla J \)\({}= 0\).
  6. So \[\eta^* = \frac{\|\nabla J\|^2}{\nabla J\T H\,\nabla J}.\]

The best \(\eta\) changes every iteration, because \(\nabla J\) and \(H\) depend on \(\mathbf w^k\). Line 3 only holds for small \(\eta\). With a large \(\eta\) the neglected terms take over, and the step can overshoot and increase \(J\).

Why the negative gradient? (L18 slide 16.) For a unit direction \(\mathbf u\), the first-order change in \(J\) is \(\mathbf u\T\nabla J \)\({}= \|\mathbf u\|\,\|\nabla J\|\cos\theta \)\({}= \|\nabla J\|\cos\theta\), where \(\theta\) is the angle between \(\mathbf u\) and \(\nabla J\). This is most negative when \(\cos\theta = -1\), that is, when \(\mathbf u\) points opposite to the gradient. That is why gradient descent is also called steepest descent.

Newton's method

Write this in the exam

Derive Newton's update \(\mathbf w^{k+1} \)\({}= \mathbf w^k - H^{-1}\nabla J\).

  1. Choose the step \(\mathbf s\) to minimise the second-order model \(J(\mathbf w) + \mathbf s\T\nabla J + \frac12\mathbf s\T H\mathbf s\).
  2. Its gradient with respect to \(\mathbf s\) is \(\nabla J + H\mathbf s\). Set it to zero.
    Why (3 steps)
    1. \(J(\mathbf w)\) does not depend on \(\mathbf s\), so its derivative is 0.
    2. The derivative of \(\mathbf s\T\mathbf g\) with respect to \(\mathbf s\) is \(\mathbf g\), here \(\nabla J\).
    3. The derivative of \(\frac12\mathbf s\T H\mathbf s\) is \(H\mathbf s\) when \(H\) is symmetric (basics page, gradient).
  3. So \(H\mathbf s = -\nabla J\) and \(\mathbf s = -H^{-1}\nabla J\).
  4. Update \(\mathbf w^{k+1} \)\({}= \mathbf w^k - H^{-1}\nabla J\).

The gradient gives the direction. The Hessian says how far to trust it. On a steeply curved loss \(H\) is large and the step is short, and on a flat one the step is long. For a quadratic loss, the second-order model is exact, so one Newton step lands on the minimum. Near a minimum, Newton's method converges quadratically, meaning that the number of correct digits roughly doubles each step.

The drawbacks are listed on this slide. At a saddle point, \(H\) has negative eigenvalues, and along those directions Newton steps go uphill. The fix is \(\mathbf w^{k+1} \)\({}= \mathbf w^k - (H + \alpha I)^{-1}\nabla J\), where \(I\) is the identity matrix. As \(\alpha\) grows, \(H + \alpha I\) is dominated by \(\alpha I\), and the update tends to \(-\frac1\alpha\nabla J\), plain gradient descent with learning rate \(\frac1\alpha\). Also, \(H\) has \(d\times d\) entries for \(d\) weights. A network with a million weights would need a matrix of \(10^{12}\) numbers and its inverse, which is far too costly. So networks use first-order methods.

Adam

Write \(\mathbf g_t \)\({}= \nabla J(\mathbf w_t)\) for the gradient at step \(t\). All operations below act on each weight separately (squares and square roots are taken entry by entry).

  1. Momentum as a moving average. \(\mathbf m_t \)\({}= \beta_1\mathbf m_{t-1} + (1 - \beta_1)\mathbf g_t\). This is an exponential moving average of the gradients. Each new gradient gets weight \(1 - \beta_1\) and older ones fade by a factor \(\beta_1\) per step. It smooths the direction and reduces zig-zag.
  2. Adaptive step per weight. \(\mathbf v_t \)\({}= \beta_2\mathbf v_{t-1} + (1 - \beta_2)\mathbf g_t^2\) is a moving average of the squared gradients. Dividing the step by \(\sqrt{\mathbf v_t}\) gives weights with large gradients smaller steps and weights with small gradients larger steps. This idea alone is called RMSProp.
  3. Adam ("adaptive moment estimation") combines the two and adds a bias correction.
\[\hat{\mathbf m}_t = \frac{\mathbf m_t}{1 - \beta_1^t},\qquad \hat{\mathbf v}_t = \frac{\mathbf v_t}{1 - \beta_2^t},\]\[\mathbf w_{t+1} = \mathbf w_t - \eta\,\frac{\hat{\mathbf m}_t}{\sqrt{\hat{\mathbf v}_t} + \epsilon}.\]
Reading the formula

\(\mathbf m\) estimates the mean of the gradient (its first moment) and \(\mathbf v\) the mean of its square (the second moment). Both start at 0, so in the first few steps they are pulled towards 0. Dividing by \(1 - \beta^t\) corrects this. \(\beta^t\) is \(\beta\) to the power \(t\), the step number, so the correction fades as \(t\) grows.

The default settings from the Adam paper (on L18 slide 20) are \(\eta = 0.001\), \(\beta_1 = 0.9\), \(\beta_2 = 0.999\), \(\epsilon = 10^{-8}\). \(\epsilon\) only stops division by zero.

Example, first step. Take one weight with gradient \(g_1 = 0.5\) and \(m_0 = v_0 = 0\).

  1. \(m_1 \)\({}= 0.9\cdot0 + 0.1\cdot0.5 \)\({}= 0.05\). \(v_1 \)\({}= 0.999\cdot0 + 0.001\cdot0.25 \)\({}= 0.00025\).
  2. Bias correction. \(\hat m_1 \)\({}= 0.05/(1 - 0.9) \)\({}= 0.5\). \(\hat v_1 \)\({}= 0.00025/(1 - 0.999) \)\({}= 0.25\).
  3. Step size \(\eta\cdot\frac{0.5}{\sqrt{0.25}} \)\({}= \eta\cdot\frac{0.5}{0.5} \)\({}= \eta\), ignoring \(\epsilon\).

So the first step moves the weight by exactly \(\eta\) against the sign of the gradient, whatever the gradient's size. Without the bias correction it would be \(\eta\cdot\frac{0.05}{0.0158} \)\({}\approx 3.16\eta\).

Remember
  • Taylor \(J(\mathbf w + \mathbf s) \)\({}\approx J + \mathbf s\T\nabla J + \frac12\mathbf s\T H\mathbf s\).
  • Gradient step lowers \(J\) by about \(\eta\|\nabla J\|^2\). Best rate \(\eta^* \)\({}= \frac{\|\nabla J\|^2}{\nabla J\T H\nabla J}\).
  • Newton \(\mathbf w \leftarrow \mathbf w - H^{-1}\nabla J\). One step for a quadratic. Regularised \((H + \alpha I)^{-1}\). Too costly for big networks.
  • Adam combines momentum (\(\mathbf m\)) with per-weight scaling (\(\mathbf v\)) and bias correction. Defaults 0.001, 0.9, 0.999, \(10^{-8}\).

Question 1, brief answers (15 points)

Quiz 2, 2026Q1(a), 3 points. True or false, with a reason. (i) Backpropagation, implemented properly, always reaches the global minimum. (ii) Backpropagation works well when all weights start at zero. (iii) Residual (skip) connections reduce the vanishing gradient problem in deep networks.›
Formula
No formula. Check each statement on its own.
Where it comes from
3.6 Backpropagation (vanishing gradients, zero initialisation) and 3.7 Training in practice. Skip connections are taught in 4, ResNet.
Working
  1. (i) False. Backpropagation only computes gradients, and gradient descent follows them downhill. The loss of a network with hidden layers is not convex, so the descent can stop at a local minimum or a saddle point.
  2. (ii) False. With equal (for example zero) weights every hidden unit computes the same thing and receives the same gradient, so they stay identical for ever. This is the symmetry problem of 3.6. With all weights zero the hidden-layer gradients are exactly zero.
  3. (iii) True. A skip connection adds the input of a block to its output, \(y = x + F(x)\). Then \(\frac{\partial y}{\partial x} \)\({}= 1 + F'(x)\), so the gradient always has a direct path of factor 1 back through the block and does not shrink layer after layer.
Marks
1 point per statement. The other variants asked the same kind of statements (backpropagation is useful only for convex problems, it never reaches a global minimum, XOR needs more than one layer, an L1 penalty gives sparse weights, cross-entropy is for regression, dropout compresses the model). See the table at the end.
Quiz 2, 2026Q1(b), 3 points. Write the update equations for (i) plain gradient descent, (ii) gradient descent with momentum and (iii) Newton's method. Define every symbol.›
Formula

(i) Plain gradient descent.

\[\mathbf w^{k+1} = \mathbf w^k - \eta\,\nabla L(\mathbf w^k)\]

(ii) Momentum.

\[\mathbf v^{k+1} = \beta\,\mathbf v^k - \eta\,\nabla L(\mathbf w^k),\]\[\mathbf w^{k+1} = \mathbf w^k + \mathbf v^{k+1}\]

(iii) Newton's method.

\[\mathbf w^{k+1} = \mathbf w^k - \big(H^k\big)^{-1}\nabla L(\mathbf w^k)\]
Where it comes from
3.3 for plain gradient descent, 3.7, momentum, and 3.8, Newton's method.
Working
  1. Symbols. \(\mathbf w^k\) is the weight vector after \(k\) updates. \(\eta > 0\) is the learning rate. \(\nabla_{\mathbf w}L(\mathbf w^k)\) is the gradient of the loss at \(\mathbf w^k\).
  2. For momentum, \(\mathbf v^k\) is the velocity, the running step, which starts at \(\mathbf 0\). \(\beta\) is the momentum coefficient, between 0 and 1 (usually 0.9).
  3. The form in 3.7, \(\Delta\theta^k \)\({}= \eta\nabla L + \gamma\Delta\theta^{k-1}\) with \(\theta^{k+1} \)\({}= \theta^k - \Delta\theta^k\), is the same rule with \(\mathbf v = -\Delta\theta\) and \(\beta = \gamma\).
  4. For Newton, \(H^k\) is the Hessian of the loss at \(\mathbf w^k\), the matrix of second derivatives \(H_{ij} \)\({}= \frac{\partial^2L}{\partial w_i\,\partial w_j}\).
Marks
1 point each. Plain gradient descent needs the minus sign, the \(k\) to \(k+1\) indices and the symbols defined (0.5 if symbols are missing, 0 for the wrong sign). Momentum needs both equations, and either the velocity form above or the form \(\mathbf v^{k+1} \)\({}= \beta\mathbf v^k + \nabla L\), \(\mathbf w^{k+1} \)\({}= \mathbf w^k - \eta\mathbf v^{k+1}\) gets full marks (0.5 for one equation). Practice5 (3 points, one, none or more correct). Which are true? (a) A single layer perceptron can learn XOR. (b) Without nonlinear activations an MLP of any depth is a linear map. Working

Where it comes from

Working
