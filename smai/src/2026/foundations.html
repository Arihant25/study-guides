Part 1L01 · Data driven problem solving

1.1Data, representation and the learning problem

Lecture L01 · Short video: How can data be useful? · Representation · Representation II · Supervised learning formulation · Read: Mathematics for Machine Learning (free book)

Machine learning writes a program from examples instead of by hand.

In ordinary programming, a person writes the program, the computer runs it on data and produces an output. In machine learning, the computer is given data together with the outputs we want, and it produces the program. The slide below shows this swap.

The setup in symbols

We are given a dataset \(D = \{(\mathbf x_i, y_i)\}\), \(i = 1, \dots, N\). Each \(\mathbf x_i\) is one example, written as a list of \(d\) numbers. Each \(y_i\) is the answer we want for it, called its label. \(N\) is the number of examples.

The learned program is a function

\[ y = f(\mathbf W, \mathbf x). \]
Reading the formula

\(\mathbf x\) is the input, \(y\) is the output, and \(f\) is the form of the program we chose (for example "a straight line" or "a neural network"). \(\mathbf W\) holds the numbers inside \(f\) that are not fixed in advance. They are called the learnable parameters or weights. "Learning" means finding good values of \(\mathbf W\) from \(D\).

Example. Take \(f(\mathbf W, x) = w_1 x + w_2\), a straight line, with \(\mathbf W = [w_1, w_2]\). If the data are \((1,2), (2,3), (3,4)\), learning should find \(w_1 = 1\), \(w_2 = 1\), because then \(f\) gives \(2, 3, 4\) for \(x = 1, 2, 3\). Section 1.6 shows how to find these values.

Representation, turning things into vectors

Before any learning, each object (an email, a fruit, a day, an image) must become a vector \(\mathbf x \in \R^d\). The symbol \(\R^d\) means "a list of \(d\) real numbers". Each entry is called a feature or attribute. The slides stress that this step decides most of the outcome, hence "representation is the key".

  • An orange and an apple on a conveyor belt could be described by \(\mathbf x \)\({}= [\text{redness}, \text{diameter in cm}]\).
  • A day for a picnic could be \(\mathbf x \)\({}= [\text{temperature}, \text{humidity}, \text{chance of rain}]\).
  • An email for spam filtering could be a vector of word counts, one entry per word in a fixed vocabulary (the bag of words in section 1.10).

Features can be hand-designed, read from a sensor (a thermometer), computed with statistics or signal processing, or learned by another model such as a neural network.

The inputs can be single vectors or sequences of vectors (speech, text).

  • Supervised learning has a label \(y_i\) for every example. Most of this course is supervised.
  • Unsupervised learning has no labels, for example grouping similar points (clustering).
  • Self-supervised learning makes labels out of the data itself, for example hiding a word and predicting it.
  • Semi-supervised learning has labels for only some examples.
  • Reinforcement learning acts in an environment and receives rewards instead of labels.

Training, validation and testing

The data are split. The training set is used to compute \(\mathbf W\). The test set is kept aside and used only to measure how well the result works on examples it has not seen. A validation set is a third part used to choose settings (such as \(K\) in k-NN) without touching the test set. Measuring on the training set alone would be like marking a student on questions they were shown with answers.

Remember
  • Learning finds \(\mathbf W\) in \(y = f(\mathbf W, \mathbf x)\) from \(D \)\({}= \{(\mathbf x_i, y_i)\}_{i=1}^N\).
  • Each example is a vector \(\mathbf x \in \R^d\). Choosing the features is the representation problem.
  • Regression predicts a number, classification predicts a class.
  • Train on one part of the data, test on another part.

1.2Nearest neighbour and k-NN

Lecture L01 · Short video: Nearest neighbour · Distances and similarities · Curse of dimensionality

To classify a new point, look at the training points closest to it and copy their label.

The nearest neighbour rule (1-NN) finds the single training example closest to the new point and gives the new point that example's label. The k-nearest neighbour rule (k-NN) finds the \(K\) closest training examples and takes a majority vote of their labels. Nothing is computed in advance. The "training" is just storing the data, and all the work happens at test time.

Three questions decide how k-NN behaves. What value of \(K\)? Which distance? Do the features need rescaling first (section 1.4)?

Distances

For two points \(\mathbf p, \mathbf q \in \R^d\), the two distances used in the course are

\[d_2(\mathbf p, \mathbf q) = \sqrt{\textstyle\sum_{j=1}^d (p_j - q_j)^2},\] \[d_1(\mathbf p, \mathbf q) = \textstyle\sum_{j=1}^d |p_j - q_j|.\]
Reading the formula

\(p_j\) is the \(j\)-th entry of \(\mathbf p\). The symbol \(\sum_{j=1}^d\) means "add the following term for \(j = 1, 2, \dots, d\)". \(|a|\) is the absolute value of \(a\) (drop the minus sign).

\(d_2\) is the Euclidean distance, the straight-line length from school geometry (Pythagoras). \(d_1\) is the Manhattan distance, named after walking on a grid of city streets where you can only go along the blocks, so you add the horizontal and vertical distances. They are the \(L_2\) and \(L_1\) norms of \(\mathbf p - \mathbf q\) (see section 1.8).

Example. \(\mathbf p = [0, 0]\), \(\mathbf q = [2, 0.5]\). Then \(d_1 = |0-2| + |0-0.5| = 2.5\) and \(d_2 \)\({}= \sqrt{4 + 0.25}\)\({}= \sqrt{4.25} \approx 2.06\). Quiz 1 Q5 uses exactly this pair.

L02 lists the four properties a function must have to be called a distance (a metric). For all points \(\mathbf p, \mathbf q, \mathbf r\):

  1. Identity. \(d(\mathbf p, \mathbf q) = 0\) if and only if \(\mathbf p = \mathbf q\).
  2. Non-negativity. \(d(\mathbf p, \mathbf q) \ge 0\).
  3. Symmetry. \(d(\mathbf p, \mathbf q) \)\({}= d(\mathbf q, \mathbf p)\).
  4. Triangle inequality. \(d(\mathbf p, \mathbf r) \le d(\mathbf p, \mathbf q) + d(\mathbf q, \mathbf r)\). Going via a third point is never shorter.

Choosing K

With \(K = 1\) the rule follows every training point, including noisy or mislabelled ones. A larger \(K\) averages over more neighbours, so single bad points matter less, but the rule becomes blunter near the boundary between classes. With two classes, use an odd \(K\) so the vote cannot tie. In practice \(K\) is chosen by trying several values on a validation set. Section 2 of the next page (bias and variance) comes back to this.

Common mistake

Ties. If two training points are at exactly the same distance, 1-NN has no unique answer. On a quiz, say that there is a tie and say how you broke it (for example "pick the smaller index" or "move to 3-NN"). The L01 problem below has such a tie on purpose.

1.3The linear classifier

Lecture L01 · Short video: Linear classifier

Decide the class by which side of a line (or plane) the point is on.

A linear classifier for two classes computes one number from the input and looks at its sign:

\[ \hat y = \operatorname{sign}(\mathbf w\T \mathbf x). \]
Reading the formula

\(\mathbf w\) is a weight vector with the same number of entries as \(\mathbf x\). The small \(\mathsf T\) means transpose, which turns a column into a row, so \(\mathbf w\T\mathbf x\) is the dot product \(w_1x_1 + w_2x_2 + \dots + w_dx_d\). The function \(\operatorname{sign}(z)\) is \(+1\) when \(z \gt 0\) and \(-1\) when \(z \lt 0\). The hat on \(\hat y\) marks a prediction, as opposed to a true label \(y\).

Example. \(\mathbf w = [1, 1]\). For \(\mathbf x = [2, -1]\), \(\mathbf w\T\mathbf x \)\({}= 2 - 1\)\({}= 1 \gt 0\), so the class is +. For \(\mathbf x = [-3, 1]\), \(\mathbf w\T\mathbf x \)\({}= -2 \lt 0\), so the class is −.

Geometrically, the points with \(\mathbf w\T\mathbf x = 0\) form a line through the origin (a plane in 3-D, a hyperplane in higher dimensions). \(\mathbf w\) points at right angles to that line, towards the + side. The classifier cuts the input space into two halves.

Adding a bias, and the augmented vector

The set \(\mathbf w\T\mathbf x = 0\) always passes through the origin, because \(\mathbf x = \mathbf 0\) gives 0. A general line needs an extra constant \(b\), called the bias: \(\mathbf w\T\mathbf x + b = 0\). The slides give two equivalent ways to write this.

  1. Keep \(b\) separate. \(\operatorname{sign}(\mathbf w\T\mathbf x + b)\).
  2. Append a 1 to every input, \(\tilde{\mathbf x} \)\({}= [x_1, \dots, x_d, 1]\), and append \(b\) to the weights, \(\tilde{\mathbf w} \)\({}= [w_1, \dots, w_d, b]\). Then \(\tilde{\mathbf w}\T\tilde{\mathbf x} \)\({}= \mathbf w\T\mathbf x + b\). This is the augmented vector.

From now on, when the course writes \(\mathbf w\T\mathbf x\), the 1 has usually been appended and the bias is "absorbed" into \(\mathbf w\). Regression in section 1.6 uses the same trick, which is why its data matrix has a column of ones.

More than two classes

The L01 discussion asks how to extend a sign-based rule to 3 or 4 classes. There are three standard answers.

  • One against the rest. Learn one weight vector \(\mathbf w_k\) per class \(k\). Each says "class \(k\) or not". Predict the class whose score is largest, \(\hat y \)\({}= \argmax_k \mathbf w_k\T\mathbf x\). The notation \(\argmax_k\) means "the value of \(k\) that makes the expression largest". This uses \(K\) classifiers for \(K\) classes and is the rule behind softmax later in the course.
  • One against one. Learn one classifier for every pair of classes, \(\frac{K(K-1)}2\) of them (6 for 4 classes), and let them vote.
  • Binary code. For 4 classes, two binary classifiers give two signs, and the 4 sign patterns \((+,+), (+,-), (-,+), (-,-)\) name the 4 classes. This uses the fewest classifiers but each must split the classes into two groups that are actually separable.
Remember
  • \(\hat y \)\({}= \operatorname{sign}(\mathbf w\T\mathbf x)\). The boundary \(\mathbf w\T\mathbf x = 0\) is a hyperplane at right angles to \(\mathbf w\).
  • A bias is handled by appending 1 to \(\mathbf x\) and \(b\) to \(\mathbf w\).
  • For \(K\) classes, the usual rule is \(\argmax_k \mathbf w_k\T\mathbf x\).

1.4Feature transformation and normalisation

Lecture L02 · Short video: Feature selection and extraction · Data from a multivariate distribution

Change the raw features into better ones before learning, often with a matrix.

A feature transformation is any function \(\phi\) that maps a feature vector \(\mathbf x\) to a new vector \(\mathbf x' = \phi(\mathbf x)\). The symbol \(\phi\) is the Greek letter phi. The most important kind is linear:

\[ \mathbf x' = \mathbf W\mathbf x. \]
Reading the formula

\(\mathbf x\) has \(d\) entries. \(\mathbf W\) is a matrix with \(d'\) rows and \(d\) columns, so \(\mathbf x'\) has \(d'\) entries. Each new feature \(x'_r\) is row \(r\) of \(\mathbf W\) dotted with \(\mathbf x\), a weighted sum of the old features.

When \(\mathbf W\) has fewer rows than columns (\(d' \lt d\)), the new vector is shorter. This is dimensionality reduction. PCA in section 1.12 is the best-known way to choose such a \(\mathbf W\).

Example. \(\mathbf W = [1, 0]\) (one row, two columns) maps \([3, 7]\) to \(3\). It keeps the first feature and drops the second. \(\mathbf W = [1, 1]\) maps \([3, 7]\) to \(10\), the sum.

The slides give three reasons to transform features.

  • Richer features. Combine features into new ones that make the task easier. The hidden layers of a neural network do this (page 3).
  • Dimensionality reduction. Fewer numbers per example, so less computation and less data needed. PCA is the example.
  • Numerical convenience. Rescale every feature to a common range, so no single feature dominates distances or gradients. This is normalisation.

Three ways to normalise

Write \(x_j\) for feature \(j\) of one example, and compute \(\min_j\), \(\max_j\), the mean \(\mu_j\) and the standard deviation \(\sigma_j\) of feature \(j\) over the training set. \(\mu\) is the Greek letter mu, \(\sigma\) is sigma.

NameFormulaResult
Min-max to \([0,1]\)\(x_j' \)\({}= \dfrac{x_j - \min_j}{\max_j - \min_j}\)each feature lies in \([0,1]\)
Min-max to \([-1,1]\)\(x_j' \)\({}= 2\,\dfrac{x_j - \min_j}{\max_j - \min_j} - 1\)each feature lies in \([-1,1]\)

Example

Heights in a class are 150, 160, 170 cm. Min 150, max 170. Min-max to \([0,1]\) gives \(\frac{0}{20}, \frac{10}{20}, \frac{20}{20} \)\({}= 0, 0.5, 1\). The mean is 160 and the standard deviation (dividing by \(N = 3\)) is \(\sqrt{\frac{100 + 0 + 100}3} \)\({}= \sqrt{66.7} \approx 8.16\), so the z-scores are \(-1.22, 0, 1.22\).

The first three act on each feature (column) separately. Unit length acts on each example (row). They fix different problems. The slides also ask how to normalise "online", meaning one example at a time as data arrive. Section 1.14 gives the running mean and variance formulas that do this, and batch normalisation in neural networks (page 3) is the same idea applied to a mini-batch.

Weighted distance and the Mahalanobis distance

Scaling feature \(j\) by a factor \(a_j\) before taking Euclidean distance is the same as using a weighted Euclidean distance on the raw features:

\[ d_{\mathbf a}(\mathbf p, \mathbf q) = \sqrt{\textstyle\sum_j a_j^2\,(p_j - q_j)^2}. \]

If instead the data have a full covariance matrix \(\Sigma\) (section 1.12 and Maths basics), the natural distance is the Mahalanobis distance \(\sqrt{(\mathbf p - \mathbf q)\T\Sigma^{-1}(\mathbf p - \mathbf q)}\). It measures distance in units of the spread of the data in each direction. When \(\Sigma\) is diagonal with entries \(\sigma_1^2, \sigma_2^2\), it is the weighted distance with \(a_j = 1/\sigma_j\), which is the same as z-scoring each feature and then using Euclidean distance. Section 1.14 has the L06 question on this.

Actually negativeFP false positive (a false alarm)TN true negative

This table of counts is the confusion matrix. With \(K\) classes it is \(K \times K\). Row \(i\), column \(j\) counts examples of true class \(i\) predicted as class \(j\). The correct predictions sit on the diagonal. The name comes from showing which classes the classifier confuses with which.

\[\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN},\] \[\text{Precision} = \frac{TP}{TP + FP}, \qquad \text{Recall}\] \[{}= \frac{TP}{TP + FN}.\]
Reading the formula

Accuracy is the fraction of all predictions that are right.

Precision looks only at what the classifier called positive (the bottom counts TP + FP), and asks what fraction of those really are positive. "When it raises an alarm, how often is it right?"

Recall looks only at the truly positive examples (TP + FN), and asks what fraction were found. "Of all the real cases, how many did it catch?" Recall is also called the true positive rate or sensitivity. Since TP + FN is the number of actual positives \(P\), recall is \(TP/P\).

Example. 100 emails, 20 are spam. The filter flags 25. Of those, 15 are spam. So TP = 15, FP = 10, FN = 20 − 15 = 5, TN = 80 − 10 = 70. Accuracy \(= \frac{85}{100} = 0.85\). Precision \(= \frac{15}{25} = 0.6\). Recall \(= \frac{15}{20} = 0.75\).

The F-score (F1) combines the two into one number, their harmonic mean:

\[ F_1 = \frac{2\cdot\text{Precision}\cdot\text{Recall}}{\text{Precision} + \text{Recall}}. \]

In the example, \(F_1 \)\({}= \frac{2 \times 0.6 \times 0.75}{1.35}\)\({}= \frac{0.9}{1.35} \approx 0.67\). The harmonic mean is small whenever either input is small, so a classifier cannot get a high F1 by being good at only one of the two.

Thresholds and ranking

Many classifiers output a score, such as \(\mathbf w\T\mathbf x\), and call an example positive when the score is at least a threshold \(\theta\) (theta). Lowering \(\theta\) flags more examples. Recall can only go up (more true cases caught), and precision usually goes down (more false alarms). Quiz 1 Q4 asked exactly this with four different thresholds.

In retrieval (a search engine returning a ranked list), precision and recall are computed for the top \(k\) results. Average precision (AP) averages the precision at each rank where a relevant item appears.

Example

A ranked list of 5 results is relevant, not, relevant, not, relevant (3 relevant items in total). Precision at rank 1 is \(\frac11\), at rank 3 is \(\frac23\), at rank 5 is \(\frac35\). AP \(= \frac13\left(1 + \frac23 + \frac35\right) \)\({}= \frac13(2.267) \approx 0.76\).

Common mistake

Accuracy is misleading when one class is rare. If 1 email in 1000 is spam, a filter that never flags anything has 99.9% accuracy and catches nothing. Look at recall and precision for the rare class.

Remember
  • Precision \(= \frac{TP}{TP+FP}\) (of the flagged, how many are real). Recall \(= \frac{TP}{TP+FN}\) (of the real, how many are flagged).
  • The confusion matrix is square, with correct counts on the diagonal.
  • For rare classes, accuracy is not enough.

1.6Linear regression and its closed-form solution

Lecture L03 · Short video: Linear regression · Read: Minka, matrix algebra for statistics · The Matrix Cookbook

Fit a straight line (or plane) to data by making the average squared error as small as possible.

Regression predicts a real number. The slides give two examples. One is to predict a student's weight from their height, and the other is to predict a laptop's price from its processor speed, memory and disk size. Linear regression uses the simplest form, a weighted sum of the features:

\[ \hat y_i = \mathbf w\T\mathbf x_i. \]

With one feature and the bias absorbed (\(\mathbf x_i = [x_i, 1]\), \(\mathbf w = [w_1, w_2]\)), this is \(\hat y_i = w_1x_i + w_2\), the school line \(y = mx + c\) with \(m = w_1\) and \(c = w_2\).

The loss

To say how bad a choice of \(\mathbf w\) is, the course uses the mean squared error (MSE):

\[ J(\mathbf w) = \frac1N\sum_{i=1}^N\left(y_i - \mathbf w\T\mathbf x_i\right)^2. \]
Reading the formula

For example \(i\), \(y_i - \mathbf w\T\mathbf x_i\) is the error, called the residual, which is actual minus predicted. Squaring makes every error positive and punishes big errors more than small ones. The sum adds this up over all \(N\) examples, and \(\frac1N\) turns the total into an average. A function like \(J\) that scores how wrong the model is, is called a loss function or objective. Learning means finding \(\mathbf w^* \)\({}= \argmin_{\mathbf w} J(\mathbf w)\), the \(\mathbf w\) that makes \(J\) smallest.

Example. Data \((1,2), (2,3), (3,5)\) and the line \(\hat y = x + 1\). Predictions are 2, 3, 4. Residuals are 0, 0, 1. \(J = \frac13(0 + 0 + 1) = 0.33\).

Quiz 1 Q8 asked you to write exactly this formula. The rubric took off 0.5 for leaving out the \(\frac1N\).

Matrix form

Stack the inputs as the rows of a data matrix \(\mathbf X\) (\(N\) rows, \(d\) columns), and the targets into a column \(\mathbf y\) (\(N\) entries). Then all the predictions at once are \(\hat{\mathbf y} \)\({}= \mathbf X\mathbf w\), and the sum of squared residuals is the squared length of the residual vector:

\[J(\mathbf w) = \frac1N(\mathbf y - \mathbf X\mathbf w)\T(\mathbf y - \mathbf X\mathbf w)\] \[{}= \frac1N\|\mathbf y - \mathbf X\mathbf w\|_2^2.\]
Example

Data \((1,2), (2,3), (3,4)\) with \(\mathbf x_i = [1, x_i]\) (the 1 first this time, so \(\mathbf w = [c, m]\)). Then \[\mathbf X = \begin{bmatrix} 1 & 1 \\ 1 & 2 \\ 1 & 3 \end{bmatrix}, \qquad \mathbf y\] \[{}= \begin{bmatrix} 2 \\ 3 \\ 4 \end{bmatrix}.\] The column of ones is the augmented 1 from section 1.3. It is what lets the line have an intercept.

Write this in the exam

Show that the \(\mathbf w\) minimising \(J(\mathbf w) \)\({}= \frac1N\|\mathbf y - \mathbf X\mathbf w\|^2\) is \(\mathbf w^* \)\({}= (\mathbf X\T\mathbf X)^{-1}\mathbf X\T\mathbf y\).

  1. \(J(\mathbf w) \)\({}= \frac1N(\mathbf y - \mathbf X\mathbf w)\T(\mathbf y - \mathbf X\mathbf w)\).
    Why (3 steps)
    1. Row \(i\) of \(\mathbf X\mathbf w\) is \(\mathbf x_i\T\mathbf w\), the prediction for example \(i\).
    2. So entry \(i\) of \(\mathbf y - \mathbf X\mathbf w\) is the residual \(y_i - \mathbf w\T\mathbf x_i\).
    3. For any vector \(\mathbf r\), \(\mathbf r\T\mathbf r \)\({}= r_1^2 + \dots + r_N^2\). So \((\mathbf y - \mathbf X\mathbf w)\T(\mathbf y - \mathbf X\mathbf w)\) is the sum of squared residuals, and dividing by \(N\) gives \(J\).
  2. Expand. \(J \)\({}= \frac1N\left(\mathbf y\T\mathbf y - 2\mathbf w\T\mathbf X\T\mathbf y + \mathbf w\T\mathbf X\T\mathbf X\mathbf w\right)\).
    Why (4 steps)
    1. Transpose the first bracket using \((\mathbf A - \mathbf B)\T \)\({}= \mathbf A\T - \mathbf B\T\) and \((\mathbf X\mathbf w)\T \)\({}= \mathbf w\T\mathbf X\T\). It becomes \(\mathbf y\T - \mathbf w\T\mathbf X\T\).
    2. Multiply out \((\mathbf y\T - \mathbf w\T\mathbf X\T)(\mathbf y - \mathbf X\mathbf w)\) into four terms. \[\mathbf y\T\mathbf y - \mathbf y\T\mathbf X\mathbf w - \mathbf w\T\mathbf X\T\mathbf y + \mathbf w\T\mathbf X\T\mathbf X\mathbf w.\]
    3. \(\mathbf y\T\mathbf X\mathbf w\) is a single number, and a number equals its own transpose, so \(\mathbf y\T\mathbf X\mathbf w \)\({}= (\mathbf y\T\mathbf X\mathbf w)\T\)\({}= \mathbf w\T\mathbf X\T\mathbf y\).
    4. So the two middle terms are equal and combine into \(-2\mathbf w\T\mathbf X\T\mathbf y\).
  3. Take the gradient. \(\nabla_{\mathbf w}J \)\({}= \frac1N\left(-2\mathbf X\T\mathbf y + 2\mathbf X\T\mathbf X\mathbf w\right)\).
    Why (4 steps)
    1. The gradient \(\nabla_{\mathbf w}J\) is the vector of partial derivatives \(\frac{\partial J}{\partial w_1}, \dots, \frac{\partial J}{\partial w_d}\). At a minimum of a smooth function it is the zero vector. See Maths basics.
    2. \(\mathbf y\T\mathbf y\) does not contain \(\mathbf w\), so its gradient is \(\mathbf 0\).
    3. For a fixed vector \(\mathbf a\), \(\nabla_{\mathbf w}(\mathbf w\T\mathbf a) \)\({}= \mathbf a\). With \(\mathbf a \)\({}= \mathbf X\T\mathbf y\) this gives \(\nabla(-2\mathbf w\T\mathbf X\T\mathbf y) \)\({}= -2\mathbf X\T\mathbf y\).
    4. For a symmetric matrix \(\mathbf A\), \(\nabla_{\mathbf w}(\mathbf w\T\mathbf A\mathbf w) \)\({}= 2\mathbf A\mathbf w\). \(\mathbf X\T\mathbf X\) is symmetric because \((\mathbf X\T\mathbf X)\T \)\({}= \mathbf X\T\mathbf X\). So this term gives \(2\mathbf X\T\mathbf X\mathbf w\).
  4. Set the gradient to zero. \(\mathbf X\T\mathbf X\mathbf w \)\({}= \mathbf X\T\mathbf y\). These are the normal equations.
    Why (3 steps)
    1. Set line 3 equal to \(\mathbf 0\). \(\frac1N(-2\mathbf X\T\mathbf y + 2\mathbf X\T\mathbf X\mathbf w) \)\({}= \mathbf 0\).
    2. Multiply both sides by \(\frac N2\). \(-\mathbf X\T\mathbf y + \mathbf X\T\mathbf X\mathbf w \)\({}= \mathbf 0\).
    3. Add \(\mathbf X\T\mathbf y\) to both sides.
  5. If \(\mathbf X\T\mathbf X\) is invertible, \[\mathbf w^* = (\mathbf X\T\mathbf X)^{-1}\mathbf X\T\mathbf y.\]
    Why (3 steps)
    1. Multiply both sides of line 4 on the left by \((\mathbf X\T\mathbf X)^{-1}\).
    2. On the left, \((\mathbf X\T\mathbf X)^{-1}\mathbf X\T\mathbf X \)\({}= \mathbf I\), the identity matrix, and \(\mathbf I\mathbf w = \mathbf w\).
    3. This is a minimum, not a maximum, because \(J\) is a sum of squares, a bowl-shaped (convex) function of \(\mathbf w\). A convex function has only one bottom, so the zero-gradient point is the global minimum.
Reading the formula

\(\mathbf X\T\mathbf X\) is a \(d\times d\) matrix of sums of products of features. \(\mathbf X\T\mathbf y\) is a \(d\)-vector of sums of feature times target. For one feature with an intercept,

\[\mathbf X\T\mathbf X = \begin{bmatrix} N & \sum x_i \\ \sum x_i & \sum x_i^2 \end{bmatrix}, \qquad \mathbf X\T\mathbf y\] \[{}= \begin{bmatrix} \sum y_i \\ \sum x_iy_i \end{bmatrix}.\]

To invert a \(2\times2\) matrix, swap the diagonal, negate the off-diagonal and divide by the determinant, so \(\begin{bmatrix} a & b \\ c & d \end{bmatrix}^{-1} \)\({}= \frac1{ad - bc}\begin{bmatrix} d & -b \\ -c & a \end{bmatrix}\). Quiz 1 Q12 is this calculation, worked in section 1.15.

The inverse fails to exist when two features are copies of each other (or one is a combination of others), because then \(\mathbf X\T\mathbf X\) has determinant 0. Ridge regression in section 1.8 fixes this.

Things the slides ask you to discuss

  • Is the solution unique? \(J\) is convex. If \(\mathbf X\T\mathbf X\) is invertible there is exactly one minimiser. If not, there are infinitely many \(\mathbf w\) with the same smallest \(J\).
  • Why squared error? It is smooth, so it can be differentiated, and it gives a closed form. Page 2 shows it is also what you get by assuming Gaussian noise and maximising the likelihood (MSE as MLE). Its weakness is that squaring makes one huge error dominate. The mean absolute error \(\frac1N\sum|y_i - \hat y_i|\) is less affected by outliers but has no closed form.
  • Noisy or wrong data. If 10% of the samples are corrupted, their large residuals get squared and pull the line towards them. See the outlier problem below and the weighted version in the next questions.
Remember
  • \(J(\mathbf w) \)\({}= \frac1N\sum(y_i - \mathbf w\T\mathbf x_i)^2\)\({}= \frac1N\|\mathbf y - \mathbf X\mathbf w\|^2\).
  • \(\mathbf w^* \)\({}= (\mathbf X\T\mathbf X)^{-1}\mathbf X\T\mathbf y\). Add a column of ones to \(\mathbf X\) for the intercept.
  • Two gradient facts are \(\nabla(\mathbf w\T\mathbf a) \)\({}= \mathbf a\) and \(\nabla(\mathbf w\T\mathbf A\mathbf w) \)\({}= 2\mathbf A\mathbf w\) for symmetric \(\mathbf A\).

1.7Gradient descent

Lectures L03, L04 · Short video: MSE using gradient descent

Walk downhill on the loss in small steps, each step in the direction where the loss falls fastest.

The closed form needs \((\mathbf X\T\mathbf X)^{-1}\), which is expensive when \(d\) is large (inverting a \(d\times d\) matrix takes about \(d^3\) operations) and impossible for losses that have no closed form, such as those of neural networks. Gradient descent finds the minimum by repeated small improvements.

The gradient \(\nabla J\) points in the direction in which \(J\) increases fastest. So a small step in the opposite direction decreases \(J\). Start from some \(\mathbf w_0\) and repeat:

\[ \mathbf w_{k+1} = \mathbf w_k - \eta\,\nabla J(\mathbf w_k). \]
Reading the formula

\(k\) counts the iterations. \(\eta\) (eta) is the learning rate, a small positive number that sets the step size. The arrow "\(\leftarrow\)" on the slides means the same as this equation. It says to replace the old value by the new one.

If \(\eta\) is too small, progress is slow. If it is too big, each step overshoots the bottom and the values can grow without limit.

Example. \(J(w) = (w-3)^2\), so \(J'(w) = 2(w-3)\). Start at \(w_0 = 0\) with \(\eta = 0.25\). \(w_1 \)\({}= 0 - 0.25 \times 2(0-3)\)\({}= 1.5\). \(w_2 \)\({}= 1.5 - 0.25 \times 2(1.5 - 3)\)\({}= 2.25\). \(w_3 = 2.625\). Each step halves the distance to 3. With \(\eta = 1.1\), \(w_1 = 6.6\), \(w_2 = -1.32\) and it swings further away each time.

Write this in the exam

Derive the gradient descent update for linear regression with MSE, and for \(y = mx + c\).

  1. \(J(\mathbf w) \)\({}= \frac1N\sum_i(y_i - \mathbf w\T\mathbf x_i)^2\).
  2. \(\nabla J \)\({}= \frac1N\sum_i 2(y_i - \mathbf w\T\mathbf x_i)(-\mathbf x_i)\)\({}= -\frac2N\sum_i(y_i - \mathbf w\T\mathbf x_i)\,\mathbf x_i\).
    Why (4 steps)
    1. The gradient of a sum is the sum of the gradients, so differentiate one term \((y_i - \mathbf w\T\mathbf x_i)^2\).
    2. By the chain rule, the derivative of \(u^2\) is \(2u\) times the derivative of \(u\). Here \(u \)\({}= y_i - \mathbf w\T\mathbf x_i\).
    3. \(\nabla_{\mathbf w}(y_i - \mathbf w\T\mathbf x_i) \)\({}= -\mathbf x_i\), since \(y_i\) does not depend on \(\mathbf w\) and \(\nabla(\mathbf w\T\mathbf x_i) \)\({}= \mathbf x_i\).
    4. So one term gives \(2(y_i - \mathbf w\T\mathbf x_i)(-\mathbf x_i)\). Put the \(\frac1N\) and the sum back, and pull out \(-2\).
  3. Update. \(\mathbf w_{k+1} \)\({}= \mathbf w_k + \frac{2\eta}N\sum_i(y_i - \mathbf w_k\T\mathbf x_i)\,\mathbf x_i\).
    Why (2 steps)
    1. Substitute line 2 into \(\mathbf w_{k+1} \)\({}= \mathbf w_k - \eta\nabla J(\mathbf w_k)\).
    2. Minus times minus is plus. Each sample pushes \(\mathbf w\) in the direction of \(\mathbf x_i\), by an amount proportional to its residual.
  4. For \(y = mx + c\), \(\frac{\partial J}{\partial m} \)\({}= -\frac2N\sum_i(y_i - mx_i - c)\,x_i\) and \(\frac{\partial J}{\partial c} \)\({}= -\frac2N\sum_i(y_i - mx_i - c)\).
    Why (3 steps)
    1. Here \(\mathbf w = [m, c]\) and \(\mathbf x_i = [x_i, 1]\), so \(\mathbf w\T\mathbf x_i \)\({}= mx_i + c\).
    2. The first entry of line 2 multiplies by the first entry of \(\mathbf x_i\), which is \(x_i\). That is \(\frac{\partial J}{\partial m}\).
    3. The second entry multiplies by the second entry of \(\mathbf x_i\), which is 1. That is \(\frac{\partial J}{\partial c}\).
  5. So \(m \leftarrow m + \frac{2\eta}N\sum_i(y_i - mx_i - c)x_i\) and \(c \leftarrow c + \frac{2\eta}N\sum_i(y_i - mx_i - c)\), both computed from the old \(m, c\).

1.8Norms, ridge and lasso

Lecture L04 · Short video: Regularization in regression

Add a penalty on the size of \(\mathbf w\) to the loss, to prefer simpler and more stable solutions.

Norms

A norm measures the size of a vector. The \(L_p\) norm is

\[ \|\mathbf x\|_p = \Big(\textstyle\sum_{i=1}^d|x_i|^p\Big)^{1/p}. \]
NormDefinitionFor \(\mathbf x = [-4, 3, 0, 0]\)
\(L_1\)\(\sum|x_i|\)\(4 + 3 = 7\)
\(L_2\)\(\sqrt{\sum x_i^2}\), the ordinary length\(\sqrt{16 + 9} = 5\)
\(L_\infty\)\(\max_i|x_i|\), the largest entry in size4
\(L_0\)number of non-zero entries2

The column on the right is Quiz 1 Q1, Set 1. \(L_\infty\) is the limit of \(L_p\) as \(p\) grows, because the largest entry raised to a huge power swamps all the others. \(L_0\) is not a true norm (doubling \(\mathbf x\) does not double it), but the course uses the name. It counts how many features a weight vector actually uses. A vector with many zeros is called sparse.

Regularisation

Regularisation means adding a second term \(g(\mathbf w)\) to the loss, giving \(J \)\({}= f(\mathbf w) + \lambda g(\mathbf w)\). The slides give three reasons.

  • It prefers some kinds of solution over others, for example sparse ones.
  • It fixes ill-posed problems, such as inverting a matrix that is nearly singular.
  • It reduces overfitting, where a model fits the training data's noise and does badly on new data (page 2, generalisation).

\(\lambda \ge 0\) (lambda) sets how much the penalty counts. \(\lambda = 0\) is plain regression. A very large \(\lambda\) forces \(\mathbf w\) towards \(\mathbf 0\). \(\lambda\) is chosen by trying values on a validation set. It is a hyperparameter, set before training rather than learned.

Ridge regression (L2 penalty)

\[J(\mathbf w) = \sum_{i=1}^N(y_i - \mathbf w\T\mathbf x_i)^2 + \lambda\|\mathbf w\|_2^2\] \[{}= \|\mathbf y - \mathbf X\mathbf w\|^2 + \lambda\,\mathbf w\T\mathbf w.\]
Write this in the exam

Show that ridge regression gives \(\mathbf w^* \)\({}= (\mathbf X\T\mathbf X + \lambda\mathbf I)^{-1}\mathbf X\T\mathbf y\).

  1. Expand. \[J = \mathbf y\T\mathbf y - 2\mathbf w\T\mathbf X\T\mathbf y + \mathbf w\T\mathbf X\T\mathbf X\mathbf w + \lambda\mathbf w\T\mathbf w.\]
    Why (2 steps)
    1. The first part expands exactly as in line 2 of section 1.6 (without the \(\frac1N\), as the L04 slide writes it).
    2. \(\|\mathbf w\|_2^2 \)\({}= w_1^2 + \dots + w_d^2\)\({}= \mathbf w\T\mathbf w\).
  2. \(\nabla J \)\({}= -2\mathbf X\T\mathbf y + 2\mathbf X\T\mathbf X\mathbf w + 2\lambda\mathbf w\).
    Why (2 steps)
    1. The first three terms differentiate as in line 3 of section 1.6.
    2. \(\mathbf w\T\mathbf w \)\({}= \mathbf w\T\mathbf I\mathbf w\), and \(\mathbf I\) is symmetric, so its gradient is \(2\mathbf I\mathbf w \)\({}= 2\mathbf w\). Times \(\lambda\) gives \(2\lambda\mathbf w\).
  3. Set to zero. \((\mathbf X\T\mathbf X + \lambda\mathbf I)\mathbf w \)\({}= \mathbf X\T\mathbf y\).
    Why (3 steps)
    1. Divide line 2 by 2 and set it to \(\mathbf 0\). \(-\mathbf X\T\mathbf y + \mathbf X\T\mathbf X\mathbf w + \lambda\mathbf w \)\({}= \mathbf 0\).
    2. Write \(\lambda\mathbf w \)\({}= \lambda\mathbf I\mathbf w\) so both \(\mathbf w\) terms have a matrix in front, and factor to get \((\mathbf X\T\mathbf X + \lambda\mathbf I)\mathbf w\).
    3. Move \(\mathbf X\T\mathbf y\) to the right side.
  4. \(\mathbf w^* \)\({}= (\mathbf X\T\mathbf X + \lambda\mathbf I)^{-1}\mathbf X\T\mathbf y\). For \(\lambda \gt 0\) this inverse always exists.
    Why (4 steps)
    1. \(\mathbf X\T\mathbf X\) is positive semi-definite (section 1.11), so its eigenvalues \(\mu_j\) are all \(\ge 0\). Some may be 0, which is when the plain inverse fails.
    2. Adding \(\lambda\mathbf I\) adds \(\lambda\) to every eigenvalue, because \((\mathbf X\T\mathbf X + \lambda\mathbf I)\mathbf v \)\({}= \mu\mathbf v + \lambda\mathbf v\)\({}= (\mu + \lambda)\mathbf v\) for each eigenvector \(\mathbf v\).
    3. So every eigenvalue is now at least \(\lambda \gt 0\). A matrix with no zero eigenvalue has non-zero determinant (the determinant is the product of the eigenvalues) and is invertible.
    4. This answers the slide's question on numerical stability. Tiny eigenvalues make the inverse huge and sensitive to noise. Ridge lifts them away from zero.

Gradient descent for ridge. Using line 2 (and dividing by \(N\) if you prefer the average), the update is \(\mathbf w \leftarrow \mathbf w - \eta(-2\mathbf X\T(\mathbf y - \mathbf X\mathbf w) + 2\lambda\mathbf w)\), which rearranges to \(\mathbf w \leftarrow (1 - 2\eta\lambda)\mathbf w + 2\eta\mathbf X\T(\mathbf y - \mathbf X\mathbf w)\). Each step first shrinks \(\mathbf w\) by the factor \(1 - 2\eta\lambda\), then takes the usual step. In neural networks this shrinking is called weight decay.

Lasso (L1 penalty)

\[J(\mathbf w) = \|\mathbf y - \mathbf X\mathbf w\|^2 + \lambda\|\mathbf w\|_1\] \[{}= \|\mathbf y - \mathbf X\mathbf w\|^2 + \lambda\sum_j|w_j|.\]

Lasso stands for "least absolute shrinkage and selection operator". It also shrinks the weights, but it sets the weights of unhelpful features exactly to zero, so it selects features. \(|w_j|\) has a corner at 0 and no derivative there, so there is no closed form. The slides say solving lasso is outside the course. What you need is the picture of why it gives zeros.

Read the lower pictures. Penalised regression is the same as minimising the error while keeping \(\mathbf w\) inside a region. The region is a disc for L2 (\(w_1^2 + w_2^2 \le t\)) or a diamond for L1 (\(|w_1| + |w_2| \le t\)). The error contours grow outward from the unpenalised best point until they first touch the region. A disc is round, so the touching point is usually somewhere on the curve with both weights non-zero. A diamond has sharp corners on the axes, and the contours usually hit a corner first. At a corner one weight is exactly 0. In many dimensions, a corner means many zeros. That is why L1 gives sparse solutions and L2 does not.

The slides ask why L0 would be "ideal". \(\lambda\|\mathbf w\|_0\) directly penalises the number of features used. But it is not continuous, and minimising it means trying every subset of features, which is far too slow. L1 is the closest convex penalty to L0, which is why it is used instead.

Remember
  • Ridge: \(+\lambda\|\mathbf w\|_2^2\), closed form \((\mathbf X\T\mathbf X + \lambda\mathbf I)^{-1}\mathbf X\T\mathbf y\), shrinks all weights, always invertible.
  • Lasso: \(+\lambda\|\mathbf w\|_1\), no closed form, sets some weights to exactly 0.
  • \(L_0\) counts non-zeros, \(L_\infty\) is the largest entry in absolute value.

1.9Problems whose answer is an eigenvector

Lecture L04 · Short video: Optimization and eigenvectors · Read: Maths basics, eigenvectors and Lagrange multipliers

Maximising \(\mathbf w\T\mathbf A\mathbf w\) over unit vectors gives the top eigenvector of \(\mathbf A\).

The course has three ways to solve an optimisation problem. They are a closed form, gradient descent, and "the answer is an eigenvector". The third is the one behind PCA, Fisher's discriminant and several quiz questions.

Recall that \(\mathbf v\) is an eigenvector of a square matrix \(\mathbf A\), with eigenvalue \(\lambda\), when \(\mathbf A\mathbf v \)\({}= \lambda\mathbf v\). Multiplying by \(\mathbf A\) only stretches \(\mathbf v\), it does not turn it.

Write this in the exam

Maximise \(\mathbf w\T\mathbf A\mathbf w\) subject to \(\mathbf w\T\mathbf w = 1\), for symmetric \(\mathbf A\).

  1. Lagrangian: \(L(\mathbf w, \lambda) \)\({}= \mathbf w\T\mathbf A\mathbf w - \lambda(\mathbf w\T\mathbf w - 1)\).
    Why (3 steps)
    1. Without the constraint, \(\mathbf w\T\mathbf A\mathbf w\) could be made as large as we like by making \(\mathbf w\) longer. So the length is fixed at 1.
    2. A Lagrange multiplier \(\lambda\) turns "maximise \(f\) subject to \(g = 0\)" into "find where the gradient of \(f - \lambda g\) is zero". See Maths basics.
    3. Here \(f \)\({}= \mathbf w\T\mathbf A\mathbf w\) and \(g = \mathbf w\T\mathbf w - 1\).
  2. \(\nabla_{\mathbf w}L \)\({}= 2\mathbf A\mathbf w - 2\lambda\mathbf w\)\({}= \mathbf 0\), so \(\mathbf A\mathbf w \)\({}= \lambda\mathbf w\).
    Why (3 steps)
    1. \(\nabla(\mathbf w\T\mathbf A\mathbf w) \)\({}= 2\mathbf A\mathbf w\) because \(\mathbf A\) is symmetric.
    2. \(\nabla(\lambda\mathbf w\T\mathbf w) \)\({}= 2\lambda\mathbf w\), and the constant \(-\lambda \cdot (-1)\) has zero gradient.
    3. Divide by 2. The equation says \(\mathbf w\) must be an eigenvector of \(\mathbf A\), and \(\lambda\) its eigenvalue.
  3. At such a \(\mathbf w\), \(\mathbf w\T\mathbf A\mathbf w \)\({}= \lambda\). So the maximum is the largest eigenvalue, reached at its eigenvector.
    Why (3 steps)
    1. Multiply \(\mathbf A\mathbf w \)\({}= \lambda\mathbf w\) on the left by \(\mathbf w\T\) to get \(\mathbf w\T\mathbf A\mathbf w \)\({}= \lambda\mathbf w\T\mathbf w\).
    2. \(\mathbf w\T\mathbf w = 1\), so the objective equals \(\lambda\).
    3. Every candidate is an eigenvector and its objective value is its eigenvalue. The largest value comes from the largest eigenvalue. For the minimum, take the smallest.
Remember
  • max \(\mathbf w\T\mathbf A\mathbf w\) with \(\|\mathbf w\| = 1\) is at the eigenvector of the largest eigenvalue of \(\mathbf A\).
  • The min is at the eigenvector of the smallest eigenvalue.
  • Read the matrix carefully. \(\mathbf w\T\mathbf X\T\mathbf X\mathbf w\) uses \(\mathbf X\T\mathbf X\). \(\mathbf w\T\mathbf X\mathbf X\T\mathbf w\) uses \(\mathbf X\mathbf X\T\). Quiz 1 Q2 tested exactly this.

Part 4L05 · Rank of the data matrix

1.10The data matrix and its rank

Lecture L05 · Short video: Data as matrix · Read: MML book, chapters 2 and 4 · Maths basics, rank

Real data matrices are usually close to low rank, and that is what makes compression and PCA work.

Put \(N\) examples, each a vector in \(\R^d\), as the rows of an \(N\times d\) matrix \(\mathbf X\). The rank of \(\mathbf X\) is the number of linearly independent rows, which always equals the number of linearly independent columns. "Linearly independent" means no row can be written as a weighted sum of the others. The rank is at most \(\min(N, d)\).

The rank counts how many genuinely different directions the data use. If every row is a multiple of one vector, the rank is 1, however large \(N\) and \(d\) are.

Bag of words

The L05 example represents a document by counting words. Fix a vocabulary of \(d\) words. A document becomes \(\mathbf x \in \R^d\) where \(x_j\) is how many times word \(j\) appears. This is a bag of words histogram, named because word order is thrown away, as if the words were shaken in a bag. A one-hot vector is the special case for a single word. It is all zeros except for a 1 in that word's position.

Histograms of different lengths are usually divided by their total (so each sums to 1) or by their length, so that a long document and a short one on the same topic look alike.

Low rank in practice

Mathematically, almost any matrix of real measurements has full rank, \(\min(N,d)\), because noise makes every row slightly different. What matters in practice is the effective rank, meaning how many eigenvalues (or singular values, section 1.11) are large, as opposed to tiny. Data generated from \(p\) underlying "concepts" plus small noise has about \(p\) large eigenvalues and many tiny ones.

Remember
  • rank \(\le \min(N, d)\). Copies and multiples of rows add nothing to the rank.
  • With noise, the exact rank is full but the effective rank (number of large eigenvalues) reflects the number of underlying concepts.
  • The eigenvalue facts from L05 are these. Eigenvectors of a symmetric matrix are orthogonal, the product of the eigenvalues is the determinant, the number of non-zero eigenvalues is the rank (for symmetric matrices), and \(\mathbf A\) is positive semi-definite (PSD) if and only if \(\mathbf z\T\mathbf A\mathbf z \ge 0\) for every \(\mathbf z\).

1.11Eigen decomposition, SVD and low-rank approximation

Lectures L05, L07 · Short video: Eigen decomposition · SVD · Maths basics, SVD

Every matrix can be written as a sum of rank-1 pieces in order of importance. Keep the first few pieces to approximate it.

Eigen decomposition of a symmetric matrix

A symmetric \(d\times d\) matrix \(\mathbf S\) has \(d\) real eigenvalues \(\lambda_1 \ge \dots \ge \lambda_d\) and orthonormal eigenvectors \(\mathbf q_1, \dots, \mathbf q_d\) (each of length 1 and at right angles to each other). Then

\[\mathbf S = \mathbf Q\Lambda\mathbf Q\T\] \[{}= \sum_{i=1}^d\lambda_i\,\mathbf q_i\mathbf q_i\T.\]
Reading the formula

\(\mathbf Q\) has the eigenvectors as its columns. \(\Lambda\) is diagonal with the eigenvalues. \(\mathbf Q\T\mathbf Q \)\({}= \mathbf I\) because the columns are orthonormal, so \(\mathbf Q^{-1} = \mathbf Q\T\).

Each \(\mathbf q_i\mathbf q_i\T\) is a \(d\times d\) matrix of rank 1 (an outer product, a column times a row). So \(\mathbf S\) is a weighted sum of rank-1 pieces, weighted by the eigenvalues. Dropping the pieces with small \(\lambda_i\) changes \(\mathbf S\) only a little.

Example. \(\mathbf S \)\({}= \begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix}\) has \(\lambda_1 = 3\), \(\mathbf q_1 \)\({}= \frac1{\sqrt2}[1, 1]\) and \(\lambda_2 = 1\), \(\mathbf q_2 \)\({}= \frac1{\sqrt2}[-1, 1]\). Then \(3\cdot\frac12\begin{bmatrix} 1&1\\1&1 \end{bmatrix} + 1\cdot\frac12\begin{bmatrix} 1&-1\\-1&1 \end{bmatrix} \)\({}= \begin{bmatrix} 1.5+0.5 & 1.5-0.5 \\ 1.5-0.5 & 1.5+0.5 \end{bmatrix}\)\({}= \mathbf S\).

Inverting is easy in this form, since \(\mathbf S^{-1} \)\({}= \mathbf Q\Lambda^{-1}\mathbf Q\T\), with \(\Lambda^{-1}\) holding \(1/\lambda_i\). (L05 Problem 2.) And \(\mathbf Q\T\mathbf S\mathbf Q \)\({}= \Lambda\), which is called diagonalising \(\mathbf S\) (L06 Problem 3).

Singular value decomposition

Any \(m\times n\) matrix \(\mathbf A\), square or not, symmetric or not, can be written

\[\mathbf A = \mathbf U\mathbf D\mathbf V\T\] \[{}= \sum_i d_i\,\mathbf u_i\mathbf v_i\T.\]
Reading the formula

This is the singular value decomposition (SVD). \(\mathbf D\) is diagonal with the singular values \(d_1 \ge d_2 \ge \dots \ge 0\). The columns \(\mathbf u_i\) of \(\mathbf U\) are the left singular vectors, and the columns \(\mathbf v_i\) of \(\mathbf V\) are the right singular vectors. Both sets are orthonormal.

Here is the link to eigenvectors. \(\mathbf A\T\mathbf A \)\({}= \mathbf V\mathbf D\T\mathbf U\T\mathbf U\mathbf D\mathbf V\T\)\({}= \mathbf V\mathbf D^2\mathbf V\T\), and similarly \(\mathbf A\mathbf A\T \)\({}= \mathbf U\mathbf D^2\mathbf U\T\). So the \(\mathbf v_i\) are eigenvectors of \(\mathbf A\T\mathbf A\), the \(\mathbf u_i\) are eigenvectors of \(\mathbf A\mathbf A\T\), and the non-zero singular values are the square roots of the non-zero eigenvalues of both.

The number of non-zero singular values is the rank of \(\mathbf A\).

Shapes matter for Quiz 1 Q6. In the thin SVD of a tall \(m\times n\) matrix (\(m \gt n\)), \(\mathbf U\) is \(m\times n\), \(\mathbf D\) is \(n\times n\) and \(\mathbf V\) is \(n\times n\). \(\mathbf U\T\mathbf U \)\({}= \mathbf I_n\), so the columns of \(\mathbf U\) are orthonormal, but \(\mathbf U\) is not square, so its rows are not. \(\mathbf V\) is square with \(\mathbf V\T\mathbf V \)\({}= \mathbf V\mathbf V\T\)\({}= \mathbf I\), so both its rows and columns are orthonormal.

Example

Find the SVD of \(\mathbf A \)\({}= \begin{bmatrix} 3 & 0 \\ 4 & 5 \end{bmatrix}\).

  1. \(\mathbf A\T\mathbf A \)\({}= \begin{bmatrix} 3 & 4 \\ 0 & 5 \end{bmatrix}\begin{bmatrix} 3 & 0 \\ 4 & 5 \end{bmatrix}\)\({}= \begin{bmatrix} 25 & 20 \\ 20 & 25 \end{bmatrix}\).
  2. Its eigenvalues are \(25 + 20 = 45\) with eigenvector \(\frac1{\sqrt2}[1, 1]\), and \(25 - 20 = 5\) with eigenvector \(\frac1{\sqrt2}[-1, 1]\). (For \(\begin{bmatrix} a & b \\ b & a \end{bmatrix}\) the eigenvalues are always \(a \pm b\).)
  3. The singular values are the square roots, \(d_1 = \sqrt{45}\), \(d_2 = \sqrt5\). The \(\mathbf v_i\) are those eigenvectors.
  4. Get each \(\mathbf u_i\) from \(\mathbf u_i \)\({}= \mathbf A\mathbf v_i / d_i\). \(\mathbf A\mathbf v_1 \)\({}= \frac1{\sqrt2}[3, 9]\), divided by \(\sqrt{45}\) gives \(\frac1{\sqrt{90}}[3, 9] \)\({}= \frac1{\sqrt{10}}[1, 3]\).
  5. \(\mathbf A\mathbf v_2 \)\({}= \frac1{\sqrt2}[-3, 1]\), divided by \(\sqrt5\) gives \(\frac1{\sqrt{10}}[-3, 1]\).
  6. Check. \(d_1\mathbf u_1\mathbf v_1\T + d_2\mathbf u_2\mathbf v_2\T \)\({}= \frac{\sqrt{45}}{\sqrt{20}}\begin{bmatrix} 1&1\\3&3 \end{bmatrix} + \frac{\sqrt5}{\sqrt{20}}\begin{bmatrix} 3&-3\\-1&1 \end{bmatrix}\)\({}= 1.5\begin{bmatrix} 1&1\\3&3 \end{bmatrix} + 0.5\begin{bmatrix} 3&-3\\-1&1 \end{bmatrix}\)\({}= \begin{bmatrix} 3&0\\4&5 \end{bmatrix}\). Correct.

Low-rank approximation

To find the closest matrix of rank \(p\) to \(\mathbf A\), keep the first \(p\) terms of the SVD:

  1. Compute \(\mathbf A \)\({}= \mathbf U\mathbf D\mathbf V\T\).
  2. Set every singular value after the \(p\)-th to zero.
  3. Multiply back. \(\hat{\mathbf A} \)\({}= \sum_{i=1}^p d_i\mathbf u_i\mathbf v_i\T\).

"Closest" means the sum of squared differences of the entries, \(\sum_{i,j}(A_{ij} - \hat A_{ij})^2\), is as small as possible, and that smallest error equals \(\sum_{i \gt p}d_i^2\), the squares of the dropped singular values. In the example above, the best rank-1 approximation is \(1.5\begin{bmatrix} 1&1\\3&3 \end{bmatrix} \)\({}= \begin{bmatrix} 1.5&1.5\\4.5&4.5 \end{bmatrix}\), with squared error \(d_2^2 = 5\). Check. \((1.5)^2 + (1.5)^2 + (0.5)^2 + (0.5)^2 \)\({}= 2.25 + 2.25 + 0.25 + 0.25\)\({}= 5\).

Remember
  • \(\mathbf A \)\({}= \mathbf U\mathbf D\mathbf V\T\). \(\mathbf v_i\) are eigenvectors of \(\mathbf A\T\mathbf A\), \(\mathbf u_i\) of \(\mathbf A\mathbf A\T\), and \(d_i^2\) are their eigenvalues.
  • In the thin SVD of a tall matrix, the columns of \(\mathbf U\) are orthonormal, and the rows and columns of \(\mathbf V\) are orthonormal.
  • For the best rank-\(p\) approximation, keep the top \(p\) singular values.
  • \(\mathbf A^{-1} \)\({}= \mathbf V\mathbf D^{-1}\mathbf U\T\) for square invertible \(\mathbf A\).

1.12Principal component analysis (PCA)

Lectures L06, L07 · Short video: Orthogonal line fitting · PCA · PCA as compression

Find the directions in which the data spread out most, and describe each point by its coordinates along just those directions.

PCA is a linear, unsupervised way to reduce dimension, \(\mathbf x' \)\({}= \mathbf W\mathbf x\) with \(\mathbf W\) having fewer rows than columns. "Unsupervised" because it never looks at labels. The rows of \(\mathbf W\) are the principal components, the main directions of the data. The course gives three views that all lead to the same answer.

  1. The direction of maximum variance.
  2. The line (or plane) closest to the data, measured by perpendicular distance.
  3. The compression with the smallest reconstruction error.

The covariance matrix of centred data (mean subtracted, so \(\boldsymbol\mu = \mathbf 0\)) is

\[\Sigma = \frac1N\sum_{i=1}^N(\mathbf x_i - \boldsymbol\mu)(\mathbf x_i - \boldsymbol\mu)\T\] \[{}= \frac1N\mathbf X\T\mathbf X \quad(\text{rows of }\mathbf X\text{ centred}).\]
Reading the formula

\(\Sigma\) (capital sigma, not a sum here) is \(d\times d\). Entry \((j, j)\) is the variance of feature \(j\). Entry \((j, k)\) is the covariance of features \(j\) and \(k\). It is positive if they tend to rise together, negative if one rises as the other falls.

Example. Points \((1, 1), (-1, -1), (2, 2), (-2, -2)\), mean \((0, 0)\). \(\Sigma_{11} \)\({}= \frac14(1 + 1 + 4 + 4)\)\({}= 2.5\), \(\Sigma_{22} = 2.5\), \(\Sigma_{12} \)\({}= \frac14(1 + 1 + 4 + 4)\)\({}= 2.5\). So \(\Sigma \)\({}= \begin{bmatrix} 2.5 & 2.5 \\ 2.5 & 2.5 \end{bmatrix}\). Its eigenvalues are \(5\) and \(0\) (the \(a \pm b\) rule), with eigenvectors along \([1,1]\) and \([-1,1]\). All the spread is along \([1,1]\), the line the points lie on.

The variance of the data projected onto a unit vector \(\mathbf v\) is \(\frac1N\sum(\mathbf v\T\mathbf x_i)^2 \)\({}= \mathbf v\T\Sigma\mathbf v\). That is why PCA becomes the eigenvector problem of section 1.9.

Write this in the exam

Show that the line through the mean that minimises the sum of squared perpendicular distances points along the top eigenvector of \(\Sigma\).

  1. Centre the data. The line is \(\{t\mathbf w\}\) with \(\|\mathbf w\| = 1\). The projection of \(\mathbf x_i\) is \((\mathbf w\T\mathbf x_i)\mathbf w\).
    Why (3 steps)
    1. Subtract the mean from every point, so the best line passes through the origin. (The mean is the best single point, by the L05 question above.)
    2. A line through the origin is all multiples of a unit direction \(\mathbf w\).
    3. The closest point on the line to \(\mathbf x_i\) is its projection, which is the component \(\mathbf w\T\mathbf x_i\) along \(\mathbf w\), times \(\mathbf w\).
  2. The squared perpendicular distance is \(\|\mathbf x_i\|^2 - (\mathbf w\T\mathbf x_i)^2\).
    Why (2 steps)
    1. The point, its projection and the origin form a right-angled triangle. The hypotenuse is \(\|\mathbf x_i\|\), one side is \(|\mathbf w\T\mathbf x_i|\), and the other side is the perpendicular distance.
    2. By Pythagoras, distance² = hypotenuse² − side² \(= \mathbf x_i\T\mathbf x_i - (\mathbf w\T\mathbf x_i)^2\).
  3. \(\min_{\mathbf w}\sum_i\left(\|\mathbf x_i\|^2 - (\mathbf w\T\mathbf x_i)^2\right)\) is the same as \(\max_{\mathbf w}\sum_i(\mathbf w\T\mathbf x_i)^2\).
    Why (2 steps)
    1. \(\sum\|\mathbf x_i\|^2\) does not depend on \(\mathbf w\).
    2. So making the total smaller means making the subtracted part larger.
  4. \(\sum_i(\mathbf w\T\mathbf x_i)^2 \)\({}= \mathbf w\T\mathbf X\T\mathbf X\mathbf w\)\({}= N\,\mathbf w\T\Sigma\mathbf w\).
    Why (3 steps)
    1. \((\mathbf w\T\mathbf x_i)^2 \)\({}= (\mathbf w\T\mathbf x_i)(\mathbf x_i\T\mathbf w)\)\({}= \mathbf w\T\mathbf x_i\mathbf x_i\T\mathbf w\).
    2. Sum over \(i\) and take \(\mathbf w\) outside. \(\mathbf w\T\left(\sum_i\mathbf x_i\mathbf x_i\T\right)\mathbf w\).
    3. \(\sum_i\mathbf x_i\mathbf x_i\T \)\({}= \mathbf X\T\mathbf X\)\({}= N\Sigma\) for centred rows.
  5. Maximise \(\mathbf w\T\Sigma\mathbf w\) with \(\mathbf w\T\mathbf w = 1\). Then \(\mathbf w\) is the eigenvector of \(\Sigma\) (equally of \(\mathbf X\T\mathbf X\)) with the largest eigenvalue.
    Why (2 steps)
    1. The factor \(N\) does not change where the maximum is.
    2. Section 1.9 shows the maximiser is the top eigenvector, and the maximum value \(\mathbf w\T\Sigma\mathbf w \)\({}= \lambda_1\) is the variance along it.

Page 2 does the same with the reconstruction error written out in full (PCA as minimising reconstruction loss). The second, third and further components are the next eigenvectors. Each is at right angles to the earlier ones and captures the most remaining variance.

The algorithm

  1. Input: \(N\) samples of dimension \(D\).
  2. Compute the mean \(\boldsymbol\mu\) and the covariance \(\Sigma \)\({}= \frac1N\sum(\mathbf x_i - \boldsymbol\mu)(\mathbf x_i - \boldsymbol\mu)\T\).
  3. Compute the eigenvalues and eigenvectors of \(\Sigma\).
  4. Keep the \(d\) eigenvectors with the largest eigenvalues.
  5. Put them as the rows of \(\mathbf A\), a \(d\times D\) matrix.
  6. Represent each point as \(\mathbf x' \)\({}= \mathbf A(\mathbf x - \boldsymbol\mu)\). Reconstruct with \(\hat{\mathbf x} \)\({}= \boldsymbol\mu + \mathbf A\T\mathbf x'\).

Reconstruction

In any orthonormal basis \(\mathbf u_1, \dots, \mathbf u_d\), a vector is the sum of its components, \(\mathbf x \)\({}= \sum_j(\mathbf x\T\mathbf u_j)\mathbf u_j\). Keeping only some of the terms gives an approximation. On the slide, \(\alpha_1 \)\({}= \mathbf x\T\mathbf u_1\)\({}= \frac{3.3 + 3}{\sqrt2}\)\({}= \frac{6.3}{\sqrt2}\) and \(\alpha_2 \)\({}= \frac{-3.3 + 3}{\sqrt2}\)\({}= \frac{-0.3}{\sqrt2}\). Keeping \(\alpha_1\) only, \(\hat{\mathbf x} \)\({}= \alpha_1\mathbf u_1\)\({}= \frac{6.3}{\sqrt2}\cdot\frac1{\sqrt2}[1, 1]\)\({}= [3.15, 3.15]\). The error is \(\|\mathbf x - \hat{\mathbf x}\| \)\({}= \|[0.15, -0.15]\|\)\({}= |\alpha_2| \approx 0.21\), exactly the dropped component.

Two class examples

In example I the points already have mean \((0, 0)\). \(\sum x^2 \)\({}= 4 + 1 + 1 + 0 + 0 + 1 + 0 + 1 + 4\)\({}= 12\), the same for \(y\), and \(\sum xy \)\({}= 4 + 1 + 0 + 0 + 0 + 0 + 0 + 1 + 4\)\({}= 10\). So \(\Sigma \)\({}= \frac19\begin{bmatrix} 12 & 10 \\ 10 & 12 \end{bmatrix}\). By the \(a \pm b\) rule the bracketed matrix has eigenvalues 22 and 2, which the slide reports. The eigenvalues of \(\Sigma\) itself are \(\frac{22}9\) and \(\frac29\). The first component \([1,1]\) keeps \(\frac{22}{24} \approx 92\%\) of the variance.

Example II has every point on the line \(y = x\), so there is no spread at all along \([-1, 1]\) and \(\lambda_2 = 0\). One number per point loses nothing. (The slide lists 10 points but says nine, and the second \([1, 1]\) looks like a typo for \([0,0]\) or a repeat. The conclusion \(\lambda_2 = 0\) holds either way, since every point is on the line.)

How many components to keep?

Each eigenvalue is the variance along its eigenvector, and the eigenvalues add up to the total variance. So keep the smallest \(d\) for which

\[ \frac{\sum_{i=1}^d\lambda_i}{\sum_{i=1}^D\lambda_i} \ge 0.95. \]

That keeps 95% of the variance. Real eigenvalue spectra drop steeply, so \(d\) is often far smaller than \(D\).

Example

Eigenvalues 50, 30, 10, 6, 3, 1 (total 100). Cumulative fractions: 0.50, 0.80, 0.90, 0.96, 0.99, 1.00. The first to reach 0.95 is at \(d = 4\).

Remember
  • PCA directions are the eigenvectors of the covariance matrix, in order of decreasing eigenvalue.
  • Max variance, min perpendicular distance and min reconstruction error all give the same directions.
  • Always subtract the mean first. \(\mathbf x' \)\({}= \mathbf A(\mathbf x - \boldsymbol\mu)\), \(\hat{\mathbf x} \)\({}= \boldsymbol\mu + \mathbf A\T\mathbf x'\).
  • Sum of squared reconstruction errors \(= N\times\) (sum of the dropped eigenvalues).

1.13Eigenfaces and the small-matrix trick

Lectures L06, L07 · Short video: Eigen faces

Treat every face image as one long vector and run PCA. The eigenvectors look like ghostly faces.

A \(100\times100\) grey image has \(10^4\) pixels. Reading the pixels row after row gives a vector in \(\R^{10^4}\). Frontal, aligned faces are all quite similar, so these vectors lie close to a low-dimensional subspace. PCA on a set of face images gives eigenvectors that, reshaped back into \(100\times100\), look like faces. They are called eigenfaces. Any face is then approximately the mean face plus a weighted sum of a few dozen eigenfaces, and the weights (a short vector) can be used to recognise the person.

The problem with the covariance matrix

With \(d = 10^4\) pixels, \(\Sigma\) is \(10^4\times10^4\), which has \(10^8\) entries. Finding its eigenvectors is very slow. But with only \(N = 200\) images, the centred data have rank at most 199 (the centred rows add up to zero, which removes one more dimension). So at most 199 eigenvalues are non-zero, and only those eigenvectors matter.

Write this in the exam

Get the eigenvectors of \(\mathbf X\mathbf X\T\) (\(d\times d\), large) from those of \(\mathbf X\T\mathbf X\) (\(N\times N\), small). Here \(\mathbf X\) is \(d\times N\) with centred images as columns.

  1. Solve the small problem \(\mathbf X\T\mathbf X\mathbf v \)\({}= \lambda\mathbf v\) (\(N\times N\)).
  2. Multiply on the left by \(\mathbf X\). \(\mathbf X\mathbf X\T(\mathbf X\mathbf v) \)\({}= \lambda(\mathbf X\mathbf v)\).
    Why (2 steps)
    1. \(\mathbf X(\mathbf X\T\mathbf X\mathbf v) \)\({}= \mathbf X(\lambda\mathbf v)\). Regroup the left side as \((\mathbf X\mathbf X\T)(\mathbf X\mathbf v)\), and pull the number \(\lambda\) out on the right.
    2. This says \(\mathbf u = \mathbf X\mathbf v\) is an eigenvector of \(\mathbf X\mathbf X\T\) with the same eigenvalue \(\lambda\).
  3. Normalise. \(\mathbf u \)\({}= \mathbf X\mathbf v / \|\mathbf X\mathbf v\|\), and \(\|\mathbf X\mathbf v\| \)\({}= \sqrt\lambda\) when \(\|\mathbf v\| = 1\).
    Why (2 steps)
    1. \(\|\mathbf X\mathbf v\|^2 \)\({}= \mathbf v\T\mathbf X\T\mathbf X\mathbf v\)\({}= \mathbf v\T(\lambda\mathbf v)\)\({}= \lambda\).
    2. So divide by \(\sqrt\lambda\) to get a unit eigenvector. This is the SVD relation \(\mathbf u_i \)\({}= \mathbf X\mathbf v_i / d_i\) from section 1.11.
  4. So both matrices have the same non-zero eigenvalues, and the large problem's eigenvectors are \(\mathbf X\) times the small problem's. The cost is a \(200\times200\) eigenproblem instead of \(10^4\times10^4\).
Remember
  • For \(N\) images of \(d\) pixels, \(\Sigma\) is \(d\times d\) but its rank is at most \(N - 1\).
  • \(\mathbf X\mathbf X\T\) and \(\mathbf X\T\mathbf X\) share their non-zero eigenvalues. Eigenvectors are linked by \(\mathbf u \)\({}= \mathbf X\mathbf v / \sqrt\lambda\).
  • For effective rank, images of only a few people, or near-duplicates, give few large eigenvalues.

Streaming mean and variance

When samples arrive one at a time, keep the running mean \(\mu_N\) and variance \(\sigma_N^2\) (dividing by \(N\)) instead of the whole data set. When \(x_{N+1}\) arrives:

\[\mu_{N+1} = \frac{N\mu_N + x_{N+1}}{N + 1}, \qquad \sigma_{N+1}^2\] \[{}= \frac{N\sigma_N^2 + (x_{N+1} - \mu_N)(x_{N+1} - \mu_{N+1})}{N + 1}.\]
Reading the formula

\(N\mu_N\) is the old total. Adding the new value and dividing by the new count gives the new mean. For the variance, \(N\sigma_N^2\) is the old sum of squared deviations. The new point adds roughly its squared deviation, but measured once from the old mean and once from the new one, which corrects for the mean having moved. This is Welford's method.

Example. Data 2, 4, 4 have \(\mu_3 \)\({}= \frac{10}3 \approx 3.333\) and \(\sigma_3^2 \)\({}= \frac13(1.778 + 0.444 + 0.444)\)\({}= 0.889\). Now 5 arrives. \(\mu_4 = \frac{10 + 5}4 = 3.75\). \(\sigma_4^2 \)\({}= \frac{3 \times 0.889 + (5 - 3.333)(5 - 3.75)}4\)\({}= \frac{2.667 + 2.083}4\)\({}= 1.1875\). Computed directly, \(\frac14(1.75^2 + 0.25^2 + 0.25^2 + 1.25^2) \)\({}= \frac{4.75}4\)\({}= 1.1875\). They match.

This is used for data too large to store, sensor streams, and batch normalisation's running statistics in neural networks.

Linear maps and k-NN

L06 slide\(\mathbf x' \)\({}= \mathbf W\mathbf x\) with square \(\mathbf W\). Is k-NN (same \(K\), Euclidean distance) equally accurate on \(\mathbf x\) and \(\mathbf x'\) for every \(\mathbf W\)? If not, when is it guaranteed? What if \(\mathbf W = \mathbf 0\) or \(|\mathbf W| = 0\)?›
  1. k-NN only uses the order of distances. Distances in the new space are \(\|\mathbf W(\mathbf p - \mathbf q)\|\).
  2. Not for every \(\mathbf W\). For example, \(\mathbf W \)\({}= \operatorname{diag}(1, 1000)\) blows up feature 2, which changes which points are nearest (the units problem of section 1.4).
  3. It is guaranteed when \(\mathbf W\) preserves all distances up to one common factor, that is \(\mathbf W = c\mathbf R\) with \(\mathbf R\) orthogonal (\(\mathbf R\T\mathbf R \)\({}= \mathbf I\), a rotation or reflection) and \(c \ne 0\). Then \(\|\mathbf W(\mathbf p - \mathbf q)\| \)\({}= |c|\,\|\mathbf p - \mathbf q\|\) and the order of distances is unchanged.
  4. \(\mathbf W = \mathbf 0\) maps every point to \(\mathbf 0\). All distances are 0, every point is a tie, and the classifier is useless.
  5. \(|\mathbf W| = 0\) (determinant zero, singular) collapses some direction to zero. Points that differed only in that direction become identical, so information is lost and accuracy usually drops. PCA is a deliberate, controlled version of this, dropping only low-variance directions.
L06 slideRaju and Sheela use the same data but list the features in different orders. Which are true?   1. Reordering features is \(\mathbf x' \)\({}= \mathbf P\mathbf x\) with a permutation matrix \(\mathbf P\), which is orthogonal. Distances do not change, so (a) true and (b) false.
  2. The predictions are identical, so the confusion matrix is identical. The confusion matrix is indexed by classes, not features. (c) false.

Mahalanobis distance as a transformation

L06 slideFor \(\mathbf x = [x_1, x_2]\), write the z-score normalisation as \(\mathbf x' \)\({}= \mathbf L(\mathbf x - \boldsymbol\mu)\). What should a matrix be so that Euclidean distance after transforming equals the Mahalanobis distance before?›
  1. z-score: \(x_j' = (x_j - \mu_j)/\sigma_j\). In matrix form \(\mathbf L \)\({}= \begin{bmatrix} 1/\sigma_1 & 0 \\ 0 & 1/\sigma_2 \end{bmatrix}\)\({}= \Sigma^{-1/2}\) for a diagonal \(\Sigma \)\({}= \operatorname{diag}(\sigma_1^2, \sigma_2^2)\).
  2. The squared Euclidean distance after the map is \(\|\mathbf L\mathbf x - \mathbf L\mathbf y\|^2 \)\({}= (\mathbf x - \mathbf y)\T\mathbf L\T\mathbf L(\mathbf x - \mathbf y)\).
  3. The squared Mahalanobis distance is \((\mathbf x - \mathbf y)\T\Sigma^{-1}(\mathbf x - \mathbf y)\).
  4. They are equal for all \(\mathbf x, \mathbf y\) when \(\mathbf L\T\mathbf L \)\({}= \Sigma^{-1}\). For a general (non-diagonal) \(\Sigma \)\({}= \mathbf Q\Lambda\mathbf Q\T\), one choice is \(\mathbf L \)\({}= \Lambda^{-1/2}\mathbf Q\T\). It rotates onto the eigenvectors, then divides each coordinate by its standard deviation \(\sqrt{\lambda_i}\). This is called whitening.

Other L06 discussion points

  • Why is PCA (the KL transform) not used in JPEG? The PCA basis depends on the data, so it would have to be computed for every image and sent along with it, and computing it is expensive. The DCT basis is fixed and known in advance, fast to compute, and for natural images it is almost as good as the PCA basis.
  • Why does a model trained only on training data work on test data? None of the five options on the slide (luck, magic and so on) is the reason. It works because we assume the training and test data are drawn from the same distribution, and because the model is kept simple enough not to memorise noise. Page 2 covers this as generalisation.
L06 slideA disease affects 1% of people. The test is 90% accurate both ways. Given a positive test, what is the chance the person has the disease?›
Formula
Bayes' rule, \(P(D \mid +) \)\({}= \dfrac{P(+ \mid D)P(D)}{P(+ \mid D)P(D) + P(+ \mid \bar D)P(\bar D)}\). \(\bar D\) means "not diseased".
Where it comes from
Maths basics, Bayes' rule.
Working
  1. \(P(D) = 0.01\), \(P(\bar D) = 0.99\), \(P(+ \mid D) = 0.9\), \(P(+ \mid \bar D) = 0.1\).
  2. Top: \(0.9 \times 0.01 = 0.009\).
  3. Bottom: \(0.009 + 0.1 \times 0.99 \)\({}= 0.009 + 0.099\)\({}= 0.108\).
  4. \(P(D \mid +) \)\({}= 0.009 / 0.108 \approx 0.083\), about 8%.
  5. Check with counts. Of 1000 people, 10 are sick and 9 test positive. Of 990 healthy, 99 test positive. So 9 of 108 positives are sick, \(\frac9{108} \approx 8\%\).
L06 slideTwo equally likely classes \(N(23, 2)\) and \(N(33, 2)\) (mean, variance) have the best threshold 28. If the variance of the second class doubles, does the threshold go up or down?›
  1. The best threshold is where the two class densities are equal (page 2, Bayes decision). With equal variances that is the midpoint, 28.
  2. If class 2's variance becomes 4, its density is spread out, so its height near its own mean, and between the two means, is lower relative to its tails. Near 28, class 1's density now wins slightly.
  3. So the crossing point moves towards class 1, so the threshold decreases. Solving \(\frac1{\sqrt{2\pi\cdot2}}e^{-(x-23)^2/4} \)\({}= \frac1{\sqrt{2\pi\cdot4}}e^{-(x-33)^2/8}\) numerically gives \(x \approx 27.24\).
  4. With unequal variances there is also a second crossing far to the left of 23, where the wider class-2 curve overtakes again. For days in this range it does not matter.
L06 slideA man tells the truth 2 times out of 3. He throws a die and reports a four. What is the probability it really was a four?›
  1. Let \(F\) be "the die shows four". \(P(F) = \frac16\), \(P(\bar F) = \frac56\).
  2. If it was a four, he reports four when he tells the truth, so \(P(\text{says }4 \mid F) \)\({}= \frac23\).
  3. If it was not a four, he reports four only if he lies. The usual textbook assumption is that a lie means saying "four" when it was not, so \(P(\text{says }4 \mid \bar F) \)\({}= \frac13\).
  4. Bayes: \(\frac{\frac16\cdot\frac23}{\frac16\cdot\frac23 + \frac56\cdot\frac13} \)\({}= \frac{\frac2{18}}{\frac2{18} + \frac5{18}}\)\({}= \frac27\).
  5. If instead a lie picks one of the 5 wrong faces at random, \(P(\text{says }4 \mid \bar F) \)\({}= \frac13\cdot\frac15\)\({}= \frac1{15}\), and the answer becomes \(\frac{\frac19}{\frac19 + \frac1{18}} \)\({}= \frac23\). State your assumption in the exam. The slide does not specify it.
