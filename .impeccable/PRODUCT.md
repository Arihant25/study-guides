# Product

## Who it is for
IIIT Hyderabad students revising for a quiz or exam, usually the night before, often on a phone. Some open a guide from a link a friend sent in a group chat. Most know which course they want and nothing else.

## What the home page must do
Get a student to the right guide (or the right part of it) in one tap. Tell a newcomer what a guide is like before they open one.

## Constraints
- Static GitHub Pages site. No build step, no framework, no JavaScript needed to read the page.
- Each guide keeps its own design. The home page must not restyle them.
- New guides get added every semester, so adding one has to be a copy-paste of one block.
- Platform: web. Phones first.

## Non-goals
Marketing, stats, testimonials, sign-ups.
