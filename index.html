Notes for IIIT Hyderabad courses

We made these for our own coursework, one for each course we took. Every guide assumes you have never seen the material, so it explains each symbol where it first appears and works through the past papers where they exist.

They are plain web pages, so they load fast on a phone and print cleanly. If you find a mistake, open an issue.

EC5.406sdet

Signal Detection and Estimation Theory (Detection Theory)

The detection half of the course, in the order of the lectures. It starts with the likelihood ratio test and ends with Wald's sequential test. Each proof done in class is written out in full, and each homework and classwork problem is solved. Chapter 13 solves Assignment 4, the Nov 2026 end-sem paper, and the detection questions from the 2024 and 2025 papers.

EC5.201sp

Signal Processing

Signals and systems, then digital signal processing, from the definition of a signal to the FFT. In between it covers convolution, Fourier series and the Fourier transform, the Laplace transform, sampling, the DTFT, the z-transform, filters through poles and zeros, and the DFT. Each chapter uses the ones before it. The last chapter is a quick reference with a self-test.
