Notes for IIIT Hyderabad courses

I write one of these for each course I take. Every guide assumes you have never seen the material, so it explains each symbol where it first appears and works through the past papers where they exist.

They are plain web pages, so they load fast on a phone and print cleanly. If you find a mistake, open an issue.
