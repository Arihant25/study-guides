Part 8Scale-free networks

19Hubs, growth and preferential attachment

Deck 14 · slides 1–32

The random graph of the Mid-sem guide gives every node about the same number of links. Real networks do not look like that. The Web, the cell and the film-actor network all have a few nodes with a huge number of links, called hubs, next to a great many nodes with very few. This section says why the random graph cannot make hubs, and gives the model that does: the Barabási–Albert (BA) model.

What the exam can ask
  • Name the two ingredients of the BA model and say what each one means. Asked in 2024 Quiz 2 (§29).
  • Write the preferential attachment probability \(\Pi(k_i) = k_i/\sum_jk_j\).
  • Say what "scale-free" means, and why the Erdős–Rényi model fails to produce hubs.

What was measured

In 1999 Barabási and Albert sent a crawler through the nd.edu web domain: about 300,000 pages, with an average of 11 clicks between two pages. Two things stood out. Distances were short (for the 800 million pages of the 1999 Web the estimate was only 19 clicks, not thousands). And there were hubs: in one study 82% of pages had fewer than 3 incoming links, while 42 pages had more than 1000.

The degree distribution was a power law, \(P(k)\sim k^{-\gamma}\), a straight line on log-log axes (Mid-sem guide §1), not the bell-shaped Poisson curve of a random graph. A network whose degree distribution is a power law is called scale-free. The name says that there is no typical degree: the ratio of hubs to ordinary nodes stays the same as the network grows, so a small copy looks like a scaled version of the large one.

The Barabási–Albert model

Start with \(m_0\) nodes. Then repeat two steps.

  1. Growth. At each time step add one new node with \(m\) links (\(m\le m_0\)) that connect it to \(m\) nodes already in the network.
  2. Preferential attachment. The probability that a link of the new node goes to node \(i\) is proportional to the degree of node \(i\):
\[\Pi(k_i) = \frac{k_i}{\sum_j k_j}\]

\(k_i\) is the degree of node \(i\) now. The sum in the bottom runs over all nodes already in the network, so the probabilities add up to 1. \(m\) is the number of links each new node brings. \(m_0\) is the number of starting nodes.

This is a rule about chances. A new node may still link to a node with one link. But a node with 4 links is twice as likely to be chosen as a node with 2 links. The rich get richer.

After \(t\) steps the network has \(N = t + m_0\) nodes and \(m_0 + mt\) links. Its degree distribution is a power law with exponent \(\gamma = 3\). The next two sections derive this.

Numbers

A network has four nodes with degrees 1, 2, 3 and 6, so \(\sum_jk_j = 12\). A new node arrives with one link. The chances are \(\frac1{12}\), \(\frac2{12}\), \(\frac3{12}\) and \(\frac6{12}\). The node with degree 6 gets the link half the time.

The questions on slide 58 · derived on the End-sem sheet
  • Growth without preferential attachment (new nodes pick partners at random): the degree distribution decays exponentially, so there are no hubs.
  • Preferential attachment without growth (fixed \(N\), keep adding links): there is no steady distribution. The network keeps filling up until every node is linked to every other.
  • So both ingredients are needed together.
  • Measuring preferential attachment: follow a real network over time and plot how many new links a node gains in a short interval against its degree \(k\). A straight line through the origin means \(\Pi\propto k\).
  • Nonlinear preferential attachment, \(\Pi\propto k^\alpha\): for \(\alpha<1\) the hubs are smaller than in the BA model, for \(\alpha = 1\) we get the BA model, and for \(\alpha>1\) a few nodes take almost all the links (winner takes all).
What to remember
  • Scale-free: \(P(k)\sim k^{-\gamma}\), hubs exist, no typical degree.
  • BA model = growth (one node with \(m\) links per step) + preferential attachment \(\Pi(k_i) = k_i/\sum_jk_j\).
  • After \(t\) steps: \(N = t + m_0\) nodes, \(m_0 + mt\) links, \(\gamma = 3\).

ExplainWhy can the Erdős–Rényi model not produce hubs?›

It has a fixed number of nodes and every pair is linked with the same probability, so every node gets about ⟨k⟩ links and the Poisson distribution falls off very fast for large \(k\). Hubs need growth (old nodes have had more time) and preferential attachment (nodes with many links collect more).

20How the degree of a node grows

Deck 14 · slides 33–44

Follow one node of the BA model through time. It joins with \(m\) links, and every later arrival may give it one more. This section finds its degree as a function of time. The result explains hubs in one line: a node's degree depends only on when it joined, and the earliest nodes are the largest.

What the exam can ask
  • Prove that \(\frac{dk_i}{dt} = \frac{k_i}{2t}\), that is, the rate at which a node gains links is proportional to \(k_i/t\). Asked in 2024 Quiz 2.
  • Solve it to get \(k_i(t) = m\,(t/t_i)^{1/2}\) and name the dynamical exponent \(\beta = \frac12\).
  • Explain the first-mover advantage and why the growth is slower than linear.
Derivation to learn · the degree of node \(i\) over time
  1. Treat the degree as a smooth quantity. \(k_i\) really jumps by whole numbers. We replace it by its average over many runs of the model, which changes smoothly, so we can write a differential equation for it.
  2. Rate of gaining links. Each time step one new node arrives with \(m\) links. Each of the \(m\) links picks node \(i\) with probability \(\Pi(k_i)\). So node \(i\) has \(m\) chances per step: \[\frac{dk_i}{dt} = m\,\Pi(k_i) = m\,\frac{k_i}{\sum_{j=1}^{N-1}k_j}.\] The sum runs over all nodes except the one being added.
  3. Find the sum. Every link adds 2 to the total degree (one for each end). After \(t\) steps there are about \(mt\) links, so the total degree is \(2mt\). Leaving out the \(m\) of the new node: \[\sum_{j=1}^{N-1}k_j = 2mt - m.\]
  4. Put it in. \[\frac{dk_i}{dt} = \frac{mk_i}{2mt - m} = \frac{k_i}{2t - 1}\approx\frac{k_i}{2t}\quad\text{for large } t.\] This is the first exam result: the rate is proportional to \(k_i/t\).
  5. Separate the variables. \[\frac{dk_i}{k_i} = \frac12\,\frac{dt}{t}.\]
  6. Integrate from the moment the node joined, \(t_i\), when it had \(k_i(t_i) = m\) links, up to time \(t\): \[\ln\frac{k_i(t)}{m} = \frac12\ln\frac{t}{t_i}.\]
  7. Result. \[k_i(t) = m\Big(\frac{t}{t_i}\Big)^{\beta},\qquad\beta = \frac12.\]

\(t\) is the time now, which is also the number of nodes added so far. \(t_i\) is the time when node \(i\) joined. \(m\) is the number of links each node arrives with. \(\beta\) is called the dynamical exponent.

What the result says

  • Every node follows the same law. The degree of each node grows as \(t^{1/2}\). Only the starting time \(t_i\) differs.
  • First-mover advantage. A smaller \(t_i\) gives a larger \(k_i(t)\). Hubs are large because they arrived early.
  • Growth is sublinear (\(\beta<1\)). Each new node has more nodes to choose from than the one before, so every existing node competes for links with a growing crowd.
  • The rate slows down. Differentiate the result: \[\frac{dk_i}{dt} = \frac m2\,\frac{1}{\sqrt{t_i\,t}}.\] Older nodes (small \(t_i\)) gain more links per step, and for every node the rate falls as \(t^{-1/2}\). This is the same equation as \(\frac{dk_i}{dt} = \frac{k_i}{2t}\) with the result for \(k_i\) put in.
Numbers

\(m = 2\). Node A joined at \(t_A = 10\), node B at \(t_B = 1000\). At \(t = 100{,}000\): \(k_A = 2\sqrt{100000/10} = 2\times100 = 200\), and \(k_B = 2\sqrt{100000/1000} = 2\times10 = 20\). A joined 100 times earlier and has \(\sqrt{100} = 10\) times the degree.

What to remember
  • \(\frac{dk_i}{dt} = m\Pi(k_i) = \frac{mk_i}{2mt - m}\approx\frac{k_i}{2t}\).
  • \(k_i(t) = m\,(t/t_i)^{1/2}\), with \(k_i(t_i) = m\). Dynamical exponent \(\beta = \frac12\).
  • \(\frac{dk_i}{dt} = \frac{m}{2\sqrt{t_it}}\): old nodes gain faster, and everyone slows down.

21The degree distribution of the BA model

Deck 14 · slides 45–59, 68, 89

Now turn the growth law of one node into the degree distribution of the whole network. The trick is that degree and joining time are tied together, and joining times are spread evenly. The answer is \(P(k) = 2m^2k^{-3}\): a power law with exponent 3, whatever \(m\) is.

What the exam can ask
  • Derive \(P(k) = 2m^2k^{-3}\) from \(k_i(t) = m(t/t_i)^{1/2}\) (continuum theory).
  • Write the rate equation for the number of degree-\(k\) nodes and get \(P(k) = \frac{2m(m+1)}{k(k+1)(k+2)}\).
  • State the three properties: \(\gamma = 3\) independent of \(m\), independent of time, coefficient \(\propto m^2\).
Derivation to learn · continuum theory
  1. Invert the growth law. From \(k_i = m(t/t_i)^{1/2}\): \[t_i = \frac{m^2t}{k_i^2}.\] A larger degree means an earlier joining time.
  2. Turn a question about degree into one about time. A node has degree less than \(k\) exactly when it joined too late to reach \(k\): \[P(k_i\frac{m^2t}{k^2}\Big).\]

In words: degree grows as \(t^{1/2}\) and joining times are uniform, so the number of nodes with degree above \(k\) falls as \(1/k^2\), and the distribution falls as \(1/k^3\).

Derivation to learn · the rate equation (exact answer)

The continuum theory treats \(k\) as smooth. The rate equation counts whole nodes, and gives the exact distribution. Let \(P(k,t)\) be the fraction of nodes with degree \(k\) at time \(t\). With one node added per step, \(N = t\), so the number of degree-\(k\) nodes is \(N\,P(k,t)\).

  1. Preferential attachment with the sum filled in. \(\sum_jk_j = 2mt\), so \[\Pi(k) = \frac{k}{2mt}.\]
  2. Links that land on degree-\(k\) nodes in one step. (chance per node) × (number of such nodes) × (links of the new node): \[\frac{k}{2mt}\times N\,P(k,t)\times m = \frac k2\,P(k,t).\] Each such link turns a degree-\(k\) node into a degree-\((k+1)\) node.
  3. Balance for \(k>m\). Degree-\(k\) nodes are gained from degree \(k-1\) and lost to degree \(k+1\): \[(N+1)P(k,t+1) = N\,P(k,t) + \frac{k-1}{2}P(k-1,t) - \frac k2P(k,t).\]
  4. Balance for \(k = m\). No node has fewer than \(m\) links, so nothing comes up from below. Instead the new node itself arrives with degree \(m\), which adds 1: \[(N+1)P(m,t+1) = N\,P(m,t) + 1 - \frac m2P(m,t).\]
  5. Steady state. For large \(t\) assume \(P(k,t)\) stops changing and call it \(P(k)\). Then \((N+1)P(k) - N\,P(k) = P(k)\), so the left side minus the first term on the right is just \(P(k)\): \[P(k) = \frac{k-1}{2}P(k-1) - \frac k2P(k),\qquad P(m) = 1 - \frac m2P(m).\]
  6. Solve each for \(P\). \[P(k) = \frac{k-1}{k+2}\,P(k-1)\quad(k>m),\qquad P(m) = \frac{2}{m+2}.\]
  7. Climb up from \(m\). \[P(m+1) = \frac{m}{m+3}P(m) = \frac{2m}{(m+2)(m+3)},\] \[P(m+2) = \frac{m+1}{m+4}P(m+1) = \frac{2m(m+1)}{(m+2)(m+3)(m+4)},\] \[P(m+3) = \frac{m+2}{m+5}P(m+2) = \frac{2m(m+1)}{(m+3)(m+4)(m+5)}.\] The pattern: the top stays \(2m(m+1)\) and the bottom is three numbers in a row ending two above the degree.
  8. Result. \[P(k) = \frac{2m(m+1)}{k(k+1)(k+2)}\;\sim\;2m^2k^{-3}\quad\text{for large }k.\]

Check with \(k = m\): \(\frac{2m(m+1)}{m(m+1)(m+2)} = \frac{2}{m+2}\), which matches step 6. Slide 56 rewrites the recursion as \(P(k+1) = \frac{k}{k+2}P(k)\); as the slide's own note says, the bottom should be \(k+3\).

Three things the result predicts

  1. The exponent \(\gamma = 3\) does not depend on \(m\).
  2. The distribution does not depend on time or on \(N\). The network keeps growing but its degree distribution stays the same: a stationary scale-free state. This fits real networks of very different ages and sizes having the same kind of distribution.
  3. The coefficient is proportional to \(m^2\).

22The largest hub and the role of the exponent

Deck 14 · slides 60–67 · Deck 15 · slides 1–5

A real network is finite, so its largest degree is finite too. This section estimates the degree of the biggest hub, \(k_{\max}\), from the power law. It grows as a power of \(N\), far faster than in a random network. The same exponent \(\gamma\) also sorts networks into three regimes.

What the exam can ask
  • Normalise a power law in the discrete and the continuous form.
  • Derive \(k_{\max} = k_{\min}N^{1/(\gamma-1)}\).
  • Say what happens to \(k_{\max}\), ⟨k⟩ and ⟨k²⟩ for \(\gamma<2\), \(2<\gamma<3\) and \(\gamma>3\).

\(\zeta(\gamma) = \sum_{k=1}^\infty k^{-\gamma}\) is the Riemann zeta function, just a name for that sum. \(k_{\min}\) is the smallest degree in the network. The continuous constant is derived in the Mid-sem guide §1.

Derivation to learn · the size of the largest hub
  1. The idea. In a network of \(N\) nodes we expect about one node with degree above \(k_{\max}\). So the probability of a degree above \(k_{\max}\) is about \(1/N\): \[\int_{k_{\max}}^\infty P(k)\,dk\approx\frac1N.\] This is called the natural upper cutoff.
  2. Do the integral with \(P(k) = (\gamma-1)k_{\min}^{\gamma-1}k^{-\gamma}\): \[\int_{k_{\max}}^\infty P(k)\,dk = (\gamma-1)k_{\min}^{\gamma-1}\Big[\frac{k^{-\gamma+1}}{-\gamma+1}\Big]_{k_{\max}}^\infty = \frac{k_{\min}^{\gamma-1}}{k_{\max}^{\gamma-1}}.\]
  3. Set it equal to \(1/N\) and solve: \(\Big(\dfrac{k_{\max}}{k_{\min}}\Big)^{\gamma-1} = N\), so \[k_{\max} = k_{\min}\,N^{\frac{1}{\gamma-1}}.\]
Numbers from the slides · the Web sample

\(N\approx3\times10^5\) pages, \(k_{\min} = 1\).

  • If the degrees followed an exponential \(e^{-\lambda k}\) with \(\lambda = 1\), then \(k_{\max}\approx k_{\min} + \frac{\ln N}{\lambda} = 1 + 12.6\approx14\).
  • Scale-free with \(\gamma = 2.1\): \(k_{\max} = N^{1/1.1} = (3\times10^5)^{0.909}\approx95{,}000\).
  • Measured: the largest in-degree in the sample is 10,721, the scale-free order of magnitude and nowhere near 14.

In a random network hubs are effectively forbidden. In a scale-free network they come naturally.

What to remember
  • Discrete: \(p_k = k^{-\gamma}/\zeta(\gamma)\). Continuous: \(p(k) = (\gamma-1)k_{\min}^{\gamma-1}k^{-\gamma}\).
  • \(\int_{k_{\max}}^\infty P(k)\,dk\approx1/N\) gives \(k_{\max} = k_{\min}N^{1/(\gamma-1)}\).

\(1/(\gamma-1)>1\), so \(k_{\max}\) grows faster than \(N\). For large \(N\) the biggest hub would need more links than there are other nodes, which is impossible without repeated links.

23Distances in scale-free networks

Deck 14 · slides 69–88

How many steps separate two nodes? For a random graph the answer was \(\ln N/\ln\langle k\rangle\). This section repeats that counting argument for any degree distribution. The only change is that a neighbour reached along a link has more links than an average node, the friendship paradox of the Mid-sem guide. With hubs, distances become even shorter than in a random graph.

What the exam can ask
  • Show that the number of second neighbours is \(z_2 = \langle k^2\rangle - \langle k\rangle\), and that it is \(\langle k\rangle^2\) for a Poisson network.
  • Derive \(L = 1 + \dfrac{\ln(N/\langle k\rangle)}{\ln\big[(\langle k^2\rangle - \langle k\rangle)/\langle k\rangle\big]}\).
  • State how the average distance scales with \(N\) for each range of \(\gamma\).

Neighbours of neighbours

Recall from the Mid-sem guide §7: following a link, the chance of arriving at a node of degree \(k\) is \(q_k = kP(k)/\langle k\rangle\), and the average degree of a neighbour is

\[\langle k_{nn}\rangle = \sum_k k\,q_k = \frac{\langle k^2\rangle}{\langle k\rangle}.\]

For a Poisson distribution with mean \(z\): \(\langle k\rangle = z\) and \(\langle k^2\rangle = z^2 + z\), so \(\langle k_{nn}\rangle = z + 1 = \langle k\rangle + 1\). This does not depend on which node we start from, which is what "uncorrelated" means.

Derivation to learn · the average path length for any degree distribution
  1. First neighbours. Start at a typical node \(i\). In one step it reaches \(z_1 = \langle k\rangle\) nodes.
  2. Branching number. Step from \(i\) to a neighbour \(j\). Node \(j\) has \(\langle k_{nn}\rangle\) links on average, but one of them is the link we came along, which leads back to \(i\). So the number of new nodes \(j\) leads to is \[\rho = \langle k_{nn}\rangle - 1 = \frac{\langle k^2\rangle}{\langle k\rangle} - 1 = \frac{\langle k^2\rangle - \langle k\rangle}{\langle k\rangle}.\] This assumes the network is like a tree near \(i\): no two branches meet again.
  3. Second neighbours. Each of the \(z_1\) first neighbours gives \(\rho\) new nodes: \[z_2 = \rho\,z_1 = \Big(\frac{\langle k^2\rangle}{\langle k\rangle} - 1\Big)\langle k\rangle = \langle k^2\rangle - \langle k\rangle.\]
  4. Further shells. Each step multiplies by \(\rho\) again: \(z_3 = \rho z_2 = \rho^2z_1\), and in general \(z_d = \rho^{d-1}z_1\).
  5. Stop when the network is used up. The nodes within distance \(L\) number \(z_1 + \rho z_1 + \dots + \rho^{L-1}z_1\), and the last term is the largest. Setting it to the size of the network: \[N\approx\rho^{L-1}z_1.\]
  6. Take logs. \(\ln N = (L-1)\ln\rho + \ln\langle k\rangle\), so \[L = 1 + \frac{\ln(N/\langle k\rangle)}{\ln\rho} = 1 + \frac{\ln\dfrac{N}{\langle k\rangle}}{\ln\dfrac{\langle k^2\rangle - \langle k\rangle}{\langle k\rangle}}.\]

\(z_d\) is the number of nodes exactly \(d\) steps away. \(\rho\) is the branching number: how many new nodes each node on the edge of the explored region adds. \(L\) is the average path length.

Check with a Poisson network. \(\rho = \langle k\rangle + 1 - 1 = \langle k\rangle\), so \(z_2 = \langle k\rangle^2\) and \(L = 1 + \frac{\ln N - \ln\langle k\rangle}{\ln\langle k\rangle} = \frac{\ln N}{\ln\langle k\rangle}\), the random-graph result. The slides also get it directly: the nodes within distance \(d\) number \(N(d)\approx1 + \langle k\rangle + \dots + \langle k\rangle^d = \frac{\langle k\rangle^{d+1} - 1}{\langle k\rangle - 1}\), and setting \(N(d_{\max})\approx N\) with \(\langle k\rangle\gg1\) gives \(\langle k\rangle^{d_{\max}}\approx N\).

What hubs do. A large ⟨k²⟩ makes \(\rho\) large, so the shells grow faster and \(L\) gets smaller. In a scale-free network with \(\gamma<3\), ⟨k²⟩ grows with \(N\) (§22), and \(L\) shrinks below the random-graph value.

Slide 75 calls \(z_1 + z_2 + \dots + z_m\) the number of nodes "exactly at distance \(m\)"; it is the number within distance \(m\).

\(N = 10^6\), \(\langle k\rangle = 4\).

  • Poisson: \(\langle k^2\rangle = 4^2 + 4 = 20\), \(\rho = 16/4 = 4\), \(L = 1 + \frac{\ln250000}{\ln4} = 1 + \frac{12.43}{1.386} = 9.97\).

Small world and ultra-small world

ExponentAverage distance \(\langle l\rangle\) grows asWhy
\(\gamma = 2\)constantThe biggest hub has of order \(N\) links. Most nodes are within two steps of each other through it, whatever the size.
\(2<\gamma<3\)\(\dfrac{\ln\ln N}{\ln(\gamma-1)}\)Ultra-small world. Most paths run through the few hubs, so distances grow more slowly than a logarithm.
\(\gamma = 3\)\(\dfrac{\ln N}{\ln\ln N}\)The BA model (§21).
\(\gamma>3\)\(\ln N\)Small world. ⟨k²⟩ is finite, so the network behaves like a random one.

For small networks such as the human protein interaction network (\(N\sim10^4\)) the four formulas give nearly the same distance. For networks the size of society or the Web the difference is large, and \(\ln N/\ln\langle k\rangle\) overestimates the real distance. The slides' table shows this: Facebook in 2011 had \(N = 7.21\times10^8\) and \(\langle k\rangle = 191.4\), so \(\ln N/\ln\langle k\rangle = 3.88\) against a measured 4.74; the Web in 2000 had \(N = 2\times10^8\), \(\langle k\rangle = 15\), giving 7.06 against a measured 6.83.

Error and attack tolerance (slides 86–88)

The slides show two figures from Albert, Jeong and Barabási (2000), who removed a fraction \(f\) of the nodes from an exponential (random) network and from a scale-free one.

  • Random failures (nodes removed at random): the scale-free network hardly notices. Its diameter stays flat, because a random node is almost always a small one.
  • Attacks (the most connected nodes removed first): the diameter of the scale-free network rises quickly and the network breaks into pieces at a small \(f\), because the hubs hold it together.
  • The exponential network behaves the same under failure and attack, since all its nodes are alike.

So hubs make a network robust to accidents and fragile to targeted attack. The measured Internet and Web behave like the scale-free model.

What to remember
  • \(\langle k_{nn}\rangle = \langle k^2\rangle/\langle k\rangle\); Poisson: \(\langle k\rangle + 1\).
  • \(\rho = \langle k_{nn}\rangle - 1\); \(z_2 = \rho z_1 = \langle k^2\rangle - \langle k\rangle\); Poisson: \(z_2 = \langle k\rangle^2\).
  • \(N\approx\rho^{L-1}z_1\) gives \(L = 1 + \ln(N/\langle k\rangle)/\ln\rho\).
  • \(\langle l\rangle\): constant (\(\gamma = 2\)), \(\ln\ln N\) (\(2<\gamma<3\)), \(\ln N/\ln\ln N\) (\(\gamma = 3\)), \(\ln N\) (\(\gamma>3\)).
  • Scale-free: robust to random failure, fragile to attack on hubs.
