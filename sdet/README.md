# SD&ET Study Guide (Detection Theory)

End-sem study guide for EC5.406 Signal Detection and Estimation Theory (detection half, Lec 1–11).

**Live site:** https://arihant25.github.io/study-guides/sdet/

Covers Bayesian and Neyman–Pearson tests, ROC, matched and generalized matched filters, M-ary signals, random signals (estimator-correlator), composite tests (UMP, Bayesian, GLRT) and Wald's SPRT, plus Tutorial 1 and homework solutions, flashcards and a formula sheet.

Single static `index.html` (KaTeX from CDN). Expand all, then print for a paper copy.
