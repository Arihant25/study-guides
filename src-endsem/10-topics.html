Formulas to remember

Know these by heart. Under each one, "where" says what every letter means. Every result is proved further down.

1 · Phase synchronisation

  • The model\(\dot\theta_1 = \omega_1 + k_1\sin(\theta_2 - \theta_1)\), \(\dot\theta_2 = \omega_2 + k_2\sin(\theta_1 - \theta_2)\)where \(\theta_{1,2}\) are the phases (angles) of the two oscillators. Each \(\omega\) is a natural frequency, how fast that oscillator turns on its own, and each \(k\) says how strongly it is pulled towards the other.
  • Phase difference\(\dot\phi = \Delta\omega - (k_1 + k_2)\sin\phi\)where \(\phi = \theta_2 - \theta_1\) and \(\Delta\omega = \omega_2 - \omega_1\).
  • Critical conditionLock iff \(|\Delta\omega|\le k_1 + k_2\). Equal couplings \(k\): \(k_c = \frac{|\Delta\omega|}2\)where locking means \(\phi\) stops changing, so both turn at one common frequency.
  • Common frequency\(\Omega = \frac{k_2\omega_1 + k_1\omega_2}{k_1 + k_2}\)a weighted average of the two natural frequencies. With \(k_1 = k_2\) it is the plain average.

2 · The Lorenz system

  • The model\(\dot x = \sigma(y - x)\), \(\dot y = \rho x - y - xz\), \(\dot z = xy - \beta z\)where all the constants are positive.
  • Fixed points\((0,0,0)\), and for \(\rho>1\): \(\big(\pm\sqrt{\beta(\rho-1)},\ \pm\sqrt{\beta(\rho-1)},\ \rho - 1\big)\)where the two signs are taken together.
  • Jacobian\(J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho - z & -1 & -x\\ y & x & -\beta\end{pmatrix}\)where row \(i\) holds the slopes of the \(i\)-th rate, taken with respect to each variable in turn. Put each fixed point into it.
  • OriginStable iff \(\rho<1\)because \(J(0)\) splits into \(-\beta\) and a 2×2 block with trace \(-(\sigma + 1)<0\) and determinant \(\sigma(1 - \rho)\).

3 · Scale-free networks

  • BA modelGrowth + preferential attachment \(\Pi(k_i) = \frac{k_i}{\sum_jk_j}\)where each step adds one node with \(m\) links, and \(k_i\) is the degree of node \(i\).
  • Degree of one node\(\frac{dk_i}{dt} = \frac{k_i}{2t}\), \(k_i(t) = m\big(\frac t{t_i}\big)^{1/2}\)where \(t\) is the time now (= number of nodes added) and \(t_i\) the time node \(i\) joined, with \(k_i(t_i) = m\).
  • Degree distribution\(P(k) = 2m^2k^{-3}\), or exactly \(\frac{2m(m+1)}{k(k+1)(k+2)}\) from the master equationwhere \(P(k)\) is the fraction of nodes with degree \(k\). Exponent \(\gamma = 3\) for every \(m\), and it does not change as the network grows.
  • Master equation\((N+1)P(k,t+1) = NP(k,t) + \frac{k-1}2P(k-1,t) - \frac k2P(k,t)\)for \(k>m\). The equation at \(k = m\) is \((N+1)P(m,t+1) = NP(m,t) + 1 - \frac m2P(m,t)\). Here \(P(k,t)\) is the fraction of degree-\(k\) nodes at time \(t\), and \(N = t\).
  • No preferential attachment\(k_i = m + m\ln\frac t{t_i}\), \(P(k) = \frac em e^{-k/m}\)Model A keeps growth, but each new link picks a node uniformly. The result is an exponential, so there are no hubs.
  • No growth\(k_i(t)\approx\frac{2t}N\) for every nodeModel B fixes \(N\) and adds one link per step. All degrees become about equal, and after about \(N^2/2\) steps the graph is complete.
  • Nonlinear attachment\(\Pi(k_i) = \frac{k_i^\alpha}{\sum_jk_j^\alpha}\). Below \(\alpha = 1\) hubs stay small, and above it one hub takes almost every linkwhere \(\alpha\ge0\), and \(\alpha = 1\) is the BA model. The largest hub grows like \((\ln t)^{1/(1-\alpha)}\) below 1 and like \(t\) above 1, against \(t^{1/2}\) for BA.

4 · Small-world graphs

  • Clustering\(C_i = \frac{\text{links among the neighbours of } i}{\binom{k_i}2}\), \(C = \frac1n\sum_iC_i\)where \(\binom{k_i}2 = \frac{k_i(k_i-1)}2\) is the number of pairs of neighbours.
  • Path length\(\bar\ell = \frac{1}{n(n-1)}\sum_{u\ne v}\ell(u,v)\)where \(\ell(u,v)\) is the number of steps on a shortest path from \(u\) to \(v\).
  • \(p = 0\), ring lattice\(C(0) = \frac{3(k-1)}{2(2k-1)}\to\frac34\), \(\bar\ell(0)\approx\frac n{4k}\)where each of the \(n\) nodes links to \(k\) neighbours on each side, so the degree is \(2k\).
  • \(p = 1\), random graph\(C\approx\frac{2k}n\), \(\bar\ell\approx\frac{\ln n}{\ln2k}\)same \(n\) and the same degree \(2k\).
  • In between\(C(p) = C(0)(1-p)^3\)where \(p\) is the rewiring probability. For small \(p\), \(\bar\ell\) is already near the random value while \(C\) is still near \(C(0)\). That range of \(p\) is the small world.

1 · Phase synchronisation

Two oscillators each turn at their own speed. Coupling pulls each towards the other. If the pull is strong enough compared with the difference in speeds, they lock and turn together. The board's \(f_1(\omega_1, \theta_1, \theta_2, k_1)\) is \(\omega_1 + k_1\sin(\theta_2 - \theta_1)\).

Numbers

Take \(\omega_1 = 2\) and \(\omega_2 = 10\). With \(k_1 = k_2 = 2\) the coupling adds up to only 4, which is less than the gap of 8, so they never lock. They lock once \(k_1 + k_2\ge8\), so with equal couplings the critical value is \(k_c = 4\). At \(k_1 = k_2 = 5\) the locked state has \(\sin\phi^* = \frac8{10}\), so \(\phi^* = 0.93\) rad (the stable root, since \(\cos\phi^*>0\)), and the common frequency is \(\Omega = \frac{5\cdot2 + 5\cdot10}{10} = 6\).

3 · Scale-free networks and the Barabási–Albert model

Real networks grow, and new nodes prefer well-connected nodes. Those two ingredients give a power law with exponent 3. The board asks for the rate \(\frac{dk_i}{dt}\) and the distribution \(P(k)\), with the master equation as a second way to get \(P(k)\). It then asks what happens when you remove an ingredient or change one.

The After mid-sem guide, §19–21, has longer versions.

3a · Growth without preferential attachment (Model A)

Keep growth, but let each new link pick an existing node uniformly at random, whatever its degree. There are \(m_0 + t - 1\approx t\) nodes to choose from, so

\[\Pi(k_i) = \frac{1}{m_0 + t - 1}\approx\frac1t,\qquad\frac{dk_i}{dt} = m\,\Pi = \frac mt.\]

The rate no longer depends on \(k_i\), so a big node gains links no faster than a small one. Integrating from \(k_i(t_i) = m\) gives a logarithm instead of a square root, \(k_i(t) = m + m\ln(t/t_i)\). Old nodes still have more links, but only logarithmically more. The same "late joiners have small degree" argument as for BA then gives an exponential:

\[P(k) = \frac em\,e^{-k/m}\qquad(k\ge m)\]

It adds up to 1, since \(\int_m^\infty\frac1me^{1 - k/m}dk = e\cdot e^{-1} = 1\).

3b · Preferential attachment without growth (Model B)

Now keep preferential attachment but fix the number of nodes at \(N\). Nothing is ever added except links. At each step one node chosen at random gets a new link, and preferential attachment chooses the other end. After \(t\) steps there are \(t\) links, so \(\sum_jk_j = 2t\), and node \(i\) gains a link either by being the random end (probability \(\frac1N\)) or by being picked (probability \(\frac{k_i}{2t}\)):

\[\frac{dk_i}{dt} = \frac1N + \frac{k_i}{2t}.\]

Trying \(k_i = at\) gives \(a = \frac1N + \frac a2\), so \(a = \frac2N\). Without the \(\frac1N\) the equation is the BA one, which \(\sqrt t\) solves. So the full solution is

\[k_i(t) = \frac{2t}N + C_i\sqrt t\;\approx\;\frac{2t}{N}\ \text{ for large } t.\]

The part that differs between nodes, \(C_i\sqrt t\), becomes negligible next to \(\frac{2t}N\), which is the same for everyone. So all degrees end up about equal, and the distribution is a narrow peak around the average instead of a power law. Since there are only \(\frac{N(N-1)}2\) possible links, after about \(\frac{N^2}{2}\) steps every pair is linked and the network is a complete graph. There is no stationary state.

What to remember

Both ingredients are needed. Growth alone gives an exponential. Preferential attachment alone gives a network where everyone ends up alike and then complete. Only together do they give \(P(k)\sim k^{-3}\).

3c · Nonlinear preferential attachment

Keep growth, and change the rule to a power of the degree:

\[\Pi(k_i) = \frac{k_i^\alpha}{\sum_jk_j^\alpha},\qquad\alpha\ge0.\]

\(\alpha = 0\) is Model A (every node equal) and \(\alpha = 1\) is the BA model. The question is what happens in between and beyond.

\(\alpha\)NameDegree distributionLargest hub after \(t\) steps
0no preferential attachmentexponential\(\sim\ln t\)
\(0<\alpha<1\)sublineara stretched exponential, about \(e^{-ck^{1-\alpha}}\), so no power law and few hubs\(\sim(\ln t)^{1/(1-\alpha)}\)
1linear (BA)power law \(k^{-3}\)\(\sim t^{1/2}\)
\(\alpha>1\)superlinearwinner takes all, with one hub and the rest small\(\sim t\)

Why \(\alpha<1\) gives small hubs. When the degrees stay small, \(k_j^\alpha\) has a finite average \(\nu = \langle k^\alpha\rangle\), so the sum over the \(\approx t\) nodes is \(\sum_jk_j^\alpha\approx\nu t\). Then

\[\frac{dk_i}{dt} = \frac{m\,k_i^\alpha}{\nu\,t}\;\Rightarrow\;\int_m^{k_i}k^{-\alpha}dk = \frac m\nu\int_{t_i}^t\frac{dt'}{t'}\;\Rightarrow\;k_i^{1-\alpha} - m^{1-\alpha} = \frac{(1-\alpha)\,m}{\nu}\ln\frac{t}{t_i}.\]

For the oldest node (\(t_i = 1\)) this gives \(k_{\max}\sim(\ln t)^{1/(1-\alpha)}\), which grows more slowly than any power of \(t\). Putting \(\alpha = 0\) and \(\nu = 1\) gives back Model A's \(k_i = m + m\ln(t/t_i)\), which is a useful check.

Why \(\alpha>1\) gives one giant hub. Suppose one node has a degree that grows like \(t\), say \(k_1 = ct\), while the others stay small. Then \(k_1^\alpha = c^\alpha t^\alpha\), and since \(\alpha>1\) this outgrows the sum over all the other nodes, which is only about \(t\). So \(\Pi(1)\to1\). Almost every new node links to node 1, which keeps \(k_1\) growing like \(t\). The guess is self-consistent. One node, usually one of the first, ends up linked to a finite fraction of the network.

4 · Small-world graphs

Start from a ring lattice (\(p = 0\)), which has high clustering and long paths. Rewire each link with probability \(p\). At \(p = 1\) the graph is random, with short paths and almost no clustering. In between, a few rewired links make the paths short while the clustering stays high. The board asks for the average clustering coefficient and the path length at both ends.

Convention

Here \(k\) is the number of neighbours on each side, so the degree is \(2k\). If a question writes \(K\) for the degree, put \(k = K/2\). Then \(C(0) = \frac{3(K-2)}{4(K-1)}\) and \(\bar\ell(0)\approx\frac{n}{2K}\).

\(p = 0\) (ring lattice)small \(p\)\(p = 1\) (random)
Clustering \(C\)\(\frac{3(k-1)}{2(2k-1)}\approx\frac34\)\(\approx C(0)\)\(\frac{2k}n\to0\)
Path length \(\bar\ell\)\(\frac n{4k}\), grows with \(n\)\(\approx\) random value\(\frac{\ln n}{\ln2k}\)
Numbers · \(n = 1000\), \(k = 5\) (degree 10)

At \(p = 0\), \(C = \frac{3\cdot4}{2\cdot9} = 0.667\) and \(\bar\ell = \frac{1000}{20} = 50\). At \(p = 1\), \(C = \frac{10}{1000} = 0.01\) and \(\bar\ell = \frac{\ln1000}{\ln10} = 3\). At \(p = 0.1\) the clustering is still \(0.667\times0.9^3 = 0.486\), although there are already \(nkp = 500\) shortcuts.

Past questions, worked

Try each before opening the answer.

2024 class quiz 2 · Q1 · 1 markIn a social network, node A has neighbours B, C and D. If B and C are not connected to each other, what is the minimum possible local clustering coefficient of A? (0, 1, 2/3, 1/2, 1/3)›

A has 3 neighbours, so there are \(\binom32 = 3\) pairs of them, and the pair B–C is missing. The smallest value comes when the other two pairs (B with D, and C with D) are missing as well. That leaves 0 links out of 3, so \(C_A = 0\). The largest possible value is \(\frac23\).

The result is an exponential, not a power law, so the network is not scale-free. Without preferential attachment there are no hubs.

Practice · 3 + 2 marksWrite the master equation for the number of degree-\(k\) nodes in the BA model, including the equation for \(k = m\). Solve it in the steady state and show \(P(k)\sim k^{-3}\).›

Follow the master-equation proof. Each of these steps earns marks.

  1. \(\Pi(k) = \frac{k}{2mt}\), so the links landing on degree-\(k\) nodes in one step number \(\frac k2P(k,t)\).
  2. Degree-\(k\) nodes are gained from degree \(k-1\) and lost to degree \(k+1\).
  3. At \(k = m\) the new node adds an extra \(+1\).
  4. In the steady state, \(P(k) = \frac{k-1}{k+2}P(k-1)\) and \(P(m) = \frac2{m+2}\).
  5. Multiplying out gives \(P(k) = \frac{2m(m+1)}{k(k+1)(k+2)}\), which is \(\approx2m^2k^{-3}\) for large \(k\).
Practice · 2 + 2 marksWhat happens to the BA model if (a) the number of nodes is fixed, (b) the attachment probability is \(\Pi\propto k^\alpha\) with \(\alpha>1\)?›

(a) \(\frac{dk_i}{dt} = \frac1N + \frac{k_i}{2t}\), solved by \(k_i = \frac{2t}N + C_i\sqrt t\). The common \(\frac{2t}N\) part wins, so all degrees become about equal (a narrow peak, no power law), and after about \(N^2/2\) steps the graph is complete.

(b) Winner takes all. If one node has \(k_1\propto t\), then \(k_1^\alpha\) grows faster than the sum over all the others (about \(t\)), so it receives almost every new link. One hub ends up with a finite fraction of the links, \(k_{\max}\sim t\).

Practice · 2 + 2 + 1 marksA Watts–Strogatz graph has \(n\) nodes, each linked to its \(k\) nearest neighbours on each side. (a) Find the average clustering coefficient at \(p = 0\). (b) Find the average path length at \(p = 0\) and at \(p = 1\). (c) What is \(C\) at rewiring probability \(p\)?›

(a) \(\binom{2k}2 = k(2k-1)\) pairs of neighbours, \(3\binom k2\) of them linked, so \(C(0) = \frac{3(k-1)}{2(2k-1)}\) (proof).

(b) \(p = 0\): \(2k\) new nodes per step out to \(\frac n{2k}\) steps, so \(\bar\ell\approx\frac n{4k}\). \(p = 1\): shells grow as \((2k)^\ell\), so \(\bar\ell\approx\frac{\ln n}{\ln2k}\) (proof, proof).

(c) A triangle survives only if its three links are all kept, so \(C(p) = C(0)(1-p)^3\) (proof).

Practice · 3 marksTwo oscillators have \(\omega_1 = 1\), \(\omega_2 = 4\), \(k_1 = 1\), \(k_2 = 2\). Do they lock? If so, at what frequency, and what is the locked phase difference?›

\(|\Delta\omega| = 3\) and \(k_1 + k_2 = 3\), which is exactly the critical condition, so they just lock. \(\sin\phi^* = \frac33 = 1\), \(\phi^* = \frac\pi2\). \(\Omega = \frac{k_2\omega_1 + k_1\omega_2}{k_1 + k_2} = \frac{2 + 4}{3} = 2\). As a check, \(\omega_1 + k_1\sin\phi^* = 1 + 1 = 2\) and \(\omega_2 - k_2\sin\phi^* = 4 - 2 = 2\).
