0a · Networks

A network (or graph) is a set of nodes joined by links. In a network of friendships, each node is a person and each link joins two people who know each other. \(N\) is the number of nodes and \(L\) is the number of links.

Degree. The degree \(k_i\) of node \(i\) is the number of links at that node. In the picture, \(k_A = 3\), \(k_B = k_C = k_D = 2\) and \(k_E = 1\). Every link has two ends, so the degrees add up to twice the number of links. This gives the average degree.

\[\sum_ik_i = 2L,\qquad\langle k\rangle = \frac{2L}{N}.\]

The symbol \(\sum_i\) (a capital Greek sigma) means "add up over every node \(i\)". So \(\sum_ik_i = k_1 + k_2 + \dots + k_N\), the sum of all the degrees. In the picture it is \(3 + 2 + 2 + 2 + 1 = 10\), which equals \(2L = 2\times5\). The angle brackets \(\langle\ \rangle\) mean "the average of". The average degree is the sum of the degrees divided by the number of nodes, so in the picture \(\langle k\rangle = \frac{10}{5} = 2\).

Degree distribution. \(P(k)\) is the fraction of nodes that have degree \(k\). In the picture, \(P(2) = \frac35\) because three of the five nodes have degree 2. The fractions add up to 1.

Power law and scale-free. A degree distribution of the form \(P(k) = Ck^{-\gamma}\) is called a power law. Here \(\gamma\) (the Greek letter gamma) is a fixed number called the exponent, and \(C\) is a constant chosen so that all the fractions add up to 1. A network whose \(P(k)\) is a power law is called scale-free.

The symbol \(\propto\) means "is proportional to", that is, equal apart from a constant factor. So \(P(k)\propto k^{-3}\) means \(P(k) = Ck^{-3}\) for some constant \(C\).

In a power law, large degrees are rare but not extremely rare. With \(\gamma = 3\), going from \(k = m\) to \(k = 20m\) divides \(P(k)\) by \(20^3 = 8000\). A large network then has a few nodes with very many links, and these are called hubs. Compare an exponential distribution such as \(P(k)\propto e^{-k/m}\), where \(e = 2.718\dots\) Every time \(k\) increases by \(m\), \(P(k)\) is divided by \(e\) once more. Going from \(k = m\) to \(k = 20m\) divides it by \(e^{19}\), about 180 million. The fraction falls so fast that there are no hubs.

Path length. The distance between two nodes is the smallest number of links you have to cross to get from one to the other. In the picture the distance from B to E is 3 (B to A, A to D, D to E). The average path length \(\bar\ell\) is the average distance over all pairs of nodes.

Clustering coefficient. This measures how many of a node's neighbours are linked to each other. A node with \(k_i\) neighbours has \(\frac{k_i(k_i-1)}2\) pairs of neighbours. (Each of the \(k_i\) neighbours can be paired with the \(k_i - 1\) others. That counts every pair twice, so divide by 2.) This number is also written \(\binom{k_i}2\), read "\(k_i\) choose 2". Then

\[C_i = \frac{\text{number of linked pairs of neighbours of } i}{k_i(k_i-1)/2}.\]

Node A has neighbours B, C and D, so 3 pairs. Only B and C are linked, so \(C_A = \frac13\). The average clustering coefficient \(C\) is the average of \(C_i\) over all nodes. Each linked pair of neighbours forms a triangle with node \(i\), so high clustering means many triangles.

Try itA network has 8 nodes and 12 links. What is \(\langle k\rangle\)?›
Formula
\(\langle k\rangle = \frac{2L}N\)
Where it comes from
Every link has two ends, so the degrees add up to \(2L\) (Part 0a, "Degree").
Working
  1. Every link has two ends, and each end adds 1 to the degree of the node it touches. So each link adds 2 to the sum of all degrees.
  2. Sum of all degrees \(= 2L = 2\times12 = 24\).
  3. The average is the sum divided by the number of nodes. \(\langle k\rangle \)\({}= \frac{24}{8} \)\({}= 3\).
2024 class quiz 2 · 1 markIn a social network, node A has neighbours B, C and D. If B and C are not connected to each other, what is the minimum possible local clustering coefficient of A? (0, 1, 2/3, 1/2, 1/3)›
Formula
\(C_i = \frac{\text{linked pairs of neighbours}}{k_i(k_i-1)/2}\)
Where it comes from
The definition of the clustering coefficient (Part 0a).
Working
  1. The neighbours of A are B, C and D, so \(k_A = 3\).
  2. Number of pairs of neighbours \(= \frac{k_A(k_A-1)}2 \)\({}= \frac{3\times2}2 \)\({}= 3\). The pairs are B–C, B–D and C–D.
  3. B–C is not linked (given). The question says nothing about B–D and C–D, so each of them may or may not be linked.
  4. To make \(C_A\) as small as possible, take B–D and C–D as not linked. Then 0 of the 3 pairs are linked.
  5. \(C_A = \frac{0}{3} = 0\). The answer is 0.
  6. Check the other options. With one of B–D or C–D linked, \(C_A = \frac13\). With both linked, \(C_A = \frac23\). So 1 and \(\frac12\) cannot happen here.

0b · Equations that change in time

\(\dot x\) (read "x dot") means \(\frac{dx}{dt}\), the rate at which \(x\) changes with time. An equation like \(\dot x = f(x)\) gives that rate for every value of \(x\).

Fixed point. A fixed point \(x^*\) is a value where the rate is zero, \(f(x^*) = 0\). If \(x\) starts exactly there, it stays there.

Stability. A fixed point is stable if a small change away from it shrinks back to zero over time, and unstable if a small change grows. For one variable the test is the slope of \(f\).

\[\dot x = f(x):\qquad x^*\text{ is stable if } f'(x^*)<0\text{ and unstable if } f'(x^*)>0.\]

Here is the reason. Suppose \(f'(x^*)<0\), so \(f\) is decreasing through zero at \(x^*\). Just above \(x^*\), \(f\) is negative, so \(\dot x<0\) and \(x\) decreases back towards \(x^*\). Just below \(x^*\), \(f\) is positive, so \(x\) increases back towards \(x^*\). Either way \(x\) returns, so \(x^*\) is stable. If \(f'(x^*)>0\), the signs are the other way round and \(x\) moves away.

The Jacobian. With several variables, say \(\dot x = f(x, y)\) and \(\dot y = g(x, y)\), the test uses the Jacobian matrix. Row 1 holds the partial derivatives of \(f\), and row 2 holds those of \(g\).

\[J = \begin{pmatrix}\frac{\partial f}{\partial x} & \frac{\partial f}{\partial y}\\[4pt] \frac{\partial g}{\partial x} & \frac{\partial g}{\partial y}\end{pmatrix}\]

A partial derivative \(\frac{\partial f}{\partial x}\) is the derivative of \(f\) with respect to \(x\), treating every other variable as a constant. You work out \(J\) with the variables left in, then put in the values at the fixed point.

Example. Take \(f = 3x + xy\) and \(g = y^2 - x\). Treating \(y\) as a constant, \(\frac{\partial f}{\partial x} = 3 + y\). Treating \(x\) as a constant, \(\frac{\partial f}{\partial y} = x\). In the same way, \(\frac{\partial g}{\partial x} = -1\) and \(\frac{\partial g}{\partial y} = 2y\). So \(J = \begin{pmatrix}3 + y & x\\ -1 & 2y\end{pmatrix}\). At the fixed point \((x, y) = (0, 0)\), \(J = \begin{pmatrix}3 & 0\\ -1 & 0\end{pmatrix}\).

Eigenvalues. \(I\) is the identity matrix, which has 1 on the diagonal and 0 everywhere else. So \(J - \lambda I\) is \(J\) with \(\lambda\) (the Greek letter lambda) subtracted from each diagonal entry. "det" means the determinant. For a 2×2 matrix \(\begin{pmatrix}a & b\\ c & d\end{pmatrix}\) the determinant is \(ad - bc\). The eigenvalues of \(J\) are the numbers \(\lambda\) that make \(\det(J - \lambda I) = 0\).

Near the fixed point, small changes grow or shrink like \(e^{\lambda t}\). If \(\lambda<0\), \(e^{\lambda t}\) shrinks to 0 as \(t\) increases, and if \(\lambda>0\) it grows. So the fixed point is stable if every eigenvalue is negative, and unstable if any eigenvalue is positive. (An eigenvalue can be a complex number \(u + iv\). Then only its real part \(u\) counts in this test.)

The 2×2 shortcut. For \(J = \begin{pmatrix}a & b\\ c & d\end{pmatrix}\), let \(T = a + d\) (the trace) and \(D = ad - bc\) (the determinant). The shortcut comes from these steps.

  1. \(J - \lambda I = \begin{pmatrix}a - \lambda & b\\ c & d - \lambda\end{pmatrix}\).
  2. Its determinant is \((a - \lambda)(d - \lambda) - bc\).
  3. Multiply out the brackets. \(ad - a\lambda - d\lambda + \lambda^2 - bc \)\({}= \lambda^2 - (a + d)\lambda + (ad - bc) \)\({}= \lambda^2 - T\lambda + D\).
  4. Set this to zero, \(\lambda^2 - T\lambda + D = 0\), and solve it with the quadratic formula.
\[\lambda = \frac{T\pm\sqrt{T^2 - 4D}}{2},\qquad\text{stable}\iff T<0\text{ and }D>0.\]

The symbol \(\iff\) means "if and only if". The two eigenvalues add up to \(T\) and multiply to \(D\). Two numbers are both negative exactly when their sum is negative and their product is positive, which gives the test. If \(D<0\), the product is negative, so one eigenvalue is positive and the other is negative. That fixed point is called a saddle, and it is unstable.

A 3×3 matrix that splits. If the third row and the third column are zero except for the corner entry, that corner entry is one eigenvalue. The other two come from the top-left 2×2 block. This works because \(\det(J - \lambda I)\) is then (corner entry \(- \lambda\)) times the determinant of (the 2×2 block \(- \lambda I\)), and a product is zero when either factor is zero. Part 5 uses this.

Try itFind the fixed points of \(\dot x = x(1 - x)\) and say whether each is stable.›
Formula
Fixed points solve \(f(x^*) = 0\). Stable if \(f'(x^*)<0\), unstable if \(f'(x^*)>0\).
Where it comes from
Part 0b, "Fixed point" and "Stability".
Working
  1. Here \(f(x) = x(1 - x)\). Fixed points solve \(f(x^*) = 0\).
  2. \(x(1 - x) = 0\). A product is zero when one of its factors is zero, so \(x = 0\) or \(1 - x = 0\). The fixed points are \(x^* = 0\) and \(x^* = 1\).
  3. Expand \(f(x) = x - x^2\) and differentiate. \(f'(x) = 1 - 2x\).
  4. At \(x^* = 0\): \(f'(0) = 1 - 0 = 1\). This is positive, so \(x^* = 0\) is unstable.
  5. At \(x^* = 1\): \(f'(1) = 1 - 2 = -1\). This is negative, so \(x^* = 1\) is stable.
Try itA fixed point has \(J = \begin{pmatrix}-3 & 1\\ 2 & -2\end{pmatrix}\). Find the eigenvalues. Is it stable?›
Formula
\(\lambda = \frac{T\pm\sqrt{T^2 - 4D}}2\), with \(T = a + d\) and \(D = ad - bc\). Stable if and only if \(T<0\) and \(D>0\).
Where it comes from
Part 0b, "The 2×2 shortcut".
Working
  1. Read off the entries of \(J = \begin{pmatrix}a & b\\ c & d\end{pmatrix}\). Here \(a = -3\), \(b = 1\), \(c = 2\), \(d = -2\).
  2. Trace. \(T = a + d = -3 + (-2) = -5\).
  3. Determinant. \(D \)\({}= ad - bc \)\({}= (-3)(-2) - (1)(2) \)\({}= 6 - 2 \)\({}= 4\).
  4. Inside the square root. \(T^2 - 4D \)\({}= (-5)^2 - 4\times4 \)\({}= 25 - 16 \)\({}= 9\), and \(\sqrt9 = 3\).
  5. \(\lambda \)\({}= \frac{T\pm3}{2} \)\({}= \frac{-5\pm3}2\). With \(+\): \(\frac{-2}2 = -1\). With \(-\): \(\frac{-8}2 = -4\).
  6. Both eigenvalues are negative, so the fixed point is stable. The shortcut gives the same answer, since \(T = -5<0\) and \(D = 4>0\).

0c · Maths tools

Parts 1 and 2 use the same three tools again and again.

Separating variables. To solve \(\frac{dk}{dt} = \frac{k}{2t}\), put everything with \(k\) on one side and everything with \(t\) on the other, then integrate both sides.

\[\frac{dk}{k} = \frac{dt}{2t}\;\Rightarrow\;\ln k = \tfrac12\ln t + c.\]

Here \(c\) is a constant that appears when you integrate. A known starting value fixes it. Instead of using \(c\), you can integrate from the starting value, as in the question below. You will need \(\int\frac{dx}x = \ln x\), \(\ln a - \ln b = \ln\frac ab\), and \(b\ln a = \ln a^b\).

Joining times are spread evenly. In a network where one node is added at each step \(1, 2, \dots, t\), every joining time occurs exactly once. Write \(t_i\) for the time at which node \(i\) joined. The nodes that joined after time \(T\) are the ones from times \(T + 1\) to \(t\), and there are \(t - T\) of them out of \(t\). So the fraction of nodes that joined after time \(T\) is

\[\text{fraction with } t_i>T = \frac{t - T}{t} = 1 - \frac Tt.\]

From "fraction below \(k\)" to \(P(k)\). If \(F(k)\) is the fraction of nodes with degree below \(k\), then the degree distribution is its derivative, \(P(k) = \frac{dF}{dk}\). The reason is that the fraction of nodes with degree between \(k\) and \(k + \Delta k\) is \(F(k + \Delta k) - F(k)\), which is about \(F'(k)\,\Delta k\). So \(F'(k)\) is the fraction of nodes per unit of degree, which is what \(P(k)\) means when degrees are treated as smooth numbers.

Sine. Angles here are in radians, where \(\pi\) radians is 180°. \(\sin\phi\) is always between \(-1\) and \(1\), so \(\sin\phi = a\) has a solution only if \(|a|\le1\). (\(|a|\) is the size of \(a\) without its sign.) For \(0\le a\le1\), \(\arcsin a\) is the angle between 0 and \(\frac\pi2\) whose sine is \(a\), and your calculator gives it. There are two solutions between 0 and \(\pi\), namely \(\arcsin a\) and \(\pi - \arcsin a\). The first is below \(\frac\pi2\), so it has \(\cos\phi>0\). The second is above \(\frac\pi2\), so it has \(\cos\phi<0\). Part 4 uses this.

Try itSolve \(\frac{dk}{dt} = \frac{k}{2t}\) with \(k = 2\) at \(t = 5\). What is \(k\) at \(t = 20\)?›
Formula
Separate variables, \(\frac{dk}{k} = \frac{dt}{2t}\), and use \(\int\frac{dx}x = \ln x\).
Where it comes from
Part 0c, "Separating variables".
Working
  1. Separate the variables. Put everything with \(k\) on the left and everything with \(t\) on the right. Divide both sides by \(k\) and multiply both sides by \(dt\). \[\frac{dk}{k} = \frac{dt}{2t} = \frac12\cdot\frac{dt}{t}.\]
  2. Integrate both sides, starting from the known values (\(k = 2\) at \(t = 5\)). \[\int_2^k\frac{dk'}{k'} = \frac12\int_5^t\frac{dt'}{t'}.\]
  3. Use \(\int\frac{dx}x = \ln x\). The left side is \(\ln k - \ln 2\). The right side is \(\frac12(\ln t - \ln 5)\).
  4. Use \(\ln a - \ln b = \ln\frac ab\). \[\ln\frac k2 = \frac12\ln\frac t5.\]
  5. Use \(\frac12\ln y = \ln\sqrt y\). \[\ln\frac k2 = \ln\sqrt{t/5}.\]
  6. If \(\ln A = \ln B\) then \(A = B\). So \(\frac k2 = \sqrt{t/5}\), which gives \[k = 2\sqrt{t/5}.\]
  7. Put in \(t = 20\). \(\frac{20}5 = 4\), \(\sqrt4 = 2\), so \(k = 2\times2 = 4\).
  8. Check the starting value. At \(t = 5\), \(k = 2\sqrt{1} = 2\), which is correct.
