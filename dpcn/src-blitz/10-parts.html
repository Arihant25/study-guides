1 · The Barabási–Albert (BA) model

About 2 hours. This part and the next are the largest share of the syllabus.

The BA model is a rule for building a network one node at a time. It has two ingredients.

  1. Growth. Start with a few nodes (\(m_0\) of them). At each time step \(t = 1, 2, 3, \dots\), add one new node with \(m\) links.
  2. Preferential attachment. Each of those \(m\) links is attached to an existing node \(i\) with probability
    \[\Pi(k_i) = \frac{k_i}{\sum_jk_j},\]
    This formula is explained below.
Reading the formula

\(\Pi\) (capital pi) is just the name for this probability. It is not the number 3.14.

The top, \(k_i\), is the degree of node \(i\), the node we are asking about.

The bottom, \(\sum_jk_j\), means "add up the degree of every node in the network". The symbol \(\sum_j\) says to let \(j\) run over all the nodes and add the terms. So \(\sum_jk_j = k_1 + k_2 + k_3 + \dots\), the total degree.

So the probability is node \(i\)'s share of the total degree. Dividing by the total makes the probabilities of all the nodes add up to 1, as they must, because the link has to attach to exactly one node.

Example. A network has 4 nodes with degrees 1, 2, 3 and 4. The total is \(\sum_jk_j = 1 + 2 + 3 + 4 = 10\). The probabilities are \(\frac1{10}\), \(\frac2{10}\), \(\frac3{10}\) and \(\frac4{10}\), which add up to \(\frac{10}{10} = 1\). The node of degree 4 is 4 times as likely to receive the link as the node of degree 1.

In general, a node with twice the degree is twice as likely to receive the link. This is why it is called preferential attachment. A node that already has many links is more likely to receive the next one.

In the BA model the total degree is easy to find. Every link adds 1 to the degree of each of its two ends, so each link adds 2 to the total. After \(t\) steps there are \(mt\) links, so \(\sum_jk_j = 2mt\) and \(\Pi(k_i) = \frac{k_i}{2mt}\). Step 2 of 1A uses this.

After \(t\) steps there are about \(t\) nodes and \(mt\) links. Nodes that were added early have had more steps in which to receive links, and every link they receive makes the next one more likely. The result is a power-law degree distribution, \(P(k)\propto k^{-3}\), so the network is scale-free with \(\gamma = 3\).

The board asks for three things. They are the rate \(\frac{dk_i}{dt}\), the distribution \(P(k)\), and the master equation, which is a second way to get \(P(k)\).

1A · The rate \(\frac{dk_i}{dt}\)

Think of \(k_i\) as a smooth number that grows with time. Its rate of change is the expected number of new links that node \(i\) receives in one step.

Write this in the exam

Show that \(\frac{dk_i}{dt} = \frac{k_i}{2t}\), and solve it.

  1. Each step adds \(m\) links, and each one attaches to node \(i\) with probability \(\Pi(k_i) = \frac{k_i}{\sum_jk_j}\). So \(\frac{dk_i}{dt} = m\,\Pi(k_i) = \frac{m\,k_i}{\sum_jk_j}\).
  2. After \(t\) steps there are \(mt\) links. Each link adds 2 to the total degree, so \(\sum_jk_j = 2mt\).
  3. Substitute. \(\frac{dk_i}{dt} = \frac{m\,k_i}{2mt} = \frac{k_i}{2t}\). This proves that the rate is proportional to \(\frac{k_i}{t}\).
  4. Separate the variables. \(\frac{dk_i}{k_i} = \frac12\,\frac{dt}{t}\).
  5. Node \(i\) was added at time \(t_i\) with \(m\) links, so \(k_i(t_i) = m\). Integrate from there. \(\ln\frac{k_i}{m} = \frac12\ln\frac{t}{t_i}\).
  6. So \(k_i(t) = m\sqrt{\frac{t}{t_i}}\). A node added earlier (smaller \(t_i\)) has a larger degree.

1B · The degree distribution \(P(k)\) (continuum theory)

The degree of a node depends only on when it was added. So the question "what fraction of nodes have degree below \(k\)?" becomes "what fraction of nodes were added after a certain time?", and joining times are spread evenly.

Write this in the exam

Show that \(P(k) = 2m^2k^{-3}\).

  1. From 1A, \(k_i = m\sqrt{t/t_i}\). Solving for the joining time gives \(t_i = \frac{m^2t}{k_i^2}\).
  2. A node has degree below \(k\) exactly when it was added after time \(\frac{m^2t}{k^2}\). So the fraction with degree below \(k\) equals the fraction with \(t_i>\frac{m^2t}{k^2}\).
  3. One node is added per step, so joining times are spread evenly over \(1\dots t\), and the fraction added after time \(T\) is \(1 - \frac Tt\).
  4. With \(T = \frac{m^2t}{k^2}\), the fraction with degree below \(k\) is \(F(k) = 1 - \frac{m^2}{k^2}\). The \(t\) cancels, so this does not change as the network grows.
  5. Differentiate. \(P(k) = \frac{dF}{dk} = \frac{2m^2}{k^3}\). This is a power law with \(\gamma = 3\), whatever the value of \(m\).

1C · The master equation

This method gives \(P(k)\) by counting. Let \(N(k, t)\) be the number of nodes with degree \(k\) at time \(t\). There are \(t\) nodes at time \(t\), so the fraction is \(P(k, t) = \frac{N(k, t)}t\). In one step, a node of degree \(k - 1\) that receives a link moves up to degree \(k\). A node of degree \(k\) that receives a link moves up to degree \(k + 1\). The new node adds one node of degree \(m\).

Write this in the exam

Write the master equation for the BA model and solve it for \(P(k)\).

  1. A given degree-\(k\) node receives a given new link with probability \(\frac{k}{2mt}\). There are \(N(k, t)\) such nodes and \(m\) new links, so the expected number of degree-\(k\) nodes that receive a link in one step is \(m\cdot N(k, t)\cdot\frac{k}{2mt} = \frac k2P(k, t)\).
  2. For \(k>m\), degree-\(k\) nodes are gained from degree \(k-1\) and lost to degree \(k+1\). \[N(k, t+1) = N(k, t) + \frac{k-1}2P(k-1, t) - \frac k2P(k, t).\]
  3. For \(k = m\) there is nothing below, but the new node is gained. \[N(m, t+1) = N(m, t) + 1 - \frac m2P(m, t).\]
  4. Look for a steady state, where \(P(k, t) = P(k)\) does not depend on \(t\). Then \(N(k, t+1) - N(k, t) = (t+1)P(k) - tP(k) = P(k)\).
  5. At \(k = m\): \(P(m) = 1 - \frac m2P(m)\), so \(P(m) = \frac{2}{m+2}\).
  6. For \(k>m\): \(P(k) = \frac{k-1}2P(k-1) - \frac k2P(k)\), so \(\frac{k+2}2P(k) = \frac{k-1}2P(k-1)\) and \[P(k) = \frac{k-1}{k+2}\,P(k-1).\]
  7. Apply this repeatedly, starting from \(P(m)\). The factors \(\frac{m}{m+3}\cdot\frac{m+1}{m+4}\cdots\frac{k-1}{k+2}\) mostly cancel, leaving \[P(k) = \frac{2m(m+1)}{k(k+1)(k+2)}.\]
  8. For large \(k\) the bottom is about \(k^3\), so \(P(k)\approx\frac{2m(m+1)}{k^3}\propto k^{-3}\). This is the same power law, \(\gamma = 3\), as in 1B.
Remember

Ingredients are growth and preferential attachment, \(\Pi(k_i) = \frac{k_i}{\sum_jk_j}\). The total degree is \(\sum_jk_j = 2mt\).

\(\frac{dk_i}{dt} = \frac{k_i}{2t}\), so \(k_i = m\sqrt{t/t_i}\). The fraction with degree below \(k\) is \(1 - \frac{m^2}{k^2}\), so \(P(k) = 2m^2k^{-3}\).

Master equation: \(P(m) = \frac2{m+2}\) and \(P(k) = \frac{k-1}{k+2}P(k-1)\), so \(P(k) = \frac{2m(m+1)}{k(k+1)(k+2)}\).

2 · Changing the BA model

About 1 hour. The board lists "no growth", "no preferential attachment" and "nonlinear preferential attachment".

Each case changes one rule of the BA model and asks what degree distribution results. The method is the same as in Part 1. Write \(\frac{dk_i}{dt}\) using the new rule, integrate from the node's starting degree, and, where needed, get \(P(k)\) from the evenly spread joining times.

2A · Growth without preferential attachment (Model A)

Nodes are still added one per step with \(m\) links each. Each link now attaches to an existing node chosen uniformly at random, so the degree of a node does not affect its chance of receiving a link.

Write this in the exam

Find \(k_i(t)\) and \(P(k)\) for Model A. Is it scale-free?

  1. There are \(m_0 + t - 1\approx t\) existing nodes, each equally likely, so \(\Pi(k_i) = \frac1t\).
  2. \(\frac{dk_i}{dt} = m\,\Pi = \frac mt\). This does not depend on \(k_i\).
  3. Integrate from \(k_i(t_i) = m\). \(k_i - m = m\ln\frac t{t_i}\), so \(k_i(t) = m + m\ln\frac{t}{t_i}\).
  4. \(k_it\,e^{1 - k/m}\).
  5. Joining times are spread evenly, so the fraction with degree below \(k\) is \(F(k) = 1 - e^{1 - k/m}\).
  6. Differentiate. \(P(k) = \frac{dF}{dk} = \frac em\,e^{-k/m}\) for \(k\ge m\).
  7. This is exponential, not a power law. Large degrees are extremely rare and there are no hubs, so the network is not scale-free.

2B · Preferential attachment without growth (Model B)

Now the number of nodes is fixed at \(N\) and no nodes are added. At each step, one node is chosen uniformly at random, and a new link is added from it to a node chosen by preferential attachment.

Write this in the exam

Find \(k_i(t)\) for Model B and describe the degree distribution.

  1. Each step adds one link, so after \(t\) steps \(\sum_jk_j = 2t\).
  2. Node \(i\) gains a link if it is the randomly chosen end (probability \(\frac1N\)) or the preferentially chosen end (probability \(\frac{k_i}{2t}\)). So \(\frac{dk_i}{dt} = \frac1N + \frac{k_i}{2t}\).
  3. Try \(k_i = at\). Then \(a = \frac1N + \frac a2\), so \(a = \frac2N\).
  4. Without the \(\frac1N\) term the equation is the BA one, solved by \(\sqrt t\). So the general solution is \(k_i(t) = \frac{2t}N + C_i\sqrt t\), where \(C_i\) depends on the node.
  5. For large \(t\), the \(\frac{2t}N\) part (the same for every node) is much larger than the \(C_i\sqrt t\) part. So every degree is close to \(\frac{2t}N\), and the distribution is a narrow peak around the average, not a power law.
  6. There are only \(\frac{N(N-1)}2\) possible links, so after about \(\frac{N^2}2\) steps every pair of nodes is linked and the network is complete. The distribution never settles to a steady state.

2C · Nonlinear preferential attachment

Nodes are added as in BA, but the attachment probability uses a power \(\alpha\) of the degree.

\[\Pi(k_i) = \frac{k_i^\alpha}{\sum_jk_j^\alpha},\qquad\alpha\ge0.\]

\(\alpha = 0\) gives Model A, and \(\alpha = 1\) gives the BA model. The table is what to learn.

0no preferential attachmentexponential\(\sim\ln t\)

\(\alpha>1\)superlinearone node has a finite fraction of all links, the rest have small degree\(\sim t\)
Write this in the exam

Explain what happens for \(\alpha<1\) and for \(\alpha>1\).

  1. For \(\alpha<1\), degrees stay small, so \(k_j^\alpha\) has a finite average \(\nu\). With about \(t\) nodes, \(\sum_jk_j^\alpha\approx\nu t\).
  2. Then \(\frac{dk_i}{dt} = \frac{m\,k_i^\alpha}{\nu t}\). Separate and integrate: \(k_i^{1-\alpha} - m^{1-\alpha} = \frac{(1-\alpha)m}{\nu}\ln\frac{t}{t_i}\).
  3. The oldest node (\(t_i = 1\)) has \(k_{\max}\sim(\ln t)^{1/(1-\alpha)}\). This grows more slowly than any power of \(t\), so there are no hubs and no power law.
  4. For \(\alpha>1\), suppose one node has degree \(k_1 = ct\). Then \(k_1^\alpha = c^\alpha t^\alpha\), which for \(\alpha>1\) grows faster than the sum over all other nodes (about \(t\)).
  5. So \(\Pi(k_1)\to1\). Almost every new link attaches to node 1, which keeps \(k_1\) proportional to \(t\). The assumption is consistent, so one node ends up with a finite fraction of all the links.
Remember

Both ingredients are needed for a power law. Growth alone (Model A) gives \(k_i = m + m\ln\frac t{t_i}\) and an exponential \(P(k) = \frac em e^{-k/m}\). Preferential attachment alone (Model B) gives \(k_i\approx\frac{2t}N\) for every node, and eventually a complete graph.

Nonlinear: \(\alpha<1\) gives no hubs, \(\alpha = 1\) gives BA, and \(\alpha>1\) gives one node with most of the links.

3 · Small-world graphs

About 90 minutes. The board asks for the average clustering coefficient and the path length at \(p = 0\) and \(p = 1\), and the rewiring probability. Part 0a defines clustering and path length.

The Watts–Strogatz model starts from a ring lattice. Place \(n\) nodes in a circle and link each node to its \(k\) nearest nodes on each side, so every node has degree \(2k\). Then go through the links one at a time and, with probability \(p\), move one end of the link to a node chosen at random. This is called rewiring, and \(p\) is the rewiring probability.

  • At \(p = 0\) nothing is rewired, and the graph is the ring lattice.
  • At \(p = 1\) every link is rewired, and the graph is a random graph with the same average degree \(2k\).

The ring lattice has high clustering and long paths. The random graph has low clustering and short paths. For small \(p\), a few rewired links connect distant parts of the ring, so paths become short, while almost all triangles remain, so clustering stays high. A graph with both properties is called a small world.

Watch the letter \(k\)

On this page \(k\) is the number of neighbours on each side, so the degree is \(2k\). If a question gives the degree as \(K\), use \(k = K/2\).

3A · Clustering of the ring lattice, \(C(0)\)

Write this in the exam

Show that \(C(0) = \frac{3(k-1)}{2(2k-1)}\).

  1. Each node has \(2k\) neighbours, so there are \(\binom{2k}2 = k(2k-1)\) pairs of neighbours.
  2. Two neighbours are linked when they are at most \(k\) positions apart on the ring.
  3. Pairs on the same side of the node are always within \(k\) of each other. Each side has \(\binom k2\) pairs, so this gives \(2\binom k2\).
  4. A pair on opposite sides, at positions \(-a\) and \(+b\), is linked when \(a + b\le k\). Counting these gives \((k-1) + (k-2) + \dots + 1 + 0 = \binom k2\).
  5. Linked pairs in total: \(3\binom k2 = \frac32k(k-1)\).
  6. \(C(0) = \frac{\frac32k(k-1)}{k(2k-1)} = \frac{3(k-1)}{2(2k-1)}\). For large \(k\) this approaches \(\frac34\), and it does not depend on \(n\).

3B · Path length of the ring lattice, \(\bar\ell(0)\)

Write this in the exam

Show that \(\bar\ell(0)\approx\frac{n}{4k}\).

  1. From any node, each step along the ring reaches \(k\) more nodes on each side, so exactly \(2k\) new nodes are at each distance \(\ell = 1, 2, \dots\)
  2. The farthest node is \(\frac n2\) positions away. Each step covers \(k\) positions, so the largest distance is \(D = \frac{n}{2k}\).
  3. Average over all nodes: \(\bar\ell(0) = \frac1n\sum_{\ell=1}^{D}2k\,\ell\approx\frac{2k}{n}\cdot\frac{D^2}{2} = \frac{2k}{n}\cdot\frac{n^2}{8k^2} = \frac{n}{4k}\).
  4. \(\bar\ell(0)\) grows in proportion to \(n\), so a large ring lattice has long paths.

3C · The random graph at \(p = 1\)

Write this in the exam

Find \(C\) and \(\bar\ell\) at \(p = 1\).

  1. The graph is random with average degree \(2k\). Any two nodes are linked with probability \(q = \frac{2k}{n-1}\approx\frac{2k}n\).
  2. Links are independent, so two neighbours of a node are linked with the same probability \(q\) as any other pair. So \(C = q\approx\frac{2k}n\), which approaches 0 for large \(n\).
  3. From a node there are about \(2k\) nodes at distance 1, \((2k)^2\) at distance 2, and \((2k)^\ell\) at distance \(\ell\).
  4. All \(n\) nodes are reached when \((2k)^{\bar\ell}\approx n\), so \(\bar\ell\approx\frac{\ln n}{\ln 2k}\). This grows only like \(\ln n\), so paths are short.

4 · Two coupled phase oscillators

About 45 minutes. The board writes \(\dot\theta_1 = f_1(\omega_1, \theta_1, \theta_2, k_1)\) and \(\dot\theta_2 = f_2(\omega_2, \theta_1, \theta_2, k_2)\) and asks for the critical condition.

An oscillator here is anything that repeats a cycle, such as a pendulum or a flashing light. Its state is an angle \(\theta\), called the phase, which increases by \(2\pi\) every cycle. On its own, the phase increases at a constant rate, \(\dot\theta = \omega\). The constant \(\omega\) is the natural frequency.

Two oscillators are coupled when the rate of each phase depends on the other phase.

\[\dot\theta_1 = \omega_1 + k_1\sin(\theta_2 - \theta_1),\qquad\dot\theta_2 = \omega_2 + k_2\sin(\theta_1 - \theta_2).\]

\(k_1\) and \(k_2\) are the coupling strengths. If \(\theta_2\) is slightly ahead of \(\theta_1\), the term \(k_1\sin(\theta_2 - \theta_1)\) is positive, so \(\theta_1\) increases faster, and the term in the second equation is negative, so \(\theta_2\) increases more slowly. The coupling therefore reduces the difference between the phases.

The oscillators are phase-locked (synchronised) when the phase difference \(\phi = \theta_2 - \theta_1\) stays constant. Then both phases increase at the same rate \(\Omega\), the common frequency. The question is how large the coupling must be for this to happen.

Write this in the exam

Find the condition for the two oscillators to lock, and the common frequency \(\Omega\).

  1. Let \(\phi = \theta_2 - \theta_1\) and \(\Delta\omega = \omega_2 - \omega_1\). Subtract the first equation from the second, using \(\sin(\theta_1 - \theta_2) = -\sin\phi\). \[\dot\phi = \Delta\omega - (k_1 + k_2)\sin\phi.\]
  2. Locked means \(\phi\) is constant, so \(\dot\phi = 0\). That gives \(\sin\phi^* = \frac{\Delta\omega}{k_1 + k_2}\).
  3. Since \(|\sin\phi^*|\le1\), a solution exists only if \[|\Delta\omega|\le k_1 + k_2.\] This is the critical condition. With equal couplings \(k_1 = k_2 = k\), the critical coupling is \(k_c = \frac{|\Delta\omega|}{2}\).
  4. Of the two solutions, the stable one has \(\cos\phi^*>0\). The slope of \(\dot\phi\) with respect to \(\phi\) is \(-(k_1 + k_2)\cos\phi\), which must be negative for stability.
  5. In the locked state, \(\Omega = \omega_1 + k_1\sin\phi^* = \omega_2 - k_2\sin\phi^*\). Multiply the first by \(k_2\) and the second by \(k_1\), add, and divide by \(k_1 + k_2\). \[\Omega = \frac{k_2\omega_1 + k_1\omega_2}{k_1 + k_2}.\]
  6. If the condition fails, \(\dot\phi\) is never zero, so the phase difference keeps changing and the oscillators do not lock.
Remember

\(\dot\phi = \Delta\omega - (k_1 + k_2)\sin\phi\). Lock if and only if \(|\Delta\omega|\le k_1 + k_2\). Equal couplings give \(k_c = \frac{|\Delta\omega|}2\).

\(\sin\phi^* = \frac{\Delta\omega}{k_1 + k_2}\), taking the root with \(\cos\phi^*>0\). \(\Omega = \frac{k_2\omega_1 + k_1\omega_2}{k_1 + k_2}\), which is the plain average when \(k_1 = k_2\).

5 · The Lorenz system

About 45 minutes. This uses the fixed points, Jacobian and eigenvalues from Part 0b.

The Lorenz system has three variables \(x\), \(y\) and \(z\) that change together. The constants \(\sigma\), \(\rho\) and \(\beta\) are all positive.

\[\dot x = \sigma(y - x),\qquad\dot y = \rho x - y - xz,\qquad\dot z = xy - \beta z.\]

The question asks for the fixed points and the Jacobian at each one. Solve the simplest equations first.

Write this in the exam

Find the fixed points of the Lorenz system, the Jacobian at each, and show that the origin is stable if and only if \(\rho<1\).

  1. Set all three rates to zero. From \(\sigma(y - x) = 0\), \(y = x\).
  2. From \(xy - \beta z = 0\) with \(y = x\): \(z = \frac{x^2}\beta\).
  3. From \(\rho x - y - xz = 0\) with \(y = x\): \(x(\rho - 1 - z) = 0\). So either \(x = 0\) or \(z = \rho - 1\).
  4. \(x = 0\) gives the origin \(P_0 = (0, 0, 0)\). \(z = \rho - 1\) gives \(x^2 = \beta(\rho - 1)\), so \[P_\pm = \left(\pm\sqrt{\beta(\rho - 1)},\ \pm\sqrt{\beta(\rho - 1)},\ \rho - 1\right),\] which exist only when \(\rho>1\).
  5. The Jacobian, with one row per equation and one column per variable: \[J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho - z & -1 & -x\\ y & x & -\beta\end{pmatrix}.\]
  6. At \(P_0\): \(J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho & -1 & 0\\ 0 & 0 & -\beta\end{pmatrix}\). The third row and column are zero except the corner, so one eigenvalue is \(-\beta<0\).
  7. The other two come from \(\begin{pmatrix}-\sigma & \sigma\\ \rho & -1\end{pmatrix}\), with trace \(T = -(\sigma + 1)<0\) and determinant \(D = \sigma(1 - \rho)\). Stable needs \(T<0\) and \(D>0\). \(T\) is always negative, so the origin is stable if and only if \(\sigma(1 - \rho)>0\), that is, \(\rho<1\). For \(\rho>1\), \(D<0\) and the origin is a saddle.
  8. At \(P_\pm\), let \(c = \sqrt{\beta(\rho - 1)}\). Put \(x = y = \pm c\) and \(z = \rho - 1\), so \(\rho - z = 1\). \[J(P_\pm) = \begin{pmatrix}-\sigma & \sigma & 0\\ 1 & -1 & \mp c\\ \pm c & \pm c & -\beta\end{pmatrix}.\]
Remember

Fixed points: \((0,0,0)\), and for \(\rho>1\), \(\left(\pm\sqrt{\beta(\rho-1)}, \pm\sqrt{\beta(\rho-1)}, \rho - 1\right)\).

\(J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho - z & -1 & -x\\ y & x & -\beta\end{pmatrix}\). The origin is stable if and only if \(\rho<1\).

  3. Put \(y = x\) into (iii). \(x^2 - \beta z = 0\), so \(z = \frac{x^2}\beta\).
  4. Put \(y = x\) into (ii). \(\rho x - x - xz = 0\). Take out the common factor \(x\). \(x(\rho - 1 - z) = 0\). So \(x = 0\) or \(z = \rho - 1\).
  5. Case \(x = 0\). Then \(y = 0\) and \(z = 0\). This is the origin \(P_0 = (0, 0, 0)\).
  6. Case \(z = \rho - 1\). From step 3, \(x^2 = \beta z = \beta(\rho - 1)\), so \(x = \pm\sqrt{\beta(\rho - 1)}\) and \(y = x\). The square root is real only if \(\rho>1\). Write \(c = \sqrt{\beta(\rho - 1)}\). The points are \(P_\pm = (\pm c, \pm c, \rho - 1)\).
  7. Jacobian, row 1. \(f_1 = \sigma y - \sigma x\). \(\frac{\partial f_1}{\partial x} \)\({}= -\sigma\), \(\frac{\partial f_1}{\partial y} \)\({}= \sigma\), \(\frac{\partial f_1}{\partial z} = 0\).
  8. Row 2. \(f_2 = \rho x - y - xz\). \(\frac{\partial f_2}{\partial x} \)\({}= \rho - z\), \(\frac{\partial f_2}{\partial y} = -1\), \(\frac{\partial f_2}{\partial z} = -x\).
  9. Row 3. \(f_3 = xy - \beta z\). \(\frac{\partial f_3}{\partial x} = y\), \(\frac{\partial f_3}{\partial y} = x\), \(\frac{\partial f_3}{\partial z} \)\({}= -\beta\). So \[J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho - z & -1 & -x\\ y & x & -\beta\end{pmatrix}.\]
  10. At \(P_0\), put \(x = y = z = 0\). \[J(P_0) = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho & -1 & 0\\ 0 & 0 & -\beta\end{pmatrix}.\]
  11. At \(P_\pm\), put \(x = y = \pm c\) and \(z = \rho - 1\). Then \(\rho - z = 1\) and \(-x = \mp c\). \[J(P_\pm) = \begin{pmatrix}-\sigma & \sigma & 0\\ 1 & -1 & \mp c\\ \pm c & \pm c & -\beta\end{pmatrix}.\]
Practice · 2 marksFind all the fixed points for \(\sigma = 10\), \(\beta = \frac83\), \(\rho = 28\).›
Formula
\((0,0,0)\), and \(x = y = \pm\sqrt{\beta(\rho - 1)}\), \(z = \rho - 1\) when \(\rho>1\).
Where it comes from
Steps 1 to 4 above.
Working
  1. The origin \((0, 0, 0)\) is always a fixed point.
  2. \(\rho = 28>1\), so the two other fixed points \(P_\pm\) exist.
  3. \(z = \rho - 1 = 28 - 1 = 27\).
  4. \(x^2 \)\({}= \beta(\rho - 1) \)\({}= \frac83\times27 \)\({}= 8\times9 \)\({}= 72\).
  5. \(x = \pm\sqrt{72} = \pm8.49\), and \(y = x\).
  6. The fixed points are \((0, 0, 0)\), \((8.49, 8.49, 27)\) and \((-8.49, -8.49, 27)\). The value of \(\sigma\) is not needed, because it only gives \(y = x\).
Practice · 3 marksWith \(\sigma = 10\) and \(\beta = \frac83\), find the eigenvalues at the origin for \(\rho = 0.5\) and for \(\rho = 28\). Is the origin stable in each case?›
Formula
One eigenvalue is \(-\beta\). The other two are \(\lambda = \frac{T\pm\sqrt{T^2 - 4D}}2\) with \(T = -(\sigma + 1)\) and \(D = \sigma(1 - \rho)\).
Where it comes from
Steps 6 and 7 above, and the 2×2 shortcut in Part 0b.
Working
  1. Put \(\sigma = 10\) and \(\beta = \frac83\) into \(J(P_0)\). \(J = \begin{pmatrix}-10 & 10 & 0\\ \rho & -1 & 0\\ 0 & 0 & -\frac83\end{pmatrix}\).
  2. The third row and third column are zero except the corner entry, so one eigenvalue is \(-\frac83 = -2.67\).
  3. The other two are the eigenvalues of \(\begin{pmatrix}-10 & 10\\ \rho & -1\end{pmatrix}\). \(T = -10 + (-1) = -11\). \(D \)\({}= (-10)(-1) - (10)(\rho) \)\({}= 10 - 10\rho\).
  4. \(\rho = 0.5\). \(D = 10 - 5 = 5\).
  5. \(T^2 - 4D = 121 - 20 = 101\), and \(\sqrt{101} = 10.05\).
  6. \(\lambda = \frac{-11\pm10.05}2\). With \(+\): \(\frac{-0.95}{2} = -0.47\). With \(-\): \(\frac{-21.05}2 = -10.5\).
  7. All three eigenvalues (\(-0.47\), \(-10.5\), \(-2.67\)) are negative, so the origin is stable.
  8. \(\rho = 28\). \(D = 10 - 280 = -270\).
  9. \(T^2 - 4D = 121 + 1080 = 1201\), and \(\sqrt{1201} = 34.7\).
  10. \(\lambda = \frac{-11\pm34.7}2\). With \(+\): \(\frac{23.7}2 = 11.8\). With \(-\): \(\frac{-45.7}2 = -22.8\).
  11. One eigenvalue (11.8) is positive, so the origin is unstable. It is a saddle. Both results agree with the rule that the origin is stable only when \(\rho<1\).
