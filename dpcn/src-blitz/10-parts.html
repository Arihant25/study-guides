1 · The Barabási–Albert (BA) model

About 2 hours. This part and the next are the largest share of the syllabus.

The BA model is a rule for building a network one node at a time. It has two ingredients.

  1. Growth. Start with a few nodes (\(m_0\) of them). At each time step \(t = 1, 2, 3, \dots\), add one new node with \(m\) links.
  2. Preferential attachment. Each of those \(m\) links is attached to an existing node \(i\) with probability
    \[\Pi(k_i) = \frac{k_i}{\sum_jk_j},\]
    This formula is explained below.
Reading the formula

\(\Pi\) (capital pi) is just the name for this probability. It is not the number 3.14.

The top, \(k_i\), is the degree of node \(i\), the node we are asking about.

The bottom, \(\sum_jk_j\), means "add up the degree of every node in the network". The symbol \(\sum_j\) says to let \(j\) run over all the nodes and add the terms. So \(\sum_jk_j = k_1 + k_2 + k_3 + \dots\), the total degree.

So the probability is node \(i\)'s share of the total degree. Dividing by the total makes the probabilities of all the nodes add up to 1, as they must, because the link has to attach to exactly one node.

Example. A network has 4 nodes with degrees 1, 2, 3 and 4. The total is \(\sum_jk_j = 1 + 2 + 3 + 4 = 10\). The probabilities are \(\frac1{10}\), \(\frac2{10}\), \(\frac3{10}\) and \(\frac4{10}\), which add up to \(\frac{10}{10} = 1\). The node of degree 4 is 4 times as likely to receive the link as the node of degree 1.

In general, a node with twice the degree is twice as likely to receive the link. This is why it is called preferential attachment. A node that already has many links is more likely to receive the next one.

In the BA model the total degree is easy to find. Every link adds 1 to the degree of each of its two ends, so each link adds 2 to the total. After \(t\) steps there are \(mt\) links, so \(\sum_jk_j = 2mt\) and \(\Pi(k_i) = \frac{k_i}{2mt}\). Line 3 of 1A uses this.

After \(t\) steps there are about \(t\) nodes and \(mt\) links. Nodes that were added early have had more steps in which to receive links, and every link they receive makes the next one more likely. The result is a power-law degree distribution, \(P(k)\propto k^{-3}\), so the network is scale-free with \(\gamma = 3\).

The board asks for three things. They are the rate \(\frac{dk_i}{dt}\), the distribution \(P(k)\), and the master equation, which is a second way to get \(P(k)\).

1A · The rate \(\frac{dk_i}{dt}\)

Think of \(k_i\) as a smooth number that grows with time. Its rate of change is the expected number of new links that node \(i\) receives in one step.

Write this in the exam

Show that \(\frac{dk_i}{dt} = \frac{k_i}{2t}\), and solve it.

  1. Each step adds \(m\) links. Each attaches to node \(i\) with probability \(\Pi(k_i) \)\({}= \frac{k_i}{\sum_jk_j}\).
  2. Node \(i\) gains \(m\,\Pi(k_i)\) links per step on average. Treating \(k_i\) as continuous (the continuum approximation), \(\frac{dk_i}{dt} \)\({}= m\,\Pi(k_i) \)\({}= \frac{m\,k_i}{\sum_jk_j}\).
    Why lines 1 and 2 work (7 steps)
    1. Each step adds \(m\) new links.
    2. Each of these links attaches to node \(i\) with probability \(\Pi(k_i) \)\({}= \frac{k_i}{\sum_jk_j}\).
    3. So on average node \(i\) receives \(m\,\Pi(k_i)\) new links per step.
    4. One time step is \(\Delta t = 1\). In one step, \(k_i\) changes by some amount \(\Delta k_i\). From step 3, the average of \(\Delta k_i\) is \(m\,\Pi(k_i)\).
    5. So on average, the rate of change is \(\frac{\Delta k_i}{\Delta t} \)\({}= \frac{m\,\Pi(k_i)}{1} \)\({}= m\,\Pi(k_i)\).
    6. In reality \(k_i\) goes up in whole-number jumps. But once the network is large, each jump is tiny compared with \(k_i\), and over many steps the jumps average out.
    7. So \(k_i\) can be treated as a smooth curve, and \(\frac{\Delta k_i}{\Delta t}\) becomes the derivative \(\frac{dk_i}{dt}\). This is called the continuum approximation. \[\frac{dk_i}{dt} = m\,\Pi(k_i) = \frac{m\,k_i}{\sum_jk_j}.\]
  3. Each link adds 2 to the total degree, so \(\sum_jk_j = 2mt\).
  4. So \(\frac{dk_i}{dt} \)\({}= \frac{m\,k_i}{2mt} \)\({}= \frac{k_i}{2t}\), which is proportional to \(\frac{k_i}t\).
    Why lines 3 and 4 work (4 steps)
    1. Find the total degree. After \(t\) steps there are \(mt\) links (ignoring the few starting links).
    2. Each link adds 1 to the degree of each of its two ends, so it adds 2 to the total. So \(\sum_jk_j = 2mt\).
    3. Substitute this into line 2. \(\frac{dk_i}{dt} \)\({}= \frac{m\,k_i}{2mt}\).
    4. Cancel \(m\). \(\frac{dk_i}{dt} \)\({}= \frac{k_i}{2t}\). This proves that the rate is proportional to \(\frac{k_i}t\).
  5. Separate the variables and integrate from \(k_i(t_i) = m\). \(\int_m^{k_i}\frac{dk}k \)\({}= \frac12\int_{t_i}^t\frac{dt'}{t'}\), so \(\ln\frac{k_i}m \)\({}= \frac12\ln\frac t{t_i}\).
  6. So \[k_i(t) = m\sqrt{t/t_i}.\]
    Why lines 5 and 6 work (7 steps)
    1. Separate the variables. Divide both sides by \(k_i\) and multiply both sides by \(dt\). \(\frac{dk_i}{k_i} \)\({}= \frac12\,\frac{dt}{t}\).
    2. Node \(i\) was added at time \(t_i\) with \(m\) links, so \(k_i(t_i) = m\). Integrate both sides from there. \[\int_m^{k_i}\frac{dk}{k} = \frac12\int_{t_i}^t\frac{dt'}{t'}.\]
    3. Use \(\int\frac{dx}x = \ln x\). \(\ln k_i - \ln m \)\({}= \frac12(\ln t - \ln t_i)\).
    4. Use \(\ln a - \ln b = \ln\frac ab\) on both sides. \(\ln\frac{k_i}m \)\({}= \frac12\ln\frac t{t_i}\).
    5. Use \(\frac12\ln y = \ln\sqrt y\). \(\ln\frac{k_i}m \)\({}= \ln\sqrt{t/t_i}\).
    6. If \(\ln A = \ln B\) then \(A = B\). So \(\frac{k_i}m = \sqrt{t/t_i}\).
    7. Multiply both sides by \(m\). \[k_i(t) = m\sqrt{t/t_i}.\] A node added earlier (smaller \(t_i\)) has a larger degree.

1B · The degree distribution \(P(k)\) (continuum theory)

The degree of a node depends only on when it was added. So the question "what fraction of nodes have degree below \(k\)?" becomes "what fraction of nodes were added after a certain time?", and joining times are spread evenly.

Write this in the exam

Show that \(P(k) = 2m^2k^{-3}\).

  1. From 1A, \(k_i = m\sqrt{t/t_i}\), so \(t_i = \frac{m^2t}{k_i^2}\).
    Why line 1 works (4 steps)
    1. From 1A, \(k_i = m\sqrt{t/t_i}\). Solve this for the joining time \(t_i\).
    2. Divide by \(m\). \(\frac{k_i}m = \sqrt{t/t_i}\).
    3. Square both sides. \(\frac{k_i^2}{m^2} \)\({}= \frac t{t_i}\).
    4. Rearrange. \(t_i = \frac{m^2t}{k_i^2}\).
  2. A node has degree below \(k\) exactly when it joined after \(T = \frac{m^2t}{k^2}\).
    Why line 2 works (1 step)
    1. A node that joined later has a smaller degree. So a node has degree below \(k\) exactly when it joined after the time \(T = \frac{m^2t}{k^2}\).
  3. Joining times are spread evenly, so the fraction that joined after \(T\) is \(1 - \frac Tt\). So \(F(k) = 1 - \frac{m^2}{k^2}\).
    Why line 3 works (2 steps)
    1. Joining times are spread evenly over \(1\dots t\) (Part 0c). So the fraction that joined after \(T\) is \(1 - \frac Tt\).
    2. Put in \(T\). \(\frac Tt = \frac{m^2}{k^2}\), so the fraction with degree below \(k\) is \(F(k) = 1 - \frac{m^2}{k^2}\). The \(t\) has cancelled, so this does not change as the network grows.
  4. \(P(k) \)\({}= \frac{dF}{dk} \)\({}= \frac{2m^2}{k^3}\), a power law with \(\gamma = 3\).
    Why line 4 works (3 steps)
    1. Write \(F(k) = 1 - m^2k^{-2}\) and differentiate. The derivative of \(k^{-2}\) is \(-2k^{-3}\).
    2. So \(P(k) \)\({}= \frac{dF}{dk} \)\({}= -m^2\times(-2k^{-3}) \)\({}= \frac{2m^2}{k^3}\).
    3. This is a power law with \(\gamma = 3\), whatever the value of \(m\).

1C · The master equation

Why "master equation". It is one equation that accounts for every way the number of degree-\(k\) nodes can change in one step. Some are gained from degree \(k - 1\) and some are lost to degree \(k + 1\). Solving it gives the whole distribution \(P(k)\) at once. In physics, any equation of this gain-and-loss form for a probability distribution is called a master equation, and the name was carried over to networks.

This method gives \(P(k)\) by counting. Let \(N(k, t)\) be the number of nodes with degree \(k\) at time \(t\). There are \(t\) nodes at time \(t\), so the fraction is \(P(k, t) = \frac{N(k, t)}t\). In one step, a node of degree \(k - 1\) that receives a link moves up to degree \(k\). A node of degree \(k\) that receives a link moves up to degree \(k + 1\). The new node adds one node of degree \(m\).

Write this in the exam

Write the master equation for the BA model and solve it for \(P(k)\).

  1. Each of the \(m\) new links attaches to a particular degree-\(k\) node with probability \(\frac{k}{2mt}\). So that node receives a link with probability \(m\cdot\frac{k}{2mt} \)\({}= \frac k{2t}\).
    Why line 1 works (2 steps)
    1. In one step there are \(m\) new links.
    2. Each one attaches to a particular degree-\(k\) node with probability \(\frac{k}{2mt}\) (1A, lines 1 and 3).
  2. There are \(N(k, t) = t\,P(k, t)\) degree-\(k\) nodes. So on average \(\frac k{2t}\times t\,P(k, t) = \frac k2P(k, t)\) of them receive a link in one step.
    Why line 2 works (2 steps)
    1. There are \(N(k, t)\) degree-\(k\) nodes. So the expected (average) number of degree-\(k\) nodes that receive a link in one step is \(m\times N(k, t)\times\frac k{2mt}\).
    2. Cancel \(m\). This is \(\frac{k\,N(k, t)}{2t}\). Since \(N(k, t) = t\,P(k, t)\), it equals \(\frac k2P(k, t)\).
  3. For \(k>m\),\[N(k, t+1) - N(k, t) = \frac{k-1}2P(k-1, t) - \frac k2P(k, t).\]\[N(k, t+1) - N(k, t)\]\[{}= \frac{k-1}2P(k-1, t) - \frac k2P(k, t).\]
    Why line 3 works (2 steps)
    1. For \(k>m\), the number of degree-\(k\) nodes goes up by one for each degree-\((k-1)\) node that receives a link.
    2. It goes down by one for each degree-\(k\) node that receives a link. Using line 2 for both, \[N(k, t+1) - N(k, t) = \frac{k-1}2P(k-1, t) - \frac k2P(k, t).\]\[N(k, t+1) - N(k, t)\]\[{}= \frac{k-1}2P(k-1, t) - \frac k2P(k, t).\]
  4. For \(k = m\),\[N(m, t+1) = N(m, t) + 1 - \frac m2P(m, t).\]
    Why line 4 works (1 step)
    1. For \(k = m\), no node can move up into degree \(m\), because every node starts with \(m\) links. The new node adds one node of degree \(m\). \[N(m, t+1) = N(m, t) + 1 - \frac m2P(m, t).\]
  5. In the steady state \(P(k, t) = P(k)\), so \(N(k, t+1) - N(k, t) = P(k)\).
    Why line 5 works (2 steps)
    1. Look for a steady state, where \(P(k, t) = P(k)\) does not depend on \(t\). Then \(N(k, t) = t\,P(k)\) and \(N(k, t+1) = (t+1)P(k)\).
    2. Subtract. \(N(k, t+1) - N(k, t) \)\({}= (t+1)P(k) - tP(k) \)\({}= P(k)\).
  6. At \(k = m\), \(P(m) = 1 - \frac m2P(m)\), so \(P(m) = \frac2{m+2}\).
    Why line 6 works (2 steps)
    1. Case \(k = m\). Subtract \(N(m, t)\) from both sides of line 4 and use line 5. \(P(m) = 1 - \frac m2P(m)\).
    2. Add \(\frac m2P(m)\) to both sides. \(\frac{m+2}2P(m) = 1\), so \(P(m) = \frac2{m+2}\).
  7. For \(k>m\), \(P(k) \)\({}= \frac{k-1}2P(k-1) - \frac k2P(k)\), so \(P(k) = \frac{k-1}{k+2}P(k-1)\).
    Why line 7 works (3 steps)
    1. Case \(k>m\). Do the same with line 3. \(P(k) \)\({}= \frac{k-1}2P(k-1) - \frac k2P(k)\).
    2. Add \(\frac k2P(k)\) to both sides. \(\frac{k+2}2P(k) \)\({}= \frac{k-1}2P(k-1)\).
    3. Multiply by 2 and divide by \(k + 2\). \[P(k) = \frac{k-1}{k+2}\,P(k-1).\]
  8. Apply this repeatedly from \(P(m)\) and cancel. \[P(k) = \frac{2m(m+1)}{k(k+1)(k+2)}.\]
    Why line 8 works (5 steps)
    1. Apply this again and again, starting from \(P(m)\). \(P(m+1) = \frac m{m+3}P(m)\), then \(P(m+2) \)\({}= \frac{m+1}{m+4}P(m+1)\), and so on up to \(P(k) = \frac{k-1}{k+2}P(k-1)\).
    2. Multiply all of these together. \[\frac{P(k)}{P(m)} = \frac{m(m+1)(m+2)\cdots(k-1)}{(m+3)(m+4)\cdots(k+2)}.\]
    3. The top is every whole number from \(m\) to \(k - 1\). The bottom is every whole number from \(m + 3\) to \(k + 2\). The numbers from \(m + 3\) to \(k - 1\) are in both, so they cancel.
    4. Left on the top are \(m(m+1)(m+2)\). Left on the bottom are \(k(k+1)(k+2)\). With \(P(m) = \frac2{m+2}\), \[P(k) = \frac2{m+2}\times\frac{m(m+1)(m+2)}{k(k+1)(k+2)}.\]
    5. Cancel \(m + 2\). \[P(k) = \frac{2m(m+1)}{k(k+1)(k+2)}.\]
  9. For large \(k\), \(P(k)\approx\frac{2m(m+1)}{k^3}\propto k^{-3}\).
    Why line 9 works (1 step)
    1. For large \(k\), \(k(k+1)(k+2)\) is about \(k^3\). So \(P(k)\approx\frac{2m(m+1)}{k^3}\propto k^{-3}\), the same power law (\(\gamma = 3\)) as in 1B.
Remember

Ingredients are growth and preferential attachment, \(\Pi(k_i) = \frac{k_i}{\sum_jk_j}\). The total degree is \(\sum_jk_j = 2mt\).

\(\frac{dk_i}{dt} = \frac{k_i}{2t}\), so \(k_i = m\sqrt{t/t_i}\). The fraction with degree below \(k\) is \(1 - \frac{m^2}{k^2}\), so \(P(k) = 2m^2k^{-3}\).

Master equation: \(P(m) = \frac2{m+2}\) and \(P(k) = \frac{k-1}{k+2}P(k-1)\), so \(P(k) = \frac{2m(m+1)}{k(k+1)(k+2)}\).

    5. Joining times are spread evenly, so the fraction that joined after \(T = t\,e^{1-k/m}\) is \(1 - \frac Tt\). So \(F(k) = 1 - e^{1 - k/m}\).
  5. \(P(k) \)\({}= \frac{dF}{dk} \)\({}= \frac em\,e^{-k/m}\). This is exponential, so there are no hubs and the network is not scale-free.
    Why line 5 works (3 steps)
    1. Differentiate. By the chain rule, the derivative of \(e^{1-k/m}\) is \(e^{1-k/m}\times\left(-\frac1m\right)\).
    2. So \(P(k) \)\({}= \frac{dF}{dk} \)\({}= \frac1m e^{1-k/m} \)\({}= \frac em\,e^{-k/m}\) for \(k\ge m\).
    3. This is exponential, not a power law. Large degrees are extremely rare, so there are no hubs and the network is not scale-free.

2B · Preferential attachment without growth (Model B)

Now the number of nodes is fixed at \(N\) and no nodes are added. At each step, one node is chosen uniformly at random, and a new link is added from it to a node chosen by preferential attachment.

Write this in the exam

Find \(k_i(t)\) for Model B and describe the degree distribution.

  1. Each step adds one link and no node, so \(\sum_jk_j = 2t\).
    Why line 1 works (2 steps)
    1. Each step adds one link and no node. After \(t\) steps there are \(t\) links.
    2. Each link adds 2 to the total degree, so \(\sum_jk_j = 2t\).
  2. Node \(i\) is the random end with probability \(\frac1N\) or the preferential end with probability \(\frac{k_i}{2t}\). So \(\frac{dk_i}{dt} \)\({}= \frac1N + \frac{k_i}{2t}\).
    Why line 2 works (3 steps)
    1. Node \(i\) is the randomly chosen end of the new link with probability \(\frac1N\).
    2. It is the preferentially chosen end with probability \(\frac{k_i}{\sum_jk_j} \)\({}= \frac{k_i}{2t}\).
    3. The average number of new links per step is the sum of these, and as in 1A, line 2, that is the rate. \(\frac{dk_i}{dt} \)\({}= \frac1N + \frac{k_i}{2t}\).
  3. The solution is \(k_i(t) \)\({}= \frac{2t}N + C_i\sqrt t\). (Substitute it to check.)
    Why line 3 works (6 steps)
    1. Look for a solution that grows in proportion to \(t\). Put \(k_i = at\), so \(\frac{dk_i}{dt} = a\).
    2. The equation becomes \(a \)\({}= \frac1N + \frac{at}{2t} \)\({}= \frac1N + \frac a2\).
    3. Subtract \(\frac a2\). \(\frac a2 = \frac1N\), so \(a = \frac2N\). So \(k_i = \frac{2t}N\) is one solution.
    4. Now try \(k_i = \frac{2t}N + C_i\sqrt t\), where \(C_i\) is a constant. The left side is \(\frac{dk_i}{dt} \)\({}= \frac2N + \frac{C_i}{2\sqrt t}\).
    5. The right side is \(\frac1N + \frac1{2t}\left(\frac{2t}N + C_i\sqrt t\right) \)\({}= \frac1N + \frac1N + \frac{C_i}{2\sqrt t}\).
    6. The two sides are equal, so this solves the equation for any \(C_i\). The value of \(C_i\) depends on the node’s starting degree.
  4. For large \(t\) the \(\frac{2t}N\) part is much larger, so every degree is close to \(\frac{2t}N\). \(P(k)\) is a narrow peak, not a power law.
    Why line 4 works (2 steps)
    1. The \(\frac{2t}N\) part is the same for every node and grows like \(t\). The \(C_i\sqrt t\) part grows only like \(\sqrt t\).
    2. So for large \(t\) every degree is close to \(\frac{2t}N\). The distribution is a narrow peak around the average, not a power law.
  5. After about \(\frac{N^2}2\) steps every pair is linked, so the network becomes complete.
    Why line 5 works (1 step)
    1. There are only \(\frac{N(N-1)}2\) possible links. After about \(\frac{N^2}2\) steps every pair of nodes is linked, so the network is complete and never settles to a steady state.

2C · Nonlinear preferential attachment

Nodes are added as in BA, but the attachment probability uses a power \(\alpha\) of the degree.

\[\Pi(k_i) = \frac{k_i^\alpha}{\sum_jk_j^\alpha},\qquad\alpha\ge0.\]

\(\alpha\) is the Greek letter alpha. \(\alpha = 0\) gives Model A, because \(k^0 = 1\) for every node. \(\alpha = 1\) gives the BA model. The table is what to learn. In the last column, \(\sim\) means "grows like", ignoring constant factors.

Write this in the exam

Explain what happens for \(\alpha<1\) and for \(\alpha>1\).

  1. For \(\alpha<1\), \(\sum_jk_j^\alpha\approx\nu t\), so \(\frac{dk_i}{dt} \)\({}= \frac{m\,k_i^\alpha}{\nu t}\).
    Why line 1 works (2 steps)
    1. For \(\alpha<1\), degrees stay small (line 3 checks this). So the values \(k_j^\alpha\) have some fixed average, called \(\nu\) (the Greek letter nu).
    2. With about \(t\) nodes, \(\sum_jk_j^\alpha\approx\nu t\). So \(\frac{dk_i}{dt} \)\({}= m\,\Pi(k_i) \)\({}= \frac{m\,k_i^\alpha}{\nu t}\).
  2. Integrating gives \(k_i^{1-\alpha} \)\({}= m^{1-\alpha} + \frac{(1-\alpha)m}\nu\ln\frac t{t_i}\).
    Why line 2 works (3 steps)
    1. Separate the variables. \(k_i^{-\alpha}\,dk_i \)\({}= \frac m\nu\,\frac{dt}t\).
    2. Integrate from \(k_i(t_i) = m\), using \(\int k^{-\alpha}dk \)\({}= \frac{k^{1-\alpha}}{1-\alpha}\). \[\frac{k_i^{1-\alpha} - m^{1-\alpha}}{1-\alpha} = \frac m\nu\ln\frac t{t_i}.\]
    3. Multiply by \(1 - \alpha\) and add \(m^{1-\alpha}\). \[k_i^{1-\alpha} = m^{1-\alpha} + \frac{(1-\alpha)m}{\nu}\ln\frac{t}{t_i}.\]
  3. So \(k_{\max}\sim(\ln t)^{1/(1-\alpha)}\), which grows more slowly than any power of \(t\). There are no hubs and no power law.
    Why line 3 works (3 steps)
    1. The largest degree belongs to the oldest node, \(t_i = 1\). For large \(t\) the \(\ln t\) term is much bigger than \(m^{1-\alpha}\), so \(k_{\max}^{1-\alpha}\approx\frac{(1-\alpha)m}\nu\ln t\).
    2. Raise both sides to the power \(\frac1{1-\alpha}\). \(k_{\max}\sim(\ln t)^{1/(1-\alpha)}\).
    3. This grows more slowly than any power of \(t\). So degrees do stay small, and there are no hubs and no power law.
  4. For \(\alpha>1\), if one node has \(k_1 = ct\), then \(\Pi(k_1) \)\({}= \frac{c^\alpha t^\alpha}{c^\alpha t^\alpha + bt}\to1\).
    Why line 4 works (4 steps)
    1. For \(\alpha>1\), suppose one node has degree \(k_1 = ct\) for some constant \(c\). Its term in the sum is \(k_1^\alpha \)\({}= c^\alpha t^\alpha\).
    2. The other nodes (about \(t\) of them) have small degrees, so their terms add up to about \(bt\) for some constant \(b\).
    3. \(\Pi(k_1) \)\({}= \frac{c^\alpha t^\alpha}{c^\alpha t^\alpha + bt}\). Divide the top and bottom by \(c^\alpha t^\alpha\). \(\Pi(k_1) \)\({}= \frac1{1 + \frac b{c^\alpha t^{\alpha-1}}}\).
    4. Since \(\alpha>1\), \(t^{\alpha-1}\) grows without limit. So \(\frac b{c^\alpha t^{\alpha-1}}\) goes to 0, and \(\Pi(k_1)\) goes to 1.
  5. So that node receives almost every new link, and ends up with a finite fraction of all the links.
    Why line 5 works (2 steps)
    1. So almost every new link attaches to node 1. It gains about \(m\) links per step, so \(k_1\approx mt\), which agrees with the starting assumption.
    2. One node ends up with a finite fraction of all the links, and every other node keeps a small degree.
Remember

Both ingredients are needed for a power law. Growth alone (Model A) gives \(k_i = m + m\ln\frac t{t_i}\) and an exponential \(P(k) = \frac em e^{-k/m}\). Preferential attachment alone (Model B) gives \(k_i\approx\frac{2t}N\) for every node, and eventually a complete graph.

Nonlinear: \(\alpha<1\) gives no hubs, \(\alpha = 1\) gives BA, and \(\alpha>1\) gives one node with most of the links.

3 · Small-world graphs

About 90 minutes. The board asks for the average clustering coefficient and the path length at \(p = 0\) and \(p = 1\), and the rewiring probability. Part 0a defines clustering and path length.

The Watts–Strogatz model starts from a ring lattice. Place \(n\) nodes in a circle and link each node to its \(k\) nearest nodes on each side, so every node has degree \(2k\). Then go through the links one at a time and, with probability \(p\), move one end of the link to a node chosen at random. This is called rewiring, and \(p\) is the rewiring probability.

  • At \(p = 0\) nothing is rewired, and the graph is the ring lattice.
  • At \(p = 1\) every link is rewired, and the graph is a random graph with the same average degree \(2k\).

The ring lattice has high clustering and long paths. The random graph has low clustering and short paths. For small \(p\), a few rewired links connect distant parts of the ring, so paths become short, while almost all triangles remain, so clustering stays high. A graph with both properties is called a small world.

Watch the letter \(k\)

On this page \(k\) is the number of neighbours on each side, so the degree is \(2k\). If a question gives the degree as \(K\), use \(k = K/2\).

3A · Clustering of the ring lattice, \(C(0)\)

Write this in the exam

Show that \(C(0) = \frac{3(k-1)}{2(2k-1)}\).

  1. A node has \(2k\) neighbours, so there are \(k(2k-1)\) pairs of neighbours.
    Why line 1 works (1 step)
    1. Each node has \(2k\) neighbours. The number of pairs of neighbours is \(\frac{2k(2k-1)}2 = k(2k-1)\).
  2. Two neighbours are linked when they are at most \(k\) apart. Pairs on the same side are all linked, which gives \(2\times\frac{k(k-1)}2 \)\({}= k(k-1)\).
    Why line 2 works (3 steps)
    1. Two neighbours are linked when they are at most \(k\) positions apart on the ring.
    2. Pairs on the same side. The right-hand neighbours are at positions \(1, 2, \dots, k\). Any two of them are at most \(k - 1\) apart, so every such pair is linked.
    3. That side has \(\frac{k(k-1)}2\) pairs, and the left side has the same number. Together this gives \(k(k-1)\) linked pairs.
  3. Pairs on opposite sides, at \(-a\) and \(+b\), are linked when \(a + b\le k\). There are \((k-1) + (k-2) + \dots + 1 \)\({}= \frac{k(k-1)}2\) of them.
    Why line 3 works (3 steps)
    1. Pairs on opposite sides. Take positions \(-a\) and \(+b\), with \(a\) and \(b\) between 1 and \(k\). They are \(a + b\) apart, so they are linked when \(a + b\le k\).

4 · Two coupled phase oscillators

About 45 minutes. The board writes \(\dot\theta_1 = f_1(\omega_1, \theta_1, \theta_2, k_1)\) and \(\dot\theta_2 = f_2(\omega_2, \theta_1, \theta_2, k_2)\) and asks for the critical condition.

An oscillator here is anything that repeats a cycle, such as a pendulum or a flashing light. Its state is an angle \(\theta\), called the phase, which increases by \(2\pi\) every cycle. On its own, the phase increases at a constant rate, \(\dot\theta = \omega\). The constant \(\omega\) is the natural frequency.

Two oscillators are coupled when the rate of each phase depends on the other phase.

\[\dot\theta_1 = \omega_1 + k_1\sin(\theta_2 - \theta_1),\qquad\dot\theta_2 = \omega_2 + k_2\sin(\theta_1 - \theta_2).\]

\(k_1\) and \(k_2\) are the coupling strengths. If \(\theta_2\) is slightly ahead of \(\theta_1\), the term \(k_1\sin(\theta_2 - \theta_1)\) is positive, so \(\theta_1\) increases faster, and the term in the second equation is negative, so \(\theta_2\) increases more slowly. The coupling therefore reduces the difference between the phases.

The oscillators are phase-locked (synchronised) when the phase difference \(\phi = \theta_2 - \theta_1\) stays constant. Then both phases increase at the same rate \(\Omega\), the common frequency. The question is how large the coupling must be for this to happen.

Write this in the exam

Find the condition for the two oscillators to lock, and the common frequency \(\Omega\).

  1. Let \(\phi = \theta_2 - \theta_1\) and \(\Delta\omega \)\({}= \omega_2 - \omega_1\). Subtracting the equations and using \(\sin(-\phi) = -\sin\phi\) gives \[\dot\phi = \Delta\omega - (k_1 + k_2)\sin\phi.\]
    Why line 1 works (3 steps)
    1. Let \(\phi = \theta_2 - \theta_1\) and \(\Delta\omega \)\({}= \omega_2 - \omega_1\).
    2. Subtract the first equation from the second. \(\dot\phi \)\({}= \dot\theta_2 - \dot\theta_1\). Put in the two equations. \[\dot\phi = \Delta\omega + k_2\sin(\theta_1 - \theta_2) - k_1\sin(\theta_2 - \theta_1).\]\[\dot\phi = \Delta\omega + k_2\sin(\theta_1 - \theta_2)\]\[{} - k_1\sin(\theta_2 - \theta_1).\]
    3. Now \(\sin(\theta_2 - \theta_1) \)\({}= \sin\phi\) and \(\sin(\theta_1 - \theta_2) \)\({}= \sin(-\phi) \)\({}= -\sin\phi\). So \[\dot\phi = \Delta\omega - (k_1 + k_2)\sin\phi.\]
  2. Locked means \(\dot\phi = 0\), so \(\sin\phi^* \)\({}= \frac{\Delta\omega}{k_1 + k_2}\).
    Why line 2 works (1 step)
    1. Locked means \(\phi\) is constant, so \(\dot\phi = 0\). Then \((k_1 + k_2)\sin\phi^* \)\({}= \Delta\omega\), so \(\sin\phi^* \)\({}= \frac{\Delta\omega}{k_1 + k_2}\).
  3. Since \(|\sin\phi^*|\le1\), they lock if and only if \(|\Delta\omega|\le k_1 + k_2\). With \(k_1 = k_2 = k\), \(k_c = \frac{|\Delta\omega|}2\).
    Why line 3 works (2 steps)
    1. A sine is never more than 1 in size. So a solution exists only if \(\left|\frac{\Delta\omega}{k_1 + k_2}\right|\le1\), that is, \[|\Delta\omega|\le k_1 + k_2.\] This is the critical condition.
    2. With equal couplings \(k_1 = k_2 = k\), the condition reads \(|\Delta\omega|\le2k\). So the critical coupling is \(k_c \)\({}= \frac{|\Delta\omega|}{2}\).
  4. The stable solution has \(\cos\phi^*>0\), because the slope \(-(k_1 + k_2)\cos\phi^*\) must be negative.
    Why line 4 works (3 steps)
    1. There are two solutions, \(\arcsin\frac{\Delta\omega}{k_1+k_2}\) and \(\pi\) minus that (Part 0c).
    2. To see which is stable, treat \(\dot\phi = g(\phi)\) like \(\dot x = f(x)\) in Part 0b. The slope is \(g'(\phi) \)\({}= -(k_1 + k_2)\cos\phi\).
    3. Stable needs \(g'(\phi^*)<0\), which means \(\cos\phi^*>0\). So the stable one is \(\phi^* \)\({}= \arcsin\frac{\Delta\omega}{k_1+k_2}\), the one below \(\frac\pi2\).
  5. When locked, \(\Omega \)\({}= \omega_1 + k_1\sin\phi^* \)\({}= \omega_2 - k_2\sin\phi^*\). Eliminating \(\sin\phi^*\) gives \[\Omega = \frac{k_2\omega_1 + k_1\omega_2}{k_1 + k_2}.\]
    Why line 5 works (3 steps)
    1. In the locked state both phases increase at the same rate \(\Omega\). Put \(\theta_2 - \theta_1 = \phi^*\) into each equation. \(\Omega \)\({}= \omega_1 + k_1\sin\phi^*\) and \(\Omega \)\({}= \omega_2 - k_2\sin\phi^*\).
    2. Multiply the first by \(k_2\) and the second by \(k_1\). \(k_2\Omega \)\({}= k_2\omega_1 + k_1k_2\sin\phi^*\) and \(k_1\Omega \)\({}= k_1\omega_2 - k_1k_2\sin\phi^*\).
    3. Add them. The \(\sin\phi^*\) terms cancel. \((k_1 + k_2)\Omega \)\({}= k_2\omega_1 + k_1\omega_2\), so \[\Omega = \frac{k_2\omega_1 + k_1\omega_2}{k_1 + k_2}.\]
  6. If \(|\Delta\omega|>k_1 + k_2\), \(\dot\phi\) is never zero, so they do not lock.
    Why line 6 works (1 step)
    1. If the condition fails, \(\dot\phi\) is never zero. The phase difference keeps changing, so the oscillators do not lock.
Remember

\(\dot\phi = \Delta\omega - (k_1 + k_2)\sin\phi\). Lock if and only if \(|\Delta\omega|\le k_1 + k_2\). Equal couplings give \(k_c = \frac{|\Delta\omega|}2\).

5 · The Lorenz system

About 45 minutes. This uses the fixed points, Jacobian and eigenvalues from Part 0b.

The Lorenz system has three variables \(x\), \(y\) and \(z\) that change together. The constants \(\sigma\), \(\rho\) and \(\beta\) are all positive.

\[\dot x = \sigma(y - x),\qquad\dot y = \rho x - y - xz,\qquad\dot z = xy - \beta z.\]

The question asks for the fixed points and the Jacobian at each one. Solve the simplest equations first.

Write this in the exam

Find the fixed points of the Lorenz system, the Jacobian at each, and show that the origin is stable if and only if \(\rho<1\).

  1. Fixed points have \(\sigma(y - x) = 0\), \(\rho x - y - xz = 0\) and \(xy - \beta z = 0\).
    Why line 1 works (1 step)
    1. At a fixed point all three rates are zero. (i) \(\sigma(y - x) = 0\). (ii) \(\rho x - y - xz = 0\). (iii) \(xy - \beta z = 0\).
  2. The first gives \(y = x\). The third then gives \(z = \frac{x^2}\beta\). The second gives \(x(\rho - 1 - z) = 0\).
    Why line 2 works (4 steps)
    1. From (i), since \(\sigma>0\), \(y - x = 0\), so \(y = x\).
    2. Put \(y = x\) into (iii). \(x^2 - \beta z = 0\), so \(z = \frac{x^2}\beta\).
    3. Put \(y = x\) into (ii). \(\rho x - x - xz = 0\).
    4. Take out the common factor \(x\). \(x(\rho - 1 - z) = 0\). So either \(x = 0\) or \(z = \rho - 1\).
  3. So \(P_0 = (0, 0, 0)\), and for \(\rho>1\), \(P_\pm \)\({}= (\pm c, \pm c, \rho - 1)\) with \(c = \sqrt{\beta(\rho - 1)}\).
    Why line 3 works (3 steps)
    1. Case \(x = 0\). Then \(y = 0\) and \(z = \frac{0^2}\beta = 0\). This is the origin \(P_0 = (0, 0, 0)\).
    2. Case \(z = \rho - 1\). From line 2, \(x^2 \)\({}= \beta z \)\({}= \beta(\rho - 1)\), so \(x = \pm\sqrt{\beta(\rho - 1)}\) and \(y = x\).
    3. The square root is real only when \(\rho - 1>0\), that is, \(\rho>1\). Write \(c = \sqrt{\beta(\rho - 1)}\). \[P_\pm = (\pm c,\ \pm c,\ \rho - 1).\]
  4. \[J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho - z & -1 & -x\\ y & x & -\beta\end{pmatrix}.\]
    Why line 4 works (4 steps)
    1. The Jacobian has one row per equation and one column per variable (\(x\), \(y\), \(z\)). Each entry is a partial derivative.
    2. Row 1, from \(\sigma y - \sigma x\), is \(-\sigma,\ \sigma,\ 0\).
    3. Row 2, from \(\rho x - y - xz\), is \(\rho - z,\ -1,\ -x\).
    4. Row 3, from \(xy - \beta z\), is \(y,\ x,\ -\beta\). So \[J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho - z & -1 & -x\\ y & x & -\beta\end{pmatrix}.\]
  5. \(J(P_0) = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho & -1 & 0\\ 0 & 0 & -\beta\end{pmatrix}\). One eigenvalue is \(-\beta\). The other two come from the 2×2 block, with \(T = -(\sigma + 1)<0\) and \(D = \sigma(1 - \rho)\).
    Why line 5 works (4 steps)
    1. At \(P_0\), put \(x = y = z = 0\). \[J(P_0) = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho & -1 & 0\\ 0 & 0 & -\beta\end{pmatrix}.\]
    2. The third row and column of \(J(P_0)\) are zero except the corner, so one eigenvalue is \(-\beta\), which is negative (Part 0b).
    3. The other two come from the block \(\begin{pmatrix}-\sigma & \sigma\\ \rho & -1\end{pmatrix}\). Its trace is \(T \)\({}= -\sigma + (-1) \)\({}= -(\sigma + 1)\).
    4. Its determinant is \(D \)\({}= (-\sigma)(-1) - (\sigma)(\rho) \)\({}= \sigma - \sigma\rho \)\({}= \sigma(1 - \rho)\).
  6. So the origin is stable if and only if \(D>0\), that is, \(\rho<1\). For \(\rho>1\) it is a saddle.
    Why line 6 works (2 steps)
    1. Stable needs \(T<0\) and \(D>0\). \(T\) is always negative because \(\sigma>0\).
    2. \(D = \sigma(1 - \rho)>0\) exactly when \(\rho<1\). So the origin is stable if and only if \(\rho<1\). For \(\rho>1\), \(D<0\) and the origin is a saddle.
  7. \[J(P_\pm) = \begin{pmatrix}-\sigma & \sigma & 0\\ 1 & -1 & \mp c\\ \pm c & \pm c & -\beta\end{pmatrix}.\]
    Why line 7 works (1 step)
    1. At \(P_\pm\), put \(x = y = \pm c\) and \(z = \rho - 1\). Then \(\rho - z = 1\) and \(-x = \mp c\). \[J(P_\pm) = \begin{pmatrix}-\sigma & \sigma & 0\\ 1 & -1 & \mp c\\ \pm c & \pm c & -\beta\end{pmatrix}.\]
Remember

Fixed points: \((0,0,0)\), and for \(\rho>1\), \(\left(\pm\sqrt{\beta(\rho-1)}, \pm\sqrt{\beta(\rho-1)}, \rho - 1\right)\).

Working
  1. At a fixed point all three rates are zero. (i) \(\sigma(y - x) = 0\). (ii) \(\rho x - y - xz = 0\). (iii) \(xy - \beta z = 0\).
  2. From (i), since \(\sigma>0\), \(y - x = 0\), so \(y = x\).
  3. Put \(y = x\) into (iii). \(x^2 - \beta z = 0\), so \(z = \frac{x^2}\beta\).
  4. Put \(y = x\) into (ii). \(\rho x - x - xz = 0\). Take out the common factor \(x\). \(x(\rho - 1 - z) = 0\). So \(x = 0\) or \(z = \rho - 1\).
  5. Case \(x = 0\). Then \(y = 0\) and \(z = 0\). This is the origin \(P_0 = (0, 0, 0)\).
  6. Case \(z = \rho - 1\). From step 3, \(x^2 \)\({}= \beta z \)\({}= \beta(\rho - 1)\), so \(x = \pm\sqrt{\beta(\rho - 1)}\) and \(y = x\). The square root is real only if \(\rho>1\). Write \(c = \sqrt{\beta(\rho - 1)}\). The points are \(P_\pm \)\({}= (\pm c, \pm c, \rho - 1)\).
  7. Jacobian, row 1. \(f_1 = \sigma y - \sigma x\). \(\frac{\partial f_1}{\partial x} \)\({}= -\sigma\), \(\frac{\partial f_1}{\partial y} \)\({}= \sigma\), \(\frac{\partial f_1}{\partial z} \)\({}= 0\).
  8. Row 2. \(f_2 = \rho x - y - xz\). \(\frac{\partial f_2}{\partial x} \)\({}= \rho - z\), \(\frac{\partial f_2}{\partial y} \)\({}= -1\), \(\frac{\partial f_2}{\partial z} \)\({}= -x\).
  9. Row 3. \(f_3 = xy - \beta z\). \(\frac{\partial f_3}{\partial x} \)\({}= y\), \(\frac{\partial f_3}{\partial y} \)\({}= x\), \(\frac{\partial f_3}{\partial z} \)\({}= -\beta\). So \[J = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho - z & -1 & -x\\ y & x & -\beta\end{pmatrix}.\]
  10. At \(P_0\), put \(x = y = z = 0\). \[J(P_0) = \begin{pmatrix}-\sigma & \sigma & 0\\ \rho & -1 & 0\\ 0 & 0 & -\beta\end{pmatrix}.\]
  11. At \(P_\pm\), put \(x = y = \pm c\) and \(z = \rho - 1\). Then \(\rho - z = 1\) and \(-x = \mp c\). \[J(P_\pm) = \begin{pmatrix}-\sigma & \sigma & 0\\ 1 & -1 & \mp c\\ \pm c & \pm c & -\beta\end{pmatrix}.\]
Practice · 2 marksFind all the fixed points for \(\sigma = 10\), \(\beta = \frac83\), \(\rho = 28\).›
Formula
\((0,0,0)\), and \(x = y = \pm\sqrt{\beta(\rho - 1)}\), \(z = \rho - 1\) when \(\rho>1\).
Where it comes from
Lines 1 to 3 above.
Working
  1. The origin \((0, 0, 0)\) is always a fixed point.
  2. \(\rho = 28>1\), so the two other fixed points \(P_\pm\) exist.
  3. \(z = \rho - 1 = 28 - 1 = 27\).
  4. \(x^2 \)\({}= \beta(\rho - 1) \)\({}= \frac83\times27 \)\({}= 8\times9 \)\({}= 72\).
  5. \(x = \pm\sqrt{72} = \pm8.49\), and \(y = x\).
  6. The fixed points are \((0, 0, 0)\), \((8.49, 8.49, 27)\) and \((-8.49, -8.49, 27)\). The value of \(\sigma\) is not needed, because it only gives \(y = x\).
Practice · 3 marksWith \(\sigma = 10\) and \(\beta = \frac83\), find the eigenvalues at the origin for \(\rho = 0.5\) and for \(\rho = 28\). Is the origin stable in each case?›
Formula
One eigenvalue is \(-\beta\). The other two are \(\lambda = \frac{T\pm\sqrt{T^2 - 4D}}2\) with \(T = -(\sigma + 1)\) and \(D = \sigma(1 - \rho)\).
Where it comes from
Lines 5 and 6 above, and the 2×2 shortcut in Part 0b.
Working
  1. Put \(\sigma = 10\) and \(\beta = \frac83\) into \(J(P_0)\). \(J = \begin{pmatrix}-10 & 10 & 0\\ \rho & -1 & 0\\ 0 & 0 & -\frac83\end{pmatrix}\).
  2. The third row and third column are zero except the corner entry, so one eigenvalue is \(-\frac83 = -2.67\).
  3. The other two are the eigenvalues of \(\begin{pmatrix}-10 & 10\\ \rho & -1\end{pmatrix}\). \(T = -10 + (-1) = -11\). \(D \)\({}= (-10)(-1) - (10)(\rho) \)\({}= 10 - 10\rho\).
  4. \(\rho = 0.5\). \(D = 10 - 5 = 5\).
  5. \(T^2 - 4D = 121 - 20 = 101\), and \(\sqrt{101} = 10.05\).
  6. \(\lambda = \frac{-11\pm10.05}2\). With \(+\): \(\frac{-0.95}{2} = -0.47\). With \(-\): \(\frac{-21.05}2 = -10.5\).
  7. All three eigenvalues (\(-0.47\), \(-10.5\), \(-2.67\)) are negative, so the origin is stable.
  8. \(\rho = 28\). \(D = 10 - 280 = -270\).
  9. \(T^2 - 4D = 121 + 1080 = 1201\), and \(\sqrt{1201} = 34.7\).
  10. \(\lambda = \frac{-11\pm34.7}2\). With \(+\): \(\frac{23.7}2 = 11.8\). With \(-\): \(\frac{-45.7}2 = -22.8\).
  11. One eigenvalue (11.8) is positive, so the origin is unstable. It is a saddle. Both results agree with the rule that the origin is stable only when \(\rho<1\).
