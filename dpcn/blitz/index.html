0a · Networks

A network (or graph) is a set of nodes joined by links. In a network of friendships, each node is a person and each link joins two people who know each other. N is the number of nodes and L is the number of links.

Degree. The degree ki of node i is the number of links at that node. In the picture, kA=3, kB=kC=kD=2 and kE=1. Every link has two ends, so the degrees add up to twice the number of links. This gives the average degree.

∑iki=2L,⟨k⟩=2LN.

The angle brackets ⟨ ⟩ mean "the average of". In the picture, ⟨k⟩=105=2.

Degree distribution. P(k) is the fraction of nodes that have degree k. In the picture, P(2)=35 because three of the five nodes have degree 2. The fractions add up to 1.

Power law and scale-free. A degree distribution of the form P(k)=Ck−γ is called a power law, and a network with such a P(k) is called scale-free. In a power law, large degrees are rare but not extremely rare. A large network then has a few nodes with very many links, and these are called hubs. Compare an exponential distribution like P(k)∝e−k/m. There the fraction of nodes falls so fast as k increases that there are no hubs.

Path length. The distance between two nodes is the smallest number of links you have to cross to get from one to the other. In the picture the distance from B to E is 3 (B to A, A to D, D to E). The average path length ℓ‾ is the average distance over all pairs of nodes.

Clustering coefficient. This measures how many of a node's neighbours are linked to each other. A node with ki neighbours has (ki2)=ki(ki−1)2 pairs of neighbours. Then

Ci=number of linked pairs of neighbours of iki(ki−1)/2.

Node A has neighbours B, C and D, so 3 pairs. Only B and C are linked, so CA=13. The average clustering coefficient C is the average of Ci over all nodes. Each linked pair of neighbours forms a triangle with node i, so high clustering means many triangles.

0b · Equations that change in time

x˙ (read "x dot") means dxdt, the rate at which x changes with time. An equation like x˙=f(x) gives that rate for every value of x.

Fixed point. A fixed point x∗ is a value where the rate is zero, f(x∗)=0. If x starts exactly there, it stays there.

Stability. A fixed point is stable if a small change away from it shrinks back to zero over time, and unstable if a small change grows. For one variable the test is the slope of f.

x˙=f(x):x∗ is stable if f′(x∗)<0 and unstable if f′(x∗)>0.

The Jacobian. With several variables, say x˙=f(x,y) and y˙=g(x,y), the test uses the Jacobian matrix. Row 1 holds the partial derivatives of f, and row 2 holds those of g.

J=(∂f∂x∂f∂y∂g∂x∂g∂y)

A partial derivative ∂f∂x is the derivative of f with respect to x, treating every other variable as a constant. You work out J with the variables left in, then put in the values at the fixed point.

Eigenvalues. The eigenvalues λ of J are the solutions of det⁡(J−λI)=0. Near the fixed point, small changes grow or shrink like eλt. So the fixed point is stable if every eigenvalue has a negative real part. It is unstable if any eigenvalue has a positive real part.

The 2×2 shortcut. For J=(abcd), let T=a+d (the trace) and D=ad−bc (the determinant).

λ=T±T2−4D2,stable⟺T<0 and D>0.

If D<0, one eigenvalue is positive and one is negative. That fixed point is called a saddle, and it is unstable.

A 3×3 matrix that splits. If the third row and the third column are zero except for the corner entry, that corner entry is one eigenvalue. The other two come from the top-left 2×2 block. Part 5 uses this.

Part 0b, "Fixed point" and "Stability".

f′(x)=1−2x. f′(0)=1>0, so 0 is unstable. f′(1)=−1<0, so 1 is stable.

0c · Maths tools

Parts 1 and 2 use the same three tools again and again.

Separating variables. To solve dkdt=k2t, put everything with k on one side and everything with t on the other, then integrate both sides.

dkk=dt2t⇒ln⁡k=12ln⁡t+c.

A known starting value fixes the constant c. You will need ∫dxx=ln⁡x, ln⁡a−ln⁡b=ln⁡ab, and bln⁡a=ln⁡ab.

Joining times are spread evenly. In a network where one node is added at each step 1,2,…,t, every joining time occurs exactly once. So the fraction of nodes that joined after some time T is

fraction with ti>T=t−Tt=1−Tt.

From "fraction below k" to P(k). If F(k) is the fraction of nodes with degree below k, then the degree distribution is its derivative, P(k)=dFdk.

Sine. sin⁡ϕ is always between −1 and 1. So sin⁡ϕ=a has a solution only if |a|≤1. When it does, there are two solutions between 0 and π, namely ϕ and π−ϕ. The one below π2 has cos⁡ϕ>0. Part 4 uses this.

Try itSolve dkdt=k2t with k=2 at t=5. What is k at t=20?›
Formula
Separate variables, dkk=dt2t, and use ∫dxx=ln⁡x.
Where it comes from
Part 0c, "Separating variables".
Working

Integrate from k=2 at t=5. ln⁡k2=12ln⁡t5, so k=2t/5.

At t=20, k=24=4.

1 · The Barabási–Albert (BA) model

About 2 hours. This part and the next are the largest share of the syllabus.

The BA model is a rule for building a network one node at a time. It has two ingredients.

  1. Growth. Start with a few nodes (m0 of them). At each time step t=1,2,3,…, add one new node with m links.
  2. Preferential attachment. Each of those m links is attached to an existing node i with probability
    Π(ki)=ki∑jkj,
    where the sum in the bottom is over all existing nodes. A node with twice the degree is twice as likely to receive the link.

After t steps there are about t nodes and mt links. Nodes that were added early have had more steps in which to receive links, and every link they receive makes the next one more likely. The result is a power-law degree distribution, P(k)∝k−3, so the network is scale-free with γ=3.

The board asks for three things. They are the rate dkidt, the distribution P(k), and the master equation, which is a second way to get P(k).

1A · The rate dkidt

Think of ki as a smooth number that grows with time. Its rate of change is the expected number of new links that node i receives in one step.

Write this in the exam

Show that dkidt=ki2t, and solve it.

  1. Each step adds m links, and each one attaches to node i with probability Π(ki)=ki∑jkj. So dkidt=mΠ(ki)=mki∑jkj.
  2. After t steps there are mt links. Each link adds 2 to the total degree, so ∑jkj=2mt.
  3. Substitute. dkidt=mki2mt=ki2t. This proves that the rate is proportional to kit.
  4. Separate the variables. dkiki=12dtt.
  5. Node i was added at time ti with m links, so ki(ti)=m. Integrate from there. ln⁡kim=12ln⁡tti.
  6. So ki(t)=mtti. A node added earlier (smaller ti) has a larger degree.

1B · The degree distribution P(k) (continuum theory)

The degree of a node depends only on when it was added. So the question "what fraction of nodes have degree below k?" becomes "what fraction of nodes were added after a certain time?", and joining times are spread evenly.

Write this in the exam

Show that P(k)=2m2k−3.

  1. From 1A, ki=mt/ti. Solving for the joining time gives ti=m2tki2.
  2. A node has degree below k exactly when it was added after time m2tk2. So the fraction with degree below k equals the fraction with ti>m2tk2.
  3. One node is added per step, so joining times are spread evenly over 1…t, and the fraction added after time T is 1−Tt.
  4. With T=m2tk2, the fraction with degree below k is F(k)=1−m2k2. The t cancels, so this does not change as the network grows.
  5. Differentiate. P(k)=dFdk=2m2k3. This is a power law with γ=3, whatever the value of m.

1C · The master equation

This method gives P(k) by counting. Let N(k,t) be the number of nodes with degree k at time t. There are t nodes at time t, so the fraction is P(k,t)=N(k,t)t. In one step, a node of degree k−1 that receives a link moves up to degree k. A node of degree k that receives a link moves up to degree k+1. The new node adds one node of degree m.

Write this in the exam

Write the master equation for the BA model and solve it for P(k).

  1. A given degree-k node receives a given new link with probability k2mt. There are N(k,t) such nodes and m new links, so the expected number of degree-k nodes that receive a link in one step is m⋅N(k,t)⋅k2mt=k2P(k,t).
  2. For k>m, degree-k nodes are gained from degree k−1 and lost to degree k+1. N(k,t+1)=N(k,t)+k−12P(k−1,t)−k2P(k,t).
  3. For k=m there is nothing below, but the new node is gained. N(m,t+1)=N(m,t)+1−m2P(m,t).
  4. Look for a steady state, where P(k,t)=P(k) does not depend on t. Then N(k,t+1)−N(k,t)=(t+1)P(k)−tP(k)=P(k).
  5. At k=m: P(m)=1−m2P(m), so P(m)=2m+2.
  6. For k>m: P(k)=k−12P(k−1)−k2P(k), so k+22P(k)=k−12P(k−1) and P(k)=k−1k+2P(k−1).
  7. Apply this repeatedly, starting from P(m). The factors mm+3⋅m+1m+4⋯k−1k+2 mostly cancel, leaving P(k)=2m(m+1)k(k+1)(k+2).
  8. For large k the bottom is about k3, so P(k)≈2m(m+1)k3∝k−3. This is the same power law, γ=3, as in 1B.
Remember

Ingredients are growth and preferential attachment, Π(ki)=ki∑jkj. The total degree is ∑jkj=2mt.

dkidt=ki2t, so ki=mt/ti. The fraction with degree below k is 1−m2k2, so P(k)=2m2k−3.

Master equation: P(m)=2m+2 and P(k)=k−1k+2P(k−1), so P(k)=2m(m+1)k(k+1)(k+2).

2 · Changing the BA model

About 1 hour. The board lists "no growth", "no preferential attachment" and "nonlinear preferential attachment".

Each case changes one rule of the BA model and asks what degree distribution results. The method is the same as in Part 1. Write dkidt using the new rule, integrate from the node's starting degree, and, where needed, get P(k) from the evenly spread joining times.

2A · Growth without preferential attachment (Model A)

Nodes are still added one per step with m links each. Each link now attaches to an existing node chosen uniformly at random, so the degree of a node does not affect its chance of receiving a link.

Write this in the exam

Find ki(t) and P(k) for Model A. Is it scale-free?

  1. There are m0+t−1≈t existing nodes, each equally likely, so Π(ki)=1t.
  2. dkidt=mΠ=mt. This does not depend on ki.
  3. Integrate from ki(ti)=m. ki−m=mln⁡tti, so ki(t)=m+mln⁡tti.
  4. ki<k exactly when ln⁡tti<km−1, that is, when ti>te1−k/m.
  5. Joining times are spread evenly, so the fraction with degree below k is F(k)=1−e1−k/m.
  6. Differentiate. P(k)=dFdk=eme−k/m for k≥m.
  7. This is exponential, not a power law. Large degrees are extremely rare and there are no hubs, so the network is not scale-free.

2B · Preferential attachment without growth (Model B)

Now the number of nodes is fixed at N and no nodes are added. At each step, one node is chosen uniformly at random, and a new link is added from it to a node chosen by preferential attachment.

Write this in the exam

Find ki(t) for Model B and describe the degree distribution.

  1. Each step adds one link, so after t steps ∑jkj=2t.
  2. Node i gains a link if it is the randomly chosen end (probability 1N) or the preferentially chosen end (probability ki2t). So dkidt=1N+ki2t.
  3. Try ki=at. Then a=1N+a2, so a=2N.
  4. Without the 1N term the equation is the BA one, solved by t. So the general solution is ki(t)=2tN+Cit, where Ci depends on the node.
  5. For large t, the 2tN part (the same for every node) is much larger than the Cit part. So every degree is close to 2tN, and the distribution is a narrow peak around the average, not a power law.
  6. There are only N(N−1)2 possible links, so after about N22 steps every pair of nodes is linked and the network is complete. The distribution never settles to a steady state.

2C · Nonlinear preferential attachment

Nodes are added as in BA, but the attachment probability uses a power α of the degree.

Π(ki)=kiα∑jkjα,α≥0.

α=0 gives Model A, and α=1 gives the BA model. The table is what to learn.

αNameDegree distributionLargest degree after t steps
0no preferential attachmentexponential∼ln⁡t
0<α<1sublinearstretched exponential, about e−ck1−α, no hubs∼(ln⁡t)1/(1−α)
1linear (BA)power law k−3∼t1/2
α>1superlinearone node has a finite fraction of all links, the rest have small degree∼t
Write this in the exam

Explain what happens for α<1 and for α>1.

  1. For α<1, degrees stay small, so kjα has a finite average ν. With about t nodes, ∑jkjα≈νt.
  2. Then dkidt=mkiανt. Separate and integrate: ki1−α−m1−α=(1−α)mνln⁡tti.
  3. The oldest node (ti=1) has kmax⁡∼(ln⁡t)1/(1−α). This grows more slowly than any power of t, so there are no hubs and no power law.
  4. For α>1, suppose one node has degree k1=ct. Then k1α=cαtα, which for α>1 grows faster than the sum over all other nodes (about t).
  5. So Π(k1)→1. Almost every new link attaches to node 1, which keeps k1 proportional to t. The assumption is consistent, so one node ends up with a finite fraction of all the links.
Remember

Both ingredients are needed for a power law. Growth alone (Model A) gives ki=m+mln⁡tti and an exponential P(k)=eme−k/m. Preferential attachment alone (Model B) gives ki≈2tN for every node, and eventually a complete graph.

Nonlinear: α<1 gives no hubs, α=1 gives BA, and α>1 gives one node with most of the links.

3 · Small-world graphs

About 90 minutes. The board asks for the average clustering coefficient and the path length at p=0 and p=1, and the rewiring probability. Part 0a defines clustering and path length.

The Watts–Strogatz model starts from a ring lattice. Place n nodes in a circle and link each node to its k nearest nodes on each side, so every node has degree 2k. Then go through the links one at a time and, with probability p, move one end of the link to a node chosen at random. This is called rewiring, and p is the rewiring probability.

  • At p=0 nothing is rewired, and the graph is the ring lattice.
  • At p=1 every link is rewired, and the graph is a random graph with the same average degree 2k.

The ring lattice has high clustering and long paths. The random graph has low clustering and short paths. For small p, a few rewired links connect distant parts of the ring, so paths become short, while almost all triangles remain, so clustering stays high. A graph with both properties is called a small world.

Watch the letter k

On this page k is the number of neighbours on each side, so the degree is 2k. If a question gives the degree as K, use k=K/2.

3A · Clustering of the ring lattice, C(0)

Write this in the exam

Show that C(0)=3(k−1)2(2k−1).

  1. Each node has 2k neighbours, so there are (2k2)=k(2k−1) pairs of neighbours.
  2. Two neighbours are linked when they are at most k positions apart on the ring.
  3. Pairs on the same side of the node are always within k of each other. Each side has (k2) pairs, so this gives 2(k2).
  4. A pair on opposite sides, at positions −a and +b, is linked when a+b≤k. Counting these gives (k−1)+(k−2)+⋯+1+0=(k2).
  5. Linked pairs in total: 3(k2)=32k(k−1).
  6. C(0)=32k(k−1)k(2k−1)=3(k−1)2(2k−1). For large k this approaches 34, and it does not depend on n.

3B · Path length of the ring lattice, ℓ‾(0)

Write this in the exam

Show that ℓ‾(0)≈n4k.

  1. From any node, each step along the ring reaches k more nodes on each side, so exactly 2k new nodes are at each distance ℓ=1,2,…
  2. The farthest node is n2 positions away. Each step covers k positions, so the largest distance is D=n2k.
  3. Average over all nodes: ℓ‾(0)=1n∑ℓ=1D2kℓ≈2kn⋅D22=2kn⋅n28k2=n4k.
  4. ℓ‾(0) grows in proportion to n, so a large ring lattice has long paths.

3C · The random graph at p=1

Write this in the exam

Find C and ℓ‾ at p=1.

  1. The graph is random with average degree 2k. Any two nodes are linked with probability q=2kn−1≈2kn.
  2. Links are independent, so two neighbours of a node are linked with the same probability q as any other pair. So C=q≈2kn, which approaches 0 for large n.
  3. From a node there are about 2k nodes at distance 1, (2k)2 at distance 2, and (2k)ℓ at distance ℓ.
  4. All n nodes are reached when (2k)ℓ‾≈n, so ℓ‾≈ln⁡nln⁡2k. This grows only like ln⁡n, so paths are short.

3D · Clustering for 0<p<1

Write this in the exam

Show that C(p)=C(0)(1−p)3.

  1. Clustering counts triangles, and each triangle in the ring lattice is made of three links.
  2. A triangle remains only if none of its three links is rewired. Each link is kept with probability 1−p, independently, so a triangle remains with probability (1−p)3.
  3. A rewired link forms a new triangle only with probability of order 1n, which is neglected.
  4. So C(p)=C(0)(1−p)3=3(k−1)2(2k−1)(1−p)3.
  5. There are about nkp rewired links. Even when p is small, these shortcuts make ℓ‾ close to the random value, while C is still close to C(0). That range of p is the small world.

4 · Two coupled phase oscillators

About 45 minutes. The board writes θ˙1=f1(ω1,θ1,θ2,k1) and θ˙2=f2(ω2,θ1,θ2,k2) and asks for the critical condition.

An oscillator here is anything that repeats a cycle, such as a pendulum or a flashing light. Its state is an angle θ, called the phase, which increases by 2π every cycle. On its own, the phase increases at a constant rate, θ˙=ω. The constant ω is the natural frequency.

Two oscillators are coupled when the rate of each phase depends on the other phase.

θ˙1=ω1+k1sin⁡(θ2−θ1),θ˙2=ω2+k2sin⁡(θ1−θ2).

k1 and k2 are the coupling strengths. If θ2 is slightly ahead of θ1, the term k1sin⁡(θ2−θ1) is positive, so θ1 increases faster, and the term in the second equation is negative, so θ2 increases more slowly. The coupling therefore reduces the difference between the phases.

The oscillators are phase-locked (synchronised) when the phase difference ϕ=θ2−θ1 stays constant. Then both phases increase at the same rate Ω, the common frequency. The question is how large the coupling must be for this to happen.

Write this in the exam

Find the condition for the two oscillators to lock, and the common frequency Ω.

  1. Let ϕ=θ2−θ1 and Δω=ω2−ω1. Subtract the first equation from the second, using sin⁡(θ1−θ2)=−sin⁡ϕ. ϕ˙=Δω−(k1+k2)sin⁡ϕ.
  2. Locked means ϕ is constant, so ϕ˙=0. That gives sin⁡ϕ∗=Δωk1+k2.
  3. Since |sin⁡ϕ∗|≤1, a solution exists only if |Δω|≤k1+k2. This is the critical condition. With equal couplings k1=k2=k, the critical coupling is kc=|Δω|2.
  4. Of the two solutions, the stable one has cos⁡ϕ∗>0. The slope of ϕ˙ with respect to ϕ is −(k1+k2)cos⁡ϕ, which must be negative for stability.
  5. In the locked state, Ω=ω1+k1sin⁡ϕ∗=ω2−k2sin⁡ϕ∗. Multiply the first by k2 and the second by k1, add, and divide by k1+k2. Ω=k2ω1+k1ω2k1+k2.
  6. If the condition fails, ϕ˙ is never zero, so the phase difference keeps changing and the oscillators do not lock.
Remember

ϕ˙=Δω−(k1+k2)sin⁡ϕ. Lock if and only if |Δω|≤k1+k2. Equal couplings give kc=|Δω|2.

sin⁡ϕ∗=Δωk1+k2, taking the root with cos⁡ϕ∗>0. Ω=k2ω1+k1ω2k1+k2, which is the plain average when k1=k2.

5 · The Lorenz system

About 45 minutes. This uses the fixed points, Jacobian and eigenvalues from Part 0b.

The Lorenz system has three variables x, y and z that change together. The constants σ, ρ and β are all positive.

x˙=σ(y−x),y˙=ρx−y−xz,z˙=xy−βz.

The question asks for the fixed points and the Jacobian at each one. Solve the simplest equations first.

Write this in the exam

Find the fixed points of the Lorenz system, the Jacobian at each, and show that the origin is stable if and only if ρ<1.

  1. Set all three rates to zero. From σ(y−x)=0, y=x.
  2. From xy−βz=0 with y=x: z=x2β.
  3. From ρx−y−xz=0 with y=x: x(ρ−1−z)=0. So either x=0 or z=ρ−1.
  4. x=0 gives the origin P0=(0,0,0). z=ρ−1 gives x2=β(ρ−1), so P±=(±β(ρ−1), ±β(ρ−1), ρ−1), which exist only when ρ>1.
  5. The Jacobian, with one row per equation and one column per variable: J=(−σσ0ρ−z−1−xyx−β).
  6. At P0: J=(−σσ0ρ−1000−β). The third row and column are zero except the corner, so one eigenvalue is −β<0.
  7. The other two come from (−σσρ−1), with trace T=−(σ+1)<0 and determinant D=σ(1−ρ). Stable needs T<0 and D>0. T is always negative, so the origin is stable if and only if σ(1−ρ)>0, that is, ρ<1. For ρ>1, D<0 and the origin is a saddle.
  8. At P±, let c=β(ρ−1). Put x=y=±c and z=ρ−1, so ρ−z=1. J(P±)=(−σσ01−1∓c±c±c−β).
Remember

Fixed points: (0,0,0), and for ρ>1, (±β(ρ−1),±β(ρ−1),ρ−1).

J=(−σσ0ρ−z−1−xyx−β). The origin is stable if and only if ρ<1.
